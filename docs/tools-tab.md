# 工具 tab 与工具永久拥有
## 背景
斧子、镐子、鱼竿、弓此前是普通背包道具:入包即拥有、占用背包格、可以在物品详情里丢弃导致失去工具。
## 需求描述
工具不再进背包:制作完成即永久拥有、不可丢弃;在背包面板「制作」与「角色」tab 之间新增「工具」tab,列出全部工具(斧子/镐子/鱼竿/弓),区分已拥有/未拥有,点击查看工具描述。
## 设计方案
- 拥有状态:`Game.tools`(布尔表)由「背包推导」改为权威状态,制作/恢复/GM 发放时点亮,永不熄灭;`Crafting.craft()` 对工具类配方直接置位 `tools[tool]`,不再写入背包。
- 存档:`SaveData` 新增 `tools: ToolId[]`,`SAVE_VERSION` 6→7(旧档按约定丢弃)。
- UI:`Backpack.tsx` tab 列表改为 物品/制作/工具/角色;工具页按 `TOOL_IDS` 顺序展示,未拥有半透明,点击行展开描述;背包为空但拥有工具时背包按钮仍显示(工具页在面板内)。
- GM 面板发放工具类物品(`gmGiveItem`)改为直接点亮拥有状态,不入包。

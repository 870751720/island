# 床与睡觉

## 背景

荒岛上过了夜晚只能硬熬,缺少一个「跳过夜晚/刷新资源」的主动手段。新增可放置的床,让玩家可以睡觉直接跳到第二天清晨。

## 需求描述

- 工作台新增配方「床」:树枝×8 + 石头×2 + 绳线×2,产物为床道具,背包里点「使用」放到脚下(与工作台/木箱同一套摆放规则)。
- 床可被锄头整张挖走(普通锄 2 下、精致锄 1 下),变回对应等级的床道具,可再放置。
- 靠近床时工具按钮变为床的图标;持锄头面对床时按钮不劫持(意图是挖走)。
- 点击床图标发起睡觉:玩家站定约 3 秒(头顶「睡觉中…」+ 进度圆环),移动会中断且不结算。
- 睡觉结算:饥饿、口渴各固定 -20,健康 +20(上限 100);饥饿或口渴不足 20 时不允许睡觉并提示「又饿又渴睡不着,先吃点喝点再睡吧」。
- 时间真的跳到第二天清晨:资源点(浆果/灌木/草/蚯蚓坑)再生倒计时推进、种下的树生长推进、火堆燃料按跳过的秒数继续消耗。
- 工作台新增配方「二级床」:床×1 + 石头×10,二级床为石架皮毛垫造型,睡觉效果与一级床相同。

## 设计方案

- `src/game/entities/Bed.ts`:`Bed` 摆件,程序化建模,1 级木框稻草垫、2 级石架皮毛垫,可放置多个。
- `src/game/systems/BedSystem.ts`:床系统,复用工作台/木箱的放置与锄头挖掘模式(距离、命中数与木箱一致);睡觉为计时流程,完成后通过 `onWake` 回调把结算交回 `Game`,系统本身不接触生存/昼夜逻辑。
- `DayNightSystem.sleepUntilMorning()`:把时刻跳到清晨(t=0.05),返回按白天流速折算的跳过秒数;GM 锁白天时返回 0。
- `Props.advance(seconds)` / `CampfireSystem.passTime(seconds, elapsed)`:按跳过的秒数推进再生/树生长与燃料消耗,不做击打、摇摆等表现。
- 结算集中在 `Game.sleep()`:校验饥饿/口渴 ≥20 → 发起睡觉 → 醒来时统一跳时间、推进世界、扣饥饿/口渴、回健康、弹提示。
- 与其他系统互斥:睡觉与挖床计入 `isBusy`,采集/合成/钓鱼/射箭/喝水/播种等的让位判断均已接入;睡觉中不可进食/钓鱼。
- 存档:`SaveData.beds`(落点 + 等级),`SAVE_VERSION` +1,旧档按约定丢弃。
- UI:工具按钮新增床模式(🛏️,优先级 工作台 > 火堆 > 木箱 > 床);背包「使用」支持床道具;工作台面板按材料(含背包里的床)展示两个配方;床道具掉落物有专属微型床造型。

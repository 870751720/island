# 床与睡觉

## 背景

荒岛上过了夜晚只能硬熬,缺少一个「跳过夜晚/刷新资源」的主动手段。新增可放置的床,让玩家可以睡觉直接跳到第二天清晨。

## 需求描述

- 工作台新增配方「床」:树枝×8 + 石头×2 + 绳线×2,产物为床道具,背包里点「使用」放到脚下(与工作台/木箱同一套摆放规则)。
- 床可被锄头整张挖走(普通锄 2 下、精致锄 1 下),变回对应等级的床道具,可再放置。
- 靠近床时工具按钮变为床的图标;持锄头面对床时按钮不劫持(意图是挖走)。
- 点击床图标发起睡觉:玩家站定约 3 秒(头顶「睡觉中…」+ 进度圆环),移动会中断且不结算。
- 睡觉结算按床等级查表(`Game.SLEEP_STATS`):一级床需饥饿/口渴 ≥20,各 -20,健康 +20;二级床需 ≥15,各 -15,健康 +25;三级床需 ≥10,各 -10,健康 +30(健康上限 100)。条件不足时不允许睡觉并提示「又饿又渴睡不着,先吃点喝点再睡吧」。
- 时间真的跳到第二天清晨:资源点(浆果/灌木/草)再生倒计时推进、种下的树生长推进、火堆燃料按跳过的秒数继续消耗。
- 工作台新增配方「二级床」(需二级工作台):一级床×1 + 皮毛×4,二级床为加高木框皮毛垫造型,睡觉消耗/条件更低、恢复更高。
- 工作台新增配方「三级床」(需三级工作台):二级床×1 + 布料×5 + 皮毛×5,三级床铺整幅软布床垫与双层白枕头、高床头板(带顶檐)、四角雕花柱与床尾板、白布毯叠皮毛搭毯;睡觉消耗与条件更低、恢复更高。

## 设计方案

- `src/game/entities/Bed.ts`:`Bed` 摆件,程序化建模,1 级木框稻草垫、2 级加高木框皮毛垫、3 级皮毛床 + 帐篷罩,可放置多个。
- `src/game/systems/BedSystem.ts`:床系统,复用工作台/木箱的放置与锄头挖掘模式(距离、命中数与木箱一致);睡觉为计时流程,完成后通过 `onWake` 回调把结算交回 `Game`,系统本身不接触生存/昼夜逻辑。
- `DayNightSystem.sleepUntilMorning()`:把时刻跳到清晨(t=0.05),返回按白天流速折算的跳过秒数;GM 锁白天时返回 0。
- `Props.advance(seconds)` / `CampfireSystem.passTime(seconds, elapsed)`:按跳过的秒数推进再生/树生长与燃料消耗,不做击打、摇摆等表现。
- 结算集中在 `Game.sleep()`:校验饥饿/口渴 ≥20 → 发起睡觉 → 醒来时统一跳时间、推进世界、扣饥饿/口渴、回健康、弹提示。
- 与其他系统互斥:睡觉与挖床计入 `isBusy`,采集/合成/钓鱼/射箭/喝水/播种等的让位判断均已接入;睡觉中不可进食/钓鱼。
- 存档:`SaveData.beds`(落点 + 等级),`SAVE_VERSION` +1,旧档按约定丢弃。
- UI:工具按钮新增床模式(🛏️,优先级 工作台 > 火堆 > 木箱 > 床);背包「使用」支持床道具;工作台面板按材料(含背包里的床)展示两个配方;床道具掉落物有专属微型床造型。
### 配方调整(2026-09)

- 二级床材料由「一级床 + 皮毛 ×4」增加为「一级床 + 皮毛 ×4 + 木头 ×4 + 石头 ×4」。
- 三级床材料由「二级床 + 皮毛 ×10」改为「二级床 + 布料 ×5 + 皮毛 ×5」(布料来自纺织机);同时优化三级床造型:软布床垫/枕头、床头雕花柱、床尾垂帘与米白布帘帐篷,明显比二级床精致。

### 睡觉分级与造型重做(2026-09)

- 睡觉数值改为按床等级查表:一级床 条件/消耗 20、恢复 20;二级床 条件/消耗 15、恢复 25;三级床 条件/消耗 10、恢复 30(条件为入睡所需最低饥饿/口渴)。
- 三级床去掉外部布帘帐篷;二、三级床造型重做:二级床加高木框 + 皮毛垫 + 米白枕 + 床头板 + 床头双柱;三级床软布床垫 + 双层大枕头 + 带顶檐高床头板 + 四角雕花柱(顶球) + 床尾板 + 白布毯叠皮毛搭毯。掉落物模型同步改为微型四柱床。
- 三级床模型整体重写并从 `makeBedMesh` 独立为 `makeLuxuryBedMesh`:深木色矮床身 + 厚软布床垫 + 高床头软包(木檐) + 床尾矮板 + 双枕 + 白毯叠皮毛搭毯,全部方块拼装、无柱状件;二级床床头柱同步移除、床腿改方柱;掉落物模型同步改为纯方块。

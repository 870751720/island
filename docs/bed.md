# 床与睡觉

## 背景

荒岛求生需要可放置、可升级的休息设施。一级至三级床以帐篷呈现，与野外营地风格一致。

## 需求描述

- 一级为草绿色简易三角帐篷，木杆、绳索和草席卧铺突出求生感。
- 二级为赤陶色皮革营帐，增加高度、浅色加强带、收束门帘和皮毛卧铺。
- 三级为米白豪华帐篷，具有金色包边、青绿色卧铺与迎宾地毯、挑出门廊和顶部旗帜，轮廓和细节均比低等级精致。
- 地面掉落物使用对应等级的微型帐篷。
- 保留床的名称、图标、配方、放置、拆除和睡眠功能。一级配方为树枝×8 + 石头×2 + 绳线×2；二级为一级床×1 + 皮毛×4 + 木头×4 + 石头×4；三级为二级床×1 + 布料×5 + 皮毛×5。
- 睡眠持续 4 秒，躺下后不可移动中断。一级饥饿/口渴条件及消耗为 20、健康恢复 20；二级为 15/25；三级为 10/30。
- 睡醒推进至次日清晨，资源再生、树木生长与火堆燃料按跳过的时间结算。

## 设计方案

- `src/game/entities/TentModel.ts` 负责程序化低多边形帐篷，使用高粗糙度、flatShading 标准材质；同材质几何体合并，每个帐篷 5 个网格，不增加灯光或逐帧动画。微型版本省略绳索和地钉。
- `Bed.ts` 和 `DropModels.ts` 复用同一模型构建函数，确保放置物与掉落物的等级外观一致。
- 帐篷脊线沿本地 X 轴，卧铺顶面为 0.37，沿用身体中轴高度 0.56 和脚跟偏移 0.72；入口敞开，床头位于 -X。
- `BedSystem` 保留交互范围、放置朝向、拆除规则和睡觉流程，`Game` 负责生存和昼夜结算。
- 保留 `bed1`/`bed2`/`bed3`、`SaveData.beds` 和 `SAVE_VERSION`；旧档加载后按原等级显示帐篷。
- 房主仍权威结算放置、拆除和睡觉；客人通过既有动作上行与床世界增量、玩家姿态快照重建相同帐篷及睡眠表现，无新增协议或同步字段。

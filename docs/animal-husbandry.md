# 动物驯养与食料桶

## 背景

套索捕捉扩展为需要持续投喂的驯养玩法。驯养关系属于全队；失养的狼熊会重新攻击玩家。

## 需求描述

### 驯养与爱心

| 动物 | 爱心上限 | 主要食谱 | 成年驯养产物 |
|---|---:|---|---|
| 兔子 | 30 | 果蔬、植物熟食、草和灌木 | 无 |
| 羊 | 60 | 果蔬、植物熟食、橡果、草和灌木 | 羊奶、羊毛 |
| 野牛 | 100 | 果蔬、植物熟食、橡果、草和灌木 | 牛奶 |
| 狼 | 150 | 生熟鱼肉，排除河豚 | 无 |
| 熊 | 200 | 果蔬、植物熟食、橡果、生熟鱼肉和浆果丛 | 无 |

- 准确食谱由每个 `Food.eaters` 标签决定；所有食物必须显式填写标签，不能喂动物时填空数组。薯条也使用这些标签，保留原本不吃生肉、生鱼、奶、酒和部分植物的限制。
- 羊、兔子、野牛被套住即可开始驯养；狼熊必须五次挣脱失败。头顶显示空心，吃食物后填充。狼熊未驯养成功前仍保留攻击能力，进食期间停下。
- 首次驯养只吃玩家主动丢弃且落地至少四秒的适配食物，不吃战利品、溢出物，不用食料桶或自然资源自动完成首次驯养。
- 每次只扣一份食物，增加其饥饿恢复值；共用五秒进食冷却，显示与薯条相同风格的进食表情和低头动作。
- 填满后成功驯养，清除攻击、追击和野生繁殖状态。全体玩家与薯条无法伤害或索敌到它，动物也不再攻击玩家；套索仍能瞄准并迁移它，再次套住不挣扎。
- 驯养成功后隐藏常驻填充红心，改为头顶每秒飘出一枚小爱心，轻微左右摆动并在 2.4 秒内上浮淡出；已驯养且爱心值达到上限的 50% 时循环播放；低于 50% 时停止特效并恢复填充爱心，恢复到 50% 及以上再切回特效。未完成驯养时仍显示填充进度，失去驯养后停止特效。进食和可剪毛提示继续显示。
- 特效复用每只动物三枚矢量节点，不增加 WebGL drawcall；以各物种头部节点上方为投影锚点，跟随头部动作、幼崽缩放与相机缩放；小爱心采用饱和粉红色与深色描边，前段保持清晰，仅末段淡出，上浮距离为图标尺寸的 1.1 倍，离屏停止，使用游戏时间随暂停停下，动物移除时回收。
- 驯养后每秒减少上限的 `1/1800`，从满心到零需三十分钟运行时间。暂停、退出不计时；睡觉跳过日历不额外扣除。
- 爱心低于 70% 后持续寻食，直到填满；最后一口超出上限的部分不保留。已驯养动物会寻找地面投喂物、食料桶及适配自然资源。一次啃草或灌木恢复 2 点，浆果丛恢复 3 点；资源进入原有 180 秒再生，不掉纤维、树枝和种子。纤维与树枝不能投喂。
- 爱心归零立即失去驯养，恢复野生攻击与受伤规则，清空中心、产物和生产进度。仍有套索时回到待驯养状态，保持本轮挣扎判定结果；首次未填满就解绳会清空进度。

### 活动范围、成长与生产

- 主动解绳时以操作玩家当时的位置为固定中心，只在半径十五米内活动。再次套住并解开刷新中心；牵引中暂不受旧中心约束，打桩受三米绳长约束。
- 断线、死亡被动释放保留已有中心；从未设置中心时以动物释放位置兜底。离旧中心太远时步行返回，不瞬移。
- 寻食及闲逛遵守地形、围栏和阻挡；到达食物附近且路径无阻挡后才消费，不能隔栏吃食。
- 小羊、小牛可以驯养，继续按五游戏日成长；未成年不产奶、不产毛。已驯养动物不繁殖，也不占原野生栖息地名额。
- 成年羊每十分钟各准备一份羊奶、一份羊毛；成年野牛每十分钟准备一份牛奶。分别计时，未领取不累计。解绳和再次套索不重置进度。
- 站在有奶动物的 2.2 米内自动挤奶，手持剪刀时改为剪毛，动作 0.6 秒，移动、游泳或其他交互占用时中断。背包装不下沿用物品发放的掉落规则。
- 只有成年驯养羊可以剪毛，每次一份。剪后模型变为短毛，十分钟后长好；幼崽和野生羊不能剪。
- 剪刀为三级工作台的永久工具，配方 2 铁锭＋1 木头，背包持有时进入工具按钮循环及长按选择，手持时不自动切采集工具。
- 牛奶生命 +5、饥饿 +10、饥渴 +25；每两份牛奶或两份羊奶可酿一瓶奶酒，不混合投料。
- 三级床配方为二级床＋5 羊毛＋5 毛皮；狗窝配方为 10 木头＋5 布料＋3 铁锭＋5 羊毛。

### 食料桶

- 四级工作台解锁，设施分类，配方 3 铁锭＋3 木头＋1 冒险家的经验书。
- 二十格，沿用容器无限同类堆叠、存取和持铲回收规则；回收时桶与内容物返还，放不下的掉落。
- 只接收至少一种动物或薯条能吃且恢复饥饿的食物。动物实际走近后每次取一份，适配各自食谱。
- 薯条也能取食，保持自身原有冷却和成长系统，不套用动物爱心。

## 设计方案

- `AnimalHusbandry.ts`：纯状态转换、衰减、冷却、生产、存档缺省恢复。
- `Food.ts` 的必填 `eaters` 与 `AnimalFood.ts`：统一食谱查询和背包喂食说明。
- `AnimalForaging.ts`：低频目标选择、有限网格寻路、抵达校验；掉落物与容器提供同一食品来源接口，消费时重新校验剩余数量。
- `Wildlife`：接入权威动物循环、战斗过滤、套索和成长。每个动物独立爱心及寻食状态，不向客人分配随机和库存结算。
- `CrateSystem`：以 `feedBarrel` 容器类型复用存取、二十格、占地、回收、存档与世界增量；模型在 `HusbandryModels.ts` 程序化生成。
- `LivestockHarvestSystem`：每会话的挤奶/剪毛进度，完成时由 `Game.harvestAnimal` 校验距离、工具、存活、成年及产物状态，拒绝重复领取。
- `HusbandryIndicators`：头顶 DOM 矢量爱心、平滑填充、进食表情与可剪毛标记，不占触摸区域。羊模型使用现有网格显隐和缩放区分短毛。

### 联机与存档

房主推进爱心、进食、资源消耗与产出；动物姿态携带 `husbandry` 与 `milk`，客人插值位置并显示爱心。短时进食由可靠 `animalEat` 事件补播，姿态同时提供恢复信息。食料桶内容按 `crates` 槽位增量同步；动作 `harvestAnimal [animalId, wool]` 由房主验证和结算。协议版本为 43，旧客户端不能混入新房间。

`SAVE_VERSION` 不变。动物新增可选 `husbandry`，保存爱心、寻食状态、冷却、活动中心、奶毛计时和短毛状态；未拴桩的驯养兔、狼、熊也保存。旧档默认未驯养，不继承原套索产奶结果；牵引绳沿用保存时返还背包的既有规则，保存驯养动物位置和中心。食料桶沿用 `crates` 存档。

### 验证

`node scripts/test-husbandry.mts` 检查爱心阈值与归零、幼崽生产限制、食谱、伤害和索敌保护、套索中心、单份消费、竞争消费、产物防重复及容器槽位同步。`node scripts/test-lasso.mts` 回归挣扎、攻击、打桩、存档和断绳表现。运行时手机视觉和联机体验由用户本地验证。

## 驯养 GM 调试

GM「驯养」分类可领取套索、剪刀、食料桶和测试食物，生成五种可驯养动物。狼、熊整轮五次挣扎的累计概率可在 0–100% 调节，默认分别 95%、99%；单次概率为 `1 - (1 - 总概率)^(1/5)`。修改只影响后续判定，不重置次数；0% 仍需完成五次挣扎，100% 在下次挣扎时必脱。

爱心衰减与奶毛生产分别支持 0–120 倍速，默认 1，0 暂停对应计时；60 倍时满心 30 秒耗尽、奶毛 10 秒成熟。进食冷却和幼崽成长不受倍率影响。恢复默认按钮只恢复这四项配置。

配置复用 `gmConfig` 上行、房主 `gmApply` 校验与 `gm` 事件回流，全房间共享。动物挣脱、爱心和产出仍由房主计算并通过原动物快照同步。配置仅保留于运行内存，不写入存档；测试导致的动物状态变化正常保存。物资领取与动物生成复用既有权威 GM 动作。

# 荒岛起步任务指引

## 背景

玩家需要从早期采集自然过渡到二级工作台和皮制四件套。指引围绕现有配方提供短目标和适量奖励，手机竖屏优先，与现有 HUD 采用同一套奶油色、鼠尾草绿与程序化道具图标。

## 需求描述

- 左上角信息卡正下方显示当前任务；点击整张卡查看详情、完整任务链与奖励。触控区不小于44px，短横屏收起提示和奖励行。
- 允许提前完成，完成过的任务直接跳过，制作/采集累计量不会因为材料消耗、丢弃或装备升级而倒退。
- 本局工作台达到二级，且玩家做齐或拥有二级及以上四栏装备后，展示一次4秒毕业反馈，随后任务栏本局不再出现。无需补做早期采集。
- 设置增加“显示任务指引”。关闭隐藏任务卡、高亮、特效线和配方任务标记；继续记录进度，奖励暂存。重新开启时发放待领奖励；显示偏好跨局保留。
- 正常任务完成自动结算奖励，每项仅一次。背包满时保留待发数量，腾出空间后入包，不丢到地面。
- 旧档根据已有工具、制作记录、工作台、装备推断已完成阶段，跳过的阶段不补奖励；不提高存档版本。

## 设计方案

### 任务与奖励

| 顺序 | 任务 | 完成条件 | 奖励 |

| 2 | 制作采集工具 | 木斧、木镐 | 纤维2 |
| 3 | 收集营地材料 | 累计采集木头4、纤维6 | 树枝2、石头2 |
| 4 | 建立工作台 | 世界中放置一级或以上工作台 | 纤维3 |

二级工作台消耗4皮毛；皮制四件套合计消耗草制四件套、9皮毛、10绳线。任务链正常合计补充3皮毛、5绳线，其余仍需采集与制作。草衣、草裤当前各消耗1树枝和1纤维，草帽2纤维，草包4纤维。原料需求和配方前置直接读取 `Crafting.ts`。

### 目标、高亮与计时

- 同时只引导一个目标。采集缺少的原料时，选择距离最近且搜索可到达的对应物资，以鼠尾草浅绿地面光圈高亮；连续10秒没有获得相关物资时，显示奶油金虚线与流动光点。
- 只在采集实际入包后计数，制作奖励不冒充采集。拾取战利品也计入；皮毛可由其他来源持有量补足，玩家丢下再拾回不会重复累加战利品计数。
- 工作台配方材料不足时，先引导缺少的原料或前置配方，例如先做绳线。材料齐全后高亮满足等级的最近工作台；20秒没有开始对应制作/升级才显示引导线。
- 有多个未完成装备时优先引导材料齐全的一件。当前配方及必要的前置配方在背包/工作台列表置顶，用主题色描边与“当前任务”标记；手搓快捷卡遵循同一优先级。
- 工作台升级入口在配方列表上方，升级任务时高亮标记。
- 皮毛只引导野生羊，排除死亡、隐藏、牵引和拴住的羊；已有可到达的皮毛掉落物时优先拾取。羊移动时光圈跟随当前位置，失效目标在下一次扫描重选。
- 箭用完时先引导补充箭；丢失弓或斧子时提示补做必要工具，不回退旧任务。
- 有效采集、当前目标改变或开始对应制作/升级重置计时；死亡、游泳、拍照和关闭指引时隐藏特效。不存在可到达目标时显示继续探索/放置工作台提示。
- 目标扫描最多每秒一次；使用2米陆地网格与A*查找路线，检查网格边和首尾短段的水域，避免直接跨海或水洼。每次搜索有节点预算，复杂地形可能需要玩家移动后重新搜索；不将其作为自动移动导航。

### 表现与性能

任务卡放在状态卡的独立纵向容器中，保留原Buff排列及右上角地图预留空间。主卡约174px宽，根据剩余屏幕宽度缩小，长提示最多两行，详情可滚动。使用现有 `gameTheme` 和 `ItemIcon`；没有外部图片、模型或额外灯光。

场景特效包含一个32段光圈、一条虚线和24个实例化光点，最多3个draw call，不产生阴影，不改动物/资源原材质。任务状态以4Hz刷新；采集计数挂实际产出回调。寻路地形按需缓存，10秒失效以适应水洼冻结。系统减少动态效果偏好下关闭光圈呼吸和流动点，保留静态定位。

### 模块、联机与存档

- `src/game/quests/QuestDefinitions.ts`：任务、奖励和同步契约。
- `QuestProgress.ts`：个人权威进度、一次性奖励、毕业与旧档识别。
- `QuestObjective.ts`：当前任务的下一步、前置配方与缺料解析。
- `QuestRoute.ts` / `QuestGuidance.ts`：本地目标选择、陆地路径和特效资源生命周期。
- `QuestSettings.ts`：显示偏好的本机存储。
- `src/ui/QuestPanel.tsx` / `questRecipe.ts`：任务卡、详情及统一配方优先级。

每名 `PlayerSession` 独立持有进度。工作台等级按世界共享达标；采集、制作、装备证据及奖励按玩家分别结算。`quests` 是个人存档的可选字段，保存累计采集、制作次数、已完成/已结算任务、历史工作台等级和待发奖励；`SAVE_VERSION` 保持32。

客人通过 `questGuide[boolean]` 上行显示偏好，房主校验参数并控制其待发奖励；新接入客人等待本机偏好同步后才发奖。个人任务视图随 HUD 差分回流，高亮和引导线只在本人的客户端从世界镜像计算，不广播特效。网络协议升到27，避免新旧客户端动作契约混用。断线重连按既有稳定会话身份恢复，奖励由已结算标记和待发数量保证不重复。

# 荒岛起步任务指引

## 背景

玩家需要从早期采集自然过渡到二级工作台和皮制四件套。指引围绕现有配方提供短目标和适量奖励，手机竖屏优先，与现有 HUD 采用同一套奶油色、鼠尾草绿与程序化道具图标。

## 需求描述

- 左上角信息卡正下方显示当前任务，点击卡片主体自动前往当前引导目标，再点一次停止；右上角独立44px按钮切换紧凑展开与最简折叠，不打开详情弹窗。默认紧凑展开，目标用棕金色文字与加粗数量表示未完成，绿色加勾表示完成；显示“进行中 / 制作中 / 已完成”。折叠仅保留任务名、已完成目标项数与待发提示，切换任务不自动展开。短横屏隐藏引导文字。
- 允许提前完成，完成过的任务直接跳过，制作/采集累计量不会因为材料消耗、丢弃或装备升级而倒退。
- 玩家实际放置或升级工作台达到二级，且玩家做齐或拥有二级及以上四栏装备后，展示一次4秒毕业反馈，随后任务栏本局不再出现。喝水、石剑、添柴、烤兽肉也需完成，早期采集无需补做。已毕业旧档保持隐藏。
- 设置增加“显示任务指引”。关闭隐藏任务卡、高亮、特效线和配方任务标记；继续记录进度，奖励暂存。重新开启时发放待领奖励；显示偏好跨局保留。
- 正常任务完成自动结算奖励，每项仅一次。背包满时保留待发数量，腾出空间后入包，不丢到地面。
- 旧档根据已有工具、制作记录、个人工作台操作记录、装备推断已完成阶段，跳过的阶段不补奖励；不提高存档版本。

### 目标、高亮与计时

- 同时只引导一个目标。采集缺少的原料时，在搜索预算内比较实际路线长度，选择路线更短的可到达对应物资，以鼠尾草浅绿地面光圈高亮；连续10秒没有获得相关物资时，显示奶油金虚线与流动光点。
- 采木目标只选择成熟的非果树，保留果树作为食物来源；仍可引导拾取掉落木头。
- 手搓配方材料齐全时提示停下点击快捷制作卡片，工具、草制装备、工作台和火堆无需打开背包制作。设施做好后仍沿既有使用/放置流程操作。任务卡片绕过本局点击历史，使用六枚暖金环绕光点，关闭指引隐藏装饰且继续暂停发奖，详见 [弹出卡片](prompt-cards.md)。
- 只在采集实际入包后计数，制作奖励不冒充采集。拾取战利品也计入；皮毛可由其他来源持有量补足，玩家丢下再拾回不会重复累加战利品计数。
- 工作台配方材料不足时，先引导缺少的原料或前置配方，例如先做绳线。材料齐全后高亮满足等级的最近工作台；20秒没有开始对应制作/升级才显示引导线。
- 有多个未完成装备时优先引导材料齐全的一件。当前配方及必要的前置配方在背包/工作台列表置顶，用主题色描边与“当前任务”标记；手搓快捷卡遵循同一优先级。
- 工作台升级入口在配方列表上方，升级任务时高亮标记。需要前往工作台且靠近满足等级的工作台时，工具入口持续显示环绕粒子、不因闲置淡出；面板中可制作的任务配方（含前置配方）及可执行的任务升级按钮也显示同款六枚光点。缺料时保留任务标记，按钮不播放粒子；开始操作、任务结束或关闭指引后停止，减少动态效果时静止。
- 皮毛只引导野生羊，排除死亡、隐藏、牵引和拴住的羊；已有可到达的皮毛掉落物时优先拾取。羊移动时光圈跟随当前位置，失效目标在下一次扫描重选。
- 丢失剑或斧子时提示补做必要工具，不回退旧任务。
- 有效采集、当前目标改变或开始对应制作/升级重置计时；死亡、游泳、拍照和关闭指引时隐藏特效。不存在可到达目标时显示继续探索/放置工作台提示。
- 目标扫描最多每秒一次；优先检测直达路线，否则使用2米八方向陆地网格与欧氏距离A*查找路线；对可直达的路径段拉直，去掉多余折角。所有线段按不超过0.5米间隔检查水域，避免直接跨海或水洼；拉直后按不超过0.5米间隔重新采样贴地。候选目标按直线距离下界筛选，并比较已找到路线的实际长度。每次搜索有节点预算，复杂地形可能需要玩家移动后重新搜索；自动移动另用包含静态障碍的路线，目标仍与引导一致。

火堆制作消耗燧石1、木头2。营火、添柴和烤肉位于工作台及装备任务之前，添柴奖励兽肉1供烤肉教学使用，后续狩猎另奖励兽肉2；无需烹饪台。缺燃料先找木头/树枝，兽肉耗尽则找羊。火堆高亮与20秒引导线复用场景效果。靠近可执行当前任务操作的火堆时，火堆工具入口显示同款六枚环绕光点且不因闲置淡出；添柴步骤在面板优先推荐的一种现有燃料按钮上描边并播放环绕粒子（优先木头/树枝，无则选择其他燃料），烤肉步骤则在点燃火堆后的兽肉“烤”按钮上播放。任务关闭、完成、开始烤制或操作不可执行时停止，减少动态效果时静止；烤制中暂停引导计时。成功添柴与实际烤熟分别记录，取消或中断不算烤熟。

烤兽肉之后的饮水任务复用浅水导航，抵达浅水停下自动喝水，房主在完整喝完一轮后计数；提前喝水也记录，中断不算完成。饮水任务导航受显示指引开关控制；已毕业旧档不补做。口渴值耗尽时，[缺水求生引导](thirst-guidance.md) 优先占用场景路线和圆环，任务卡与进度照常；求生引导退出后任务特效按正常空闲时间重新显示。

### 点击任务自动前往

点击卡片主体启动 `QuestAutoMove`，状态显示“前往中”，再次点击停止；右上角折叠按钮独立处理，不触发移动。移动只到当前引导目标，任务变化后停止，不自动串行完成整条任务链。当前目标为手搓制作或放置提示、没有空间目标时显示现有提示，不虚构目的地。

每秒重新规划最多一次，复用有预算的 QuestRoute，但额外避开树、大石和围栏，并为转弯保留余量。资源/羊在约1.25米的可达邻接点停下，工作台/火堆约1.5米；喝水路径允许可饮用浅水，进入浅水后停止并由既有喝水系统处理。不可达或连续2秒未前进时停止并提示，保留玩家碰撞结算，不传送、不穿海。到达不会自动打开工作台或代按制作按钮，既有站定采集/狩猎规则继续生效。

触摸摇杆、键盘移动、再次点击任务卡、目标变化/失效、开始任务制作、死亡、睡眠、游泳、拍照或关闭指引均取消自动移动。自动输入与手动输入分开，停止发送零向量。寻路仅在本地运行；客人沿既有普通 input 上行、房主权威移动及姿态对账执行。路线和“前往中”表现不入存档、不广播，不改变 SAVE_VERSION。

### 任务补羊

- “收获第一张皮毛”进行中，玩家画面内没有活着、未隐藏且未被牵引/拴住的羊时，在屏幕外补一只普通野生羊；该阶段最多成功补一次。
- “换上探险装”开始及每完成皮衣/皮裤中的一件后，重新累计尚未完成装备的皮毛成本。背包皮毛不足时补一只，每个装备完成组合最多成功补一次；材料已经够用或任务完成后不补。
- 房主每秒检查，关闭指引、死亡、游泳、拍照或缺少新鲜视域时不为该玩家补羊。每次在12～48米范围内最多抽样96个点，筛选草地、设施/动物间距和所有玩家画面，再用有预算的陆路寻路选择可达点；屏幕边缘额外保留整羊及3米球形余量。找不到合法点时稍后重试，不强行刷进水里或画面内。
- 使用各端实际正交相机视域，客人每秒上报一次矩阵，房主校验并在2.5秒或玩家移动5米后视作过期；其他玩家视域未知时保守避开其周围60米。补充的羊复用既有野生羊AI、战利品及动物姿态同步，不直接发皮毛。
- 已成功补充的检查点保存在个人任务可选 `sheepSupport` 字段，旧档缺省为空；连续刷新、重连或读档不会重复发放同一检查点。`SAVE_VERSION` 不变。

### 完成与奖励反馈

房主每次结算将新完成任务名称和实际入包奖励数量写入可选 HUD feedback，保留4秒，窗口内连续完成或分批到账合并累计并增加反馈序号。角色头顶显示“任务完成 ✓”，采用13px暖白金色文字与轻微暗色文字阴影，无背景、边框或底板。独立投影角色头顶（脚底上方1.85米），文字底边距该位置16px，逐帧跟随并限制屏幕边缘。每条播放1.6秒：前0.2秒淡入上移4px，停留1秒，最后0.4秒上飘10px并淡出。客户端对累计任务名称去重并依次播放，反馈窗口结束不截断队列；仅奖励到账不弹完成提示。不展示任务名称、数量或奖励文字；实际播放期间临时隐藏自言自语。奖励使用现有道具图标外观，从任务卡中心沿弧线缩小飞入背包按钮，落点轻微闪亮；累计反馈只对本次新增实际到账数量播放，同种最多3个飞行道具，同时最多18个，避免堆满手机屏幕。动画使用 DOM transform/opacity，不创建额外 WebGL 上下文。毕业时任务卡保留至反馈结束以提供飞行起点，待发奖励仍保留卡片。折叠后以最简卡中心为起点，不自动展开；死亡、拍照与关闭指引时不播放奖励动画。减少动态效果偏好下头顶文字仅淡入淡出、不位移，并将飞行改成背包位置短暂淡出。背包满时仅在任务卡保留待发文字，腾出空间后实际到账才飞入。旧档推断跳过不触发反馈，库存及奖励结算不受动画影响。

### 表现与性能

任务卡放在状态卡的独立纵向容器中，保留原Buff排列及右上角地图预留空间。主卡展开约154px宽，折叠118px宽，与状态卡同宽；根据可用屏幕宽度限制展开尺寸。卡片主体与独立折叠按钮触控区域至少44px，主体点击自动前往/停止，右上角按钮切换折叠。标题12px，目标数量11px加粗，提示10px最多两行。无进度条、目标边框和卡内奖励明细，通过文字色彩区分状态。使用现有 `gameTheme` 和 `ItemIcon`；没有外部图片、模型或额外灯光。

场景特效包含一个32段逐顶点贴合地形的光圈、一条虚线和最多24个实例化光点，最多3个draw call，不产生阴影，不改动物/资源原材质。任务状态以4Hz刷新；采集计数挂实际产出回调。寻路地形按需缓存，10秒失效以适应水洼冻结。光圈按周边各顶点的地形高度抬高0.2米，使用透明叠加避免坡面或目标模型遮住部分圆环；圆环以约4秒周期做±10%径向呼吸并同步明暗变化，逐帧重新采样缩放后的周边地形，避免埋坡。光点适度加大并透明叠加，以目标为基准按固定2.2米间距排列，正常流速0.65米/秒；相位按固定间距累计，不以变化中的路线长度取余。最多24个点覆盖靠近目标的路段，短路线只保留实际容得下的点，首尾0.45米范围渐缩显隐。移动时按玩家到目标的水平直线距离分档：60米以内每帧做直达检测，可通行时直接重新采样整条直线；超过60米或直线路段不可通行时沿用最近一次完整寻路，仅让起点跟随并剔除已走过的路段，允许保留折角。任务路线不可穿水，喝水路线允许可饮用浅水。完整目标选择和寻路仍最多每秒一次，分档不触发额外A*。几何缓冲区复用，光点相位跨模式切换连续。减少动态效果偏好下使用约6秒周期、±3.5%的轻微呼吸，光点降速至0.25米/秒。

### 模块、联机与存档

- `src/game/quests/QuestDefinitions.ts`：任务、奖励和同步契约。
- `QuestProgress.ts`：个人权威进度、一次性奖励、毕业与旧档识别。
- `QuestObjective.ts`：当前任务的下一步、前置配方与缺料解析。
- `QuestRoute.ts` / `QuestGuidance.ts`：本地任务目标选择和路径；`GuidanceEffect.ts` 管理任务与求生共用的特效资源生命周期。
- `QuestSettings.ts`：显示偏好的本机存储。
- `src/ui/QuestPanel.tsx` / `questRecipe.ts`：折叠任务卡及统一配方优先级；`QuestFeedback.tsx` 显示头顶“任务完成”，`QuestRewardFlight.tsx` 显示任务卡到背包按钮的奖励飞行。

每名 `PlayerSession` 独立持有进度。工作台等级只按本人成功放置或升级后的最高等级达标；采集、制作、装备证据及奖励按玩家分别结算。`quests` 是个人存档的可选字段，保存累计采集、制作次数、已完成/已结算任务、个人历史工作台操作等级、可选火堆操作计数、可选饮水轮数 drinks（旧档默认为0）、毕业标记和待发奖励；`SAVE_VERSION` 保持32。

客人通过 `questGuide[boolean]` 上行显示偏好，房主校验参数并控制其待发奖励；新接入客人等待本机偏好同步后才发奖。个人任务视图随 HUD 差分回流，高亮和引导线只在本人的客户端从世界镜像计算，不广播特效。网络协议为30，避免新旧客户端动作契约混用。断线重连按既有稳定会话身份恢复，奖励由已结算标记和待发数量保证不重复。

火堆与工作台同时靠近时，可执行的当前火堆任务优先显示火堆入口，避免工作台遮蔽任务入口；其他情况沿用原设施优先级。

### 设施任务结算

火堆放置任务只记录本人成功放置火堆的操作；工作台任务只记录本人成功放置或升级的等级，不读取世界设施数量或最高等级。遗迹、村落生成设施和世界快照恢复不推进任务，其他玩家的操作也不代为完成。玩家挖走预设设施后重新放置，或实际升级预设工作台，计入本人的操作进度。添柴、烤肉和制作可使用预设设施，仍须本人完成相应操作。放置火堆任务始终引导制作或放置，不因世界已有火堆改为引导添柴。

沿用现有个人任务存档字段，不提高存档版本；保留旧档已记录的等级、完成状态及奖励结算记录，不回收奖励。没有任务记录的旧档不再从世界设施推断进度。

# 可乐外观选型
## 背景
以可乐的实拍照片为辨识特征参考，允许明显美化与卡通化，参考薯条简洁、圆润可爱的画风重新设计模型与图标。可乐不是短腿猫，保留正常猫咪腿长，不照搬薯条体型，也不受现有可乐模型轮廓限制。
## 需求描述
提供临时、离线可打开的 HTML，分别选择模型与图标。保留灰白花色、金眼睛、白鼻梁、不对称嘴边深色花纹和灰色尾巴。
## 设计方案
`scripts/cola-preview/` 提供三个独立重建的程序化 Three.js 模型和三个重画的 SVG 图标，包含现有可乐及薯条对照、拖动旋转和动作切换。材质为高粗糙度低面数黏土风格，设备像素比上限为 2。正常腿长在三套候选中均保留。

- A「棉花糖」：横向包子脸、较小耳朵、大圆眼与闭嘴微笑。
- B「元气可乐」：较窄脸型、舒展大耳、修长身体与露舌笑脸。
- C「云朵小狮子」：蓬松双颊、奶油围脖与毛绒玩偶轮廓。

模型、图标与样式参数按职责分文件。灰白毛色通过模型表面的顶点色表现，不再使用重叠色块球体作为脸部花纹。模型具备独立程序动画，支持眨眼、歪头、呼吸、摆尾及走路、扒拉、舔毛、睡觉预览；骨架节点仍遵循 `CompanionModel` 接口。保留灰白毛、金色虹膜、深色嘴边斑纹，同时允许暖白毛色、柔和灰色、圆瞳、轻腮红和更有亲和力的嘴型。

模型采用与薯条接近的简单低面风格：身体以 7×5 分段球体、头部以 8×5 分段球体构成，耳朵用低面锥体，尾巴仅使用 6 段管体。移除爪缝、胡须、眉毛、腮红和第二眼睛高光，减少毛簇，保留正常腿长、三种头身比例、灰白花纹、金眼睛与嘴边深色斑纹。SVG 图标独立保留现有设计。

选型页提供 10%–150% 连续缩放，以及 15%、25%、50%、100% 快捷档位，使用正交相机缩放；切换候选及薯条参考时保持相同比例，窗口变化不重置缩放。比例表示相对预览大小，不宣称等同于游戏内实际屏幕尺寸。滑杆与按钮按至少 44px 触控高度设计，优先观察缩小后的轮廓与辨识度。

运行 `node scripts/cola-preview/build.mts` 生成 `dist/cola-preview/index.html`，脚本与 Three.js 内嵌，不依赖网络或本地服务器。选择结果可复制发回；本地选择记录仅为方便再次打开。浏览器无法直接删除本地 HTML，用户选定并应用后，由开发端删除临时生成文件和选型源码，清理选型记录逻辑。

本次仅选型，不接入正式游戏，不改变存档、图鉴机制或网络协议；正式应用时需统一房主与客人的模型及各处伙伴图标，并维护相关文档。图鉴现有名称、获取方式、用途与解锁条件不变。

# 可乐外观
## 背景
可乐是灰白猫咪，参考实拍的花色与嘴边斑纹，采用与薯条协调的简单低面可爱画风，保留正常猫咪腿长。
## 需求描述
- 模型采用低面「元气可乐」：舒展猫耳、圆脸、金色圆眼与开心小嘴。
- 伙伴图标采用「弯眼甜笑」：右倾 13°、左上爱心，与左倾、右上爱心的薯条配对。
- 开始界面帐篷彩蛋采用「笑眯眯探头」：正头、无爱心，无白爪，保持原有探头时机和随机规则。
## 设计方案
`src/game/companions/ColaModel.ts` 用 Three.js 基础几何体构建，头部 8×5 分段、身体 7×5 分段，锥体耳朵、六段管体尾巴。灰白花纹使用顶点色；合并静态部件后 11 个网格、1572 个三角形。材质为高粗糙度、flatShading 黏土风格，不加载外部模型或纹理。

程序动画覆盖待机、走路、扒拉、舔毛、睡眠、游泳、嗅闻、伸展与甩水，保留眨眼、呼吸、歪头与摆尾。房主与客人共用模型，由原有状态决定动作；外观动画不结算奖励，不增加网络字段，存档版本与网络协议不变。

`src/ui/icons/ColaFace.ts` 共用笑脸图形；`ColaIcon.ts` 添加右倾与左侧爱心，所有引用 `COLA_ICON` 的角色页、开局选择与图鉴同步更新。`IslandCatHead.tsx` 使用同一笑脸，以帐篷原位置和尺寸绘制正头、无爱心彩蛋，独立 clip ID 避免 SVG 引用冲突。临时选型源码及生成 HTML 在应用后清理。

图鉴生物名称、获取方式、用途与解锁条件均不变；只更新共用图标。由用户本地验证手机小尺寸、联机模型表现及开始界面彩蛋。

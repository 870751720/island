# 开始界面与死亡返回

## 背景
游戏开始页需要呈现荒岛求生的氛围，并承载单人存档、联机与玩家形象入口。手机竖屏优先，同时适配电脑与手机横屏。

## 需求描述
- 使用「晴日小岛」视觉：晴空蓝渐变背景、立体奶油色标题、雾海蓝主按钮与奶油色操作面板，贴近游戏 HUD 和低多边形黏土质感。
- 标题下展示纯代码 SVG 小岛：太阳、树木、帐篷、篝火和岸边钓鱼小人。保留左侧一簇浆果丛，火堆旁不放浆果丛；帐篷下不铺路，不叠加暖色光晕，不提供主题或光感切换控件。
- 保留开始游戏、继续游戏、开新档、重开结算确认、荒岛传承、设置形象、创建房间、加入房间与断线提示。
- 加入轻量入场动画、海面水纹、海鸟漂移、火焰跳动，以及约 12 秒一轮的抛竿、等待、咬钩、提竿收鱼循环。
- 提供海浪环境声和按钮拨弦提示，独立开关持久化；首次触摸后启动声音，遵循浏览器播放限制。

## 设计方案
### 界面与响应式
- `src/ui/StartScreen.tsx` 保留存档和档案流程，只负责菜单状态与入口编排；表现拆分至 `src/ui/start/`。
- `styles.ts` 定义响应式视觉。约 375px 手机将标题、小岛和操作卡片居中纵向排列；电脑宽屏和低高度横屏采用左侧标题与小岛、右侧操作卡片的两列布局。短屏缩小场景并允许纵向滚动，保留安全区，所有按钮触控高度至少 44px。
- `start/palette.ts` 为开始页、创建/加入房间、形象设置与荒岛传承提供同源晴空蓝底色（`#d2e3e9` → `#a8c8db` → `#8cb4ce`）；主操作统一使用雾海蓝（`#6f93ab` → `#496e87`），文字奶油色。`menuSurfaceColors` 统一奶油面板、鼠尾草文字、浅蓝选中态与控件阴影，避免子界面保留旧配色。
- 标题用分层文字阴影表现厚度；操作区采用奶油与鼠尾草绿渐变、浅色边框和底部阴影。主按钮与联机按钮按压时下沉、缩小并收紧阴影，主按钮悬停时箭头轻移。

### 小岛插画与循环垂钓
- `IslandScene.tsx` 编排场景，`IslandScenery.tsx` 复用树木并绘制浆果丛，`IslandFisher.tsx` 绘制草帽小人、钓竿、鱼线、浮漂、水花和鱼。全部为内联 SVG，不依赖图片、外部模型、SVG ID 或额外渲染引擎。
- `sceneStyles.ts` 的 CSS 时间轴让浮漂轻晃、咬钩下沉、身体后仰并提鱼；独立水纹、海鸟与火焰动画增加环境细节。岛屿固定，不整体漂浮。选择减少动态效果时保留静态垂钓姿态，隐藏收鱼、水花及提竿鱼线。
- 插画使用 `aria-hidden`、不可聚焦和 `pointer-events:none`，不新增点击入口；打开形象、传承、重开确认弹窗或页面隐藏时暂停动画。页面可见后恢复，组件卸载时移除可见性监听。

### 形象设置与联机大厅
- `start/formStyles.ts` 统一子界面样式：晴空蓝背景、奶油黏土卡片、浅蓝选中态和雾海蓝主按钮。卡片使用浅色厚边框、底部落差与内高光，标题使用粗体无衬线字；图标放在圆角浅蓝徽章中，按钮保留按压下沉反馈，不增加重模糊或额外渲染器。
- 形象设置以岛民档案呈现，保留昵称长度校验、性别选择、首次确认和修改保存；输入框关联标签，性别按钮提供选中状态语义。
- 创建与加入房间采用同一大厅框架，手机单列、电脑宽屏左侧邀请文案与右侧操作卡片；短屏允许完整滚动，安全区留白，按钮至少 44px。
- 邀请卡突出五位房间码，保留二维码与分享操作；队友区显示已靠岸人数，连接消息使用状态提示。保留继续旧岛、房主开局条件、客人昵称设置和所有返回清理逻辑。
- 荒岛传承共用同一套浅色主题，心得计数、求生之根、天赋节点和详情均使用奶油卡片；已学习路径、等级圆点与选中描边使用海蓝色。保留三分支九节点、三级预览、前置限制、费用、禁用态与单机加成规则，不改变树状布局和触控区域。
- 入场与等待动画遵循减少动态效果设置；子界面不增加 WebGL 场景或生成图资源。

### 背景与声音
- 开始页仅使用 CSS 背景、SVG 图标与小岛插画，不创建 WebGL 渲染器，不加载装饰模型或运行 3D 动画循环。
- `useMenuAudio.ts` 独立管理 Web Audio：滤波噪声与缓慢音量调制模拟海浪，两个衰减正弦音构成按钮提示。尊重已有音乐/音效音量，菜单开关用 `island-menu-sound` 单独存储。页面隐藏时暂停，卸载时关闭上下文，避免与游戏音频重叠。

### 游戏和联机流程
- `GameCanvas.tsx` 继续在开始页、房主大厅、客人大厅与游戏之间路由。开始页不创建 Game 实例，不读写世界状态，不改变存档版本。
- 房主与客人入口沿用现有大厅与同步链路；菜单钓鱼、环境动画和音频属于各端本地表现，不调用游戏钓鱼结算、不产生物品、不上行动作、不发快照、不广播事件。首次档案设置、继续存档、开新档结算、传承可见条件和离线渠道隐藏联机入口的规则均保持原样。
- `DeathScreen.tsx` 确认后经 `GameplayUI.onExit` 返回开始界面；游戏初始化仍先绘制「正在登上小岛…」遮罩，世界构建和相机落位完成后淡出。

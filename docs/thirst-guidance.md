# 缺水求生引导

## 背景

玩家口渴耗尽时需要优先找到能喝水的浅滩，避免任务路线分散注意力，也避免停在岸边却不知道需要再向前一点。

## 需求描述

- 主线“先喝一口水”位于“烤一份兽肉”之后，也启用同一浅水导航，受任务指引开关控制；水洼或净化器实际完成一轮饮水后由房主记录个人进度。中断不计数，提前完成有效。

- 口渴值 `thirst <= 0` 时立即开启非任务引导，优先级高于任务路线和目标圆环；不等待任务的10/20秒空闲计时。
- 不受“显示任务指引”开关和任务毕业状态限制。口渴恢复至正数后退出，任务指引恢复正常计时。
- 引导至可到达的水洼浅水饮水点，排除海水、冻结水洼和深水；没有可达目标时隐藏路线，不退回任务引导。
- 距目标1.5米内、仍在岸上且未采集时，持续满足条件后通过自言自语提醒再向浅水走一点。提供20句台词，一轮抽取内不重复，每次此类提醒至少间隔10秒。
- 已进入可饮用浅水或正在喝水时不再提示前进。死亡、拍照和游泳时隐藏求生特效与靠近提示。

## 设计方案

### 路线与表现

`ThirstGuidance` 管理本地求生目标与接近判定，`GuidanceEffect` 共用任务引导的贴地圆环、虚线和匀速光点。Game 先更新求生引导，再把接近状态交给自言自语系统，并用求生激活状态抑制任务特效，同屏最多显示一套引导。

目标与完整寻路每秒最多扫描一次；移动时距目标不超过60米且可直达则每帧更新直线（允许饮用浅水），超过60米或被海水/深水阻隔则沿用完整寻路并让起点跟随。每次目标扫描中，每个水洼沿24个方向从外围以0.25米间隔向内寻找水深0.08～0.45米的候选点。复用有节点预算的八方向寻路与路径拉直，允许陆地和可饮用浅水，不穿海或深水，比较搜索预算内路线长度。

`WaterAccess` 与玩家游泳共用0.6米水深阈值；`WaterSystem` 和求生引导共用浅水饮用判定。到达后仍按既有规则停下、停止其他作业并自动喝水，不新增触屏按钮。

### 自言自语

`drinkCloser` 位于普通触发规则最前，持续条件沿用2秒防抖，独立冷却10秒；发出前与上一句普通/强制台词至少相隔10秒，发出后重置全局计时。其他普通台词保留20秒间隔。20句使用既有牌堆抽取机制，不通过强制发言绕过冷却。

### 联机与存档

房主与客人分别依据本人的口渴状态和本地地形镜像计算路线、接近提示及特效。客人口渴取既有玩家快照，移动沿既有移动同步；喝水恢复和喝水事件继续由房主 WaterSystem 权威结算并经既有快照回流。路线与台词不上行、不广播、不入档，主线进度随个人 HUD 回流，可选 drinks 字段随任务存档保存，旧档缺省为0；任务序号和新增 drink 引导契约使用协议30，SAVE_VERSION 不变。

### 喝水终点提示

求生与任务喝水引导在目标浅滩上方显示“喝水”，屏外沿目标方向显示在安全边缘。喝水引导优先于普通任务，同一时刻只显示一个终点提示；开始喝水、到达可饮用浅水或原引导隐藏时文字同步隐藏。

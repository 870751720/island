# 出生点北侧饮水水洼

## 背景

新手喝水任务不应要求玩家远距离寻找随机水洼,需要在出生点附近提供稳定淡水。

## 需求描述

- 仅新档增加一处水洼,洼心位于主岛出生点正北（世界坐标 -z）30～35 米,优先 32.5 米。玩家到靠近出生点一侧的浅水岸边即可喝水,无需走到洼心。
- 从出生点沿正北陆地能够走到水深 0.08～0.45 米的饮水点,中途不隔海或深水。保持现有站定自动喝水、任务指引与奖励机制。
- 固定水洼不结冰,冬季新档也能就近完成喝水任务。
- 已有旧档不补刷、不改变地形。新档生成后保存水洼,重载、转联机和客人加入均恢复同一处水洼。

## 设计方案

- `StarterPond.createIslandWorld` 将新档选址与恢复分开。先生成原有地形并寻找主岛出生点,依次检查正北 32.5、35、30 米处;水洼半轴为 7.5/6.5 米,保留轻微不规则轮廓。外围通过 `PondPlacement` 的完整干岸检查,与其他水洼外接圆保留 2.6 米间距。
- 水位以周围最低地势约束,最低为海面以上 0.35 米,洼底沿用 `PondBasin`。新水洼在原有随机水洼之后加入,随后生成最终地形、水面和水深纹理;资源、设施和动物均在最终地形上初始化。
- 最终三角网格上重新确认出生点与水洼的相对位置,沿正北每 0.25 米采样检查浅水饮水路径。若候选岛不满足要求,新档确定性重选种子,最多八个候选后使用验证过的种子 42 兜底;失败显式报错,不交付缺少饮水点的新档。废弃的候选地形释放几何体、材质和纹理。选址只在首次新建世界时执行。
- `SaveData.starterPond` 为可选水洼参数,房主记录最终地形种子并保存完整参数。旧档缺省时直接生成原有地形,不进入新档选址。`SAVE_VERSION` 保持不变。
- 联机欢迎包的完整存档携带该字段,客人直接按最终种子与参数重建,不自行选址。协议 42 阻止不支持固定水洼的旧客户端加入。喝水仍由房主权威结算,客人动作、玩家数值快照和任务进度沿用现有同步,无需新增动作或逐帧事件。
- `node scripts/test-starter-pond.mts` 验证十个种子的正北距离、可饮用路径、不结冰、存档/欢迎包恢复一致性和旧档地形逐顶点不变;无需浏览器或新增逐帧计算。

# 死亡掉落与复活提示
## 背景
自动复活应保留工具积累，并用简短、温和的提示帮助玩家了解可捡回的物品。
## 需求描述
- 海里或水洼里死亡产生的地面物品移到距死亡位置最近的干燥岸边；岸边随机散落也不能落回水中，陆地死亡仍在原地附近掉落。
- 按 `Items.itemCategory` 的“工具”分类豁免死亡掉落，包括斧、镐、铲、锄、鱼竿、弓和剑；已拥有工具保持原等级，背包内工具原数量保留。
- 箭矢和鱼饵属于独立弹药，继续按原规则掉落。背包普通物品、植株和穿戴装备的掉落概率以及其余携带重置规则保持现状。
- 复活倒计时界面显示“工具和等级都为你保留着”。实际掉落不超过 3 类时直接展示图标、名称、数量；超过 3 类仅展示类别总数，不要求展开、翻页或滚动列表。
- 没有实际掉落时显示“这次没有物品掉在地上”，不暗示其余携带也得到保留。有掉落时温和提示回到倒下的地方捡回。
- 庇佑、复活石免掉落流程不展示本次普通死亡摘要；无复活资格的求生结算沿用战绩界面。
## 设计方案
`DropSystem.deathDropper` 为同一次死亡选取共用落点，使用实际地形高度与当地海面／洼面比较，保留 0.05 米高度余量。`NearestDryPoint.ts` 以 1 米网格覆盖整岛比较水平距离，再以 0.25、0.0625 米步长局部细化最近候选，得到采样精度内的最近干地；找不到候选时回退安全出生点。每件物品随机偏移后重新检查干地，不满足则留在共用落点。选点只在权威死亡结算时执行，不进入逐帧循环。
`DeathLoot.ts` 负责权威掉落结算、同类合并、最多三类的摘要及复活携带重置；摘要只包含实际生成的地面物品，不将未掉落但随重生清空的物品计入。
`PlayerSession.deathLoot` 保存本次临时摘要，房主经本人 HUD 快照下发 `deathLoot`；地面物品仍经世界增量同步。客人不计算随机数或掉落结果。复活时清空摘要，存活 HUD 始终返回 null。
`DeathLootNotice.tsx` 复用暗场主题，以小屏为基准限宽 320px、自动换行；不添加确认按钮、不延长三秒倒计时。死亡界面内容在横屏高度不足时可以从顶部滚动。复活文案不再固定声称返回出生点，落点沿用营地设施优先级。
摘要不持久化，不新增网络动作或事件，存档版本不变。旧存档中的工具掉落物仍可拾回，保留既有等级恢复逻辑。

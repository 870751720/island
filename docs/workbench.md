# 工作台合成与放置

## 背景

游戏缺少中期设施类目标。工作台作为全局唯一的设施,给玩家一个采集→积累→建造的第一个完整循环,并为后续更多合成配方打基础。

## 需求描述

- 四级设施配方包含狗窝（海岛草棚）：木头 ×10 + 布料 ×5 + 铁锭 ×3，详见 `docs/doghouse.md`。

- 配方:**2 石头 + 1 树枝**合成工作台。
- 弹卡条件:材料满足、场上(全局)没有工作台、当前位置可摆放。
- 点击卡片后玩家开始定时制作(站定敲打,复用合成动作与木屑特效),期间移动/游泳会中断。
- 制作完成后扣除材料,并在玩家**原位**放置工作台模型。
- 摆放限制(不满足时无法发起制作,卡片也不显示):
  - 玩家在水中(游泳或处于水洼范围及水边)时不能制作;
  - 脚下附近(1 格内)已有树、石头等资源点占位时不能制作。

## 设计方案

- `src/game/entities/Workbench.ts`:程序化拼装的工作台模型(黏土低多边形风格:木桌板 + 四条腿 + 桌上小砧石),构造时加入场景。
- `src/game/systems/WorkbenchSystem.ts`:全局唯一工作台系统。
  - `canPlace()` 校验不在水中/水边、地形露出水面、周围 1 格内无资源点;
  - `canStart()` = 未拥有 + 材料齐(`WORKBENCH_COST`)+ `canPlace()`;
  - `update()` 与 `CraftingSystem` 同款定时敲打逻辑,移动/游泳中断,完成后扣材料并在玩家位置生成 `Workbench`。
- 配方常量 `WORKBENCH_COST` 放在 `Crafting.ts`,与工具配方同处维护。
- `CraftPrompt` 在工具卡片下方追加「手搓工作台」卡片;任一合成进行中时隐藏所有卡片。
- `HudSnapshot` 新增 `canCraftWorkbench` / `workbenchCrafting` / `workbenchProgress`;头顶提示与进度圆环复用现有 indicator 通道,制作中显示「制作中:工作台」。
- 制作期间采集、进食、喝水均让位(与工具合成一致)。

### 工作台制作面板(2026-08-29 迭代)

- 绳线、鱼竿改为**工作台专属配方**(`Recipe.station = 'workbench'`),不再出现在手搓卡片中;斧子、镐子仍为手搓(`station = 'hand'`)。
- 玩家进入工作台范围(距离 < 2.2)时,右中侧工具按钮自动变为工作台图标并持续脉冲缩放(与工具切换提示同一动画),点击弹出工作台制作面板(无工具时也会显示该按钮)。
- 面板列出当前等级解锁的工作台配方。可重复制作的材料、设施和装备不因已制作过或材料不足而隐藏；永久工具保持原有已制作且已拥有时隐藏的规则，未制作过或任务指定的工具仍可查看。任务配方优先，其次可制作优先，再按配方分类排序。
- 保持原工作台面板尺寸（宽度 `min(calc(100vw - 56px), 400px)`、最大高度 `90vh`）、行间距、内边距及数量/制作按钮尺寸。配方沿用左侧图标、中间名称与材料两行、右侧数量及制作按钮的紧凑横向布局；升级仍位于列表上方。不增加说明栏、筛选栏或材料多行卡片。
- 材料压缩在原材料行中：`木头 3/8 缺5 · 绳线 2/2 ✓`，不足项优先、暖红色突出缺口，足够项使用柔和正文色和勾号。所选份数的材料总需求直接显示，数量不足仍至少展示一份需求。升级复用相同展示。
- 名称与材料仅在实际溢出时启动跑马灯，缓慢往返、两端停留，边缘轻微渐隐；内容不溢出则静止。`ResizeObserver` 处理屏幕旋转与内容宽度变化，组件卸载释放观察器；数量/库存变化后按新文本重新测量和播放。文本裁切在自身区域，不能撑大行高、挤压按钮或超出卡片。系统开启减少动态效果时停止自动滚动，允许横向滑动查看全文。
- 材料统计包含当前玩家背包与可消耗的穿戴装备，不包含箱子或队友库存；二/三级工具额外列出前一级工具需求。按钮分别提示「已拥有」「需前一级工具」「材料不足」。
- 可批量配方用「份」表示制作次数，明细直接显示所选份数的总需求。数量上限仍为当前材料可制作上限，材料不足时至少显示一份需求并禁用制作与加减；库存下降时收回超出的数量。单份多产物继续在名称中标明产量（如「箭 ×5」）。单件设施和装备不显示数量调节。
- 确认制作后沿用关闭面板、逐份排队完成与扣料的流程。
- `src/ui/MaterialRequirements.tsx` 负责可复用的材料与工具前置明细；`OverflowMarquee` 负责单行溢出测量和滚动；`WorkbenchPanel` 负责配方可见性、份数与原有布局。联机按各自 HUD 快照派生显示，制作/升级仍由房主权威结算；不新增网络动作、事件、快照字段或存档字段。
- 排队制作走 `CraftingSystem`,头顶提示显示「制作中:绳线 2/5」;移动/游泳或离开工作台范围会中断整个队列。

### 三级升级材料与冒险家的经验书(2026-09-06 迭代)

- 工作台升级材料改为按目标等级区分(`Crafting.ts` 的 `WORKBENCH_UPGRADE_COST`):升 2 级为 4 皮毛;升 4 级需要冒险家的经验书 ×5 + 铁锭 ×20 + 布料 ×10;**升 3 级需要 1 本冒险家的经验书 + 20 石头 + 20 木头 + 5 绳线**。
- 新道具「冒险家的经验书」(`adventureBook`):猎杀狼有 30% 概率额外掉落(在房主端 `Wildlife.lootOf` 随机判定,掉落物随战利品散落地面),用于三级/四级工作台升级，以及酿酒桶、海水净化器等高级配方。
- 掉落模型为红皮小书(`DropModels.ts`);`HudSnapshot` 新增 `adventureBook` 字段,工作台面板按当前等级展示对应升级材料,不足时提示还缺的具体材料。
- 存档兼容:新增道具 ID 走缺省值恢复,`SAVE_VERSION` 不变。

### 制作/烹饪数量步进支持长按连发(2026-09-06 迭代)

- 工作台面板的可调数量配方与火堆烹饪的份数步进按钮改为通用 `src/ui/StepButton.tsx`:点按一次 ±1,长按连发(间隔 160ms→45ms 加速,步进 0.8s 后 ±5、1.6s 后 ±10),与背包丢弃数量、木箱存取的交互一致;连发调度复用 `src/ui/holdRepeat.ts`。
- 数量更新改为函数式 setState,连发期间不受渲染闭包中的旧数量影响;步进按钮保留原有样式与禁用条件(到达 1/上限即停)。

### 制作改为产出道具拿在手上(2026-09-09 迭代)

- 工作台不再「原地搭建直接放置」:改为普通手搓配方(2 石头 + 1 树枝 → `workbench1` 道具),制作完成后自动拿在手上,走与其他设施一致的站定自动放置流程放下;`WorkbenchSystem` 删除搭建模式,只保留升级/挖掘/放回(`placeItem`),首次放置工作台时设置本局已制作标记(原 `workbenchCrafted` 存档字段语义不变)。
- 配方可见性:工作台全局唯一——已放置或背包里已有任意等级工作台道具时,场景手搓卡片不再弹出(2026-09-18 起背包制作页改为置灰「已拥有」展示,不再隐藏,见 `inventory-grid.md`);HUD 用 `workbenchCrafted` 替代原 `canCraftWorkbench/workbenchCrafting` 特殊卡片字段,手搓卡片与背包制作页都按普通配方渲染。联机删 `craftWorkbench` 动作(制作走 `craftTool`)。
- 同批:火堆同样道具化(新道具「火堆」放下即引燃),详见 `docs/autoplace.md` 迭代记录。

### 制作完成手持范围收窄(2026-09-11 迭代)

- 设施产物制作完成后自动拿在手上的仅剩火把/火堆/一级工作台,其余(含 2~4 级工作台道具)进背包,经背包「使用」或长按选择面板切入手持安放模式放下;背包「使用」不再瞬间直放。详见 `docs/autoplace.md` 迭代记录。

### 工作台面板纳入手搓配方(2026-09-19 迭代)

- 工作台面板除工作台专属配方外,同时列出全部手搓配方(木斧、木镐、火把、草衣等),靠近工作台一个入口完成所有制作;材料不足仍置灰展示,已拥有的永久工具维持隐藏规则,排序不变(任务优先 → 可制作优先 → 分类)。
- 工作台/火堆全局唯一:已放置或背包已有同类道具时不出现在面板中。该抑制判定从 `recipeVisible` 抽为 `Crafting.ts` 的 `recipeUniqueSuppressed` 复用,手搓卡片与背包制作页行为不变。
- `PlayerCommandController.craftAtWorkbench` 放宽站点校验:靠近工作台时可结算任意配方(仍要求靠近、未在升级/挖掘、`minBenchLevel` 满足;手搓配方无等级门槛);`craftTool` 手搓路径不变。联机协议不变,客人沿用 `craftAtWorkbench` 上行,详见 `docs/multiplayer.md` 对应迭代记录。

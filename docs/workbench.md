# 工作台合成与放置

## 背景

游戏缺少中期设施类目标。工作台作为全局唯一的设施,给玩家一个采集→积累→建造的第一个完整循环,并为后续更多合成配方打基础。

## 需求描述

- 配方:**2 石头 + 1 树枝**合成工作台。
- 弹卡条件:材料满足、场上(全局)没有工作台、当前位置可摆放。
- 点击卡片后玩家开始定时制作(站定敲打,复用合成动作与木屑特效),期间移动/游泳会中断。
- 制作完成后扣除材料,并在玩家**原位**放置工作台模型。
- 摆放限制(不满足时无法发起制作,卡片也不显示):
  - 玩家在水中(游泳或处于水洼范围及水边)时不能制作;
  - 脚下附近(1 格内)已有树、石头等资源点占位时不能制作。

## 设计方案

- `src/game/entities/Workbench.ts`:程序化拼装的工作台模型(黏土低多边形风格:木桌板 + 四条腿 + 桌上小砧石),构造时加入场景。
- `src/game/systems/WorkbenchSystem.ts`:全局唯一工作台系统。
  - `canPlace()` 校验不在水中/水边、地形露出水面、周围 1 格内无资源点;
  - `canStart()` = 未拥有 + 材料齐(`WORKBENCH_COST`)+ `canPlace()`;
  - `update()` 与 `CraftingSystem` 同款定时敲打逻辑,移动/游泳中断,完成后扣材料并在玩家位置生成 `Workbench`。
- 配方常量 `WORKBENCH_COST` 放在 `Crafting.ts`,与工具配方同处维护。
- `CraftPrompt` 在工具卡片下方追加「手搓工作台」卡片;任一合成进行中时隐藏所有卡片。
- `HudSnapshot` 新增 `canCraftWorkbench` / `workbenchCrafting` / `workbenchProgress`;头顶提示与进度圆环复用现有 indicator 通道,制作中显示「制作中:工作台」。
- 制作期间采集、进食、喝水均让位(与工具合成一致)。

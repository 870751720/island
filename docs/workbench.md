# 工作台合成与放置

## 背景

游戏缺少中期设施类目标。工作台作为全局唯一的设施,给玩家一个采集→积累→建造的第一个完整循环,并为后续更多合成配方打基础。

## 需求描述

- 配方:**2 石头 + 1 树枝**合成工作台。
- 弹卡条件:材料满足、场上(全局)没有工作台、当前位置可摆放。
- 点击卡片后玩家开始定时制作(站定敲打,复用合成动作与木屑特效),期间移动/游泳会中断。
- 制作完成后扣除材料,并在玩家**原位**放置工作台模型。
- 摆放限制(不满足时无法发起制作,卡片也不显示):
  - 玩家在水中(游泳或处于水洼范围及水边)时不能制作;
  - 脚下附近(1 格内)已有树、石头等资源点占位时不能制作。

## 设计方案

- `src/game/entities/Workbench.ts`:程序化拼装的工作台模型(黏土低多边形风格:木桌板 + 四条腿 + 桌上小砧石),构造时加入场景。
- `src/game/systems/WorkbenchSystem.ts`:全局唯一工作台系统。
  - `canPlace()` 校验不在水中/水边、地形露出水面、周围 1 格内无资源点;
  - `canStart()` = 未拥有 + 材料齐(`WORKBENCH_COST`)+ `canPlace()`;
  - `update()` 与 `CraftingSystem` 同款定时敲打逻辑,移动/游泳中断,完成后扣材料并在玩家位置生成 `Workbench`。
- 配方常量 `WORKBENCH_COST` 放在 `Crafting.ts`,与工具配方同处维护。
- `CraftPrompt` 在工具卡片下方追加「手搓工作台」卡片;任一合成进行中时隐藏所有卡片。
- `HudSnapshot` 新增 `canCraftWorkbench` / `workbenchCrafting` / `workbenchProgress`;头顶提示与进度圆环复用现有 indicator 通道,制作中显示「制作中:工作台」。
- 制作期间采集、进食、喝水均让位(与工具合成一致)。

### 工作台制作面板(2026-08-29 迭代)

- 绳线、鱼竿改为**工作台专属配方**(`Recipe.station = 'workbench'`),不再出现在手搓卡片中;斧子、镐子仍为手搓(`station = 'hand'`)。
- 玩家进入工作台范围(距离 < 2.2)时,右中侧工具按钮自动变为工作台图标并持续脉冲缩放(与工具切换提示同一动画),点击弹出工作台制作面板(无工具时也会显示该按钮)。
- 面板列出所有工作台配方:材料类(绳线)可调制作数量(上限为材料可承受的最大个数),工具类(鱼竿)为单个,已拥有/材料不足时禁用;点「制作」关闭面板并开始排队制作,逐个完成,材料在每件完成时结算。
- 排队制作走 `CraftingSystem`,头顶提示显示「制作中:绳线 2/5」;移动/游泳或离开工作台范围会中断整个队列。

### 三级升级材料与冒险家的经验书(2026-09-06 迭代)

- 工作台升级材料改为按目标等级区分(`Crafting.ts` 的 `WORKBENCH_UPGRADE_COST`):升 2 级/4 级仍为 4 皮毛;**升 3 级需要 1 本冒险家的经验书 + 20 石头 + 20 木头 + 5 绳线**。
- 新道具「冒险家的经验书」(`adventureBook`):猎杀熊有 30% 概率额外掉落(在房主端 `Wildlife.lootOf` 随机判定,掉落物随战利品散落地面),唯一用途是升级三级工作台。
- 掉落模型为红皮小书(`DropModels.ts`);`HudSnapshot` 新增 `adventureBook` 字段,工作台面板按当前等级展示对应升级材料,不足时提示还缺的具体材料。
- 存档兼容:新增道具 ID 走缺省值恢复,`SAVE_VERSION` 不变。

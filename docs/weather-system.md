# 天气系统

## 背景

荒岛求生的环境表现需要更丰富的变化。昼夜循环解决了时间维度,但白天的画面节奏单一;天气是最自然的环境压力与氛围来源,且在低多边形风格下实现成本可控。

## 需求描述

三种天气,按权重随机轮换(不引入多云):

- ☀️ 晴天(默认,权重 0.5)
- 🌧️ 雨天(权重 0.25):雨滴粒子、压暗去饱和
- 🌫️ 雾天(权重 0.25):浓雾压缩可见距离

要求:

- 天气随时间随机切换,不连续出现同种天气;每种持续 50~110 秒。
- 切换时强度平滑过渡(约 10 秒),不做突变。
- HUD 时钟旁显示当前天气。
- 移动端友好:粒子数量与灯光调制成本可控。

## 设计方案

### 模块

- `src/game/systems/WeatherSystem.ts`:天气状态机。持有 `sun`/`hemi`/`scene` 引用,在 `DayNightSystem.update` **之后**执行,对昼夜系统输出的天空色、灯光强度、太阳颜色做一层调制(乘暗系数 + 颜色 lerp),并维护 `scene.fog`(晴天 far=300 近乎无雾,雾天 near=26/far=58,雾色跟随天空色)。
- `src/game/fx/Rain.ts`:雨滴粒子。单个 `THREE.Points`(350 滴)在玩家周围 44×44 区域内下落循环,水平跟随玩家,透明度随雨量渐变,雨量为 0 时隐藏。
- `src/game/SurvivalSystem`:新增 `thirstDrainMultiplier`(仅作用于口渴),由天气驱动;雨天淋雨口渴消耗 ×0.6。

### 数值

| 天气 | 天空调制 | 灯光 | 雾 | 玩法 |
| --- | --- | --- | --- | --- |
| 晴 | 无 | 无 | 近乎无 | 无 |
| 雨 | lerp 向灰蓝 `#7d8f9c` | ×0.55 | 无 | 口渴 ×0.6 |
| 雾 | lerp 向白灰 `#c3ccd1` | ×0.85 | near 26 / far 58 | 无 |

### UI

`HudSnapshot` 新增 `weather` / `weatherLabel`,`Hud` 在时钟后显示 `☀️/🌧️/🌫️` 标签。

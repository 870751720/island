# 天气系统

## 背景

荒岛求生的环境表现需要更丰富的变化。昼夜循环解决了时间维度,但白天的画面节奏单一;天气是最自然的环境压力与氛围来源,且在低多边形风格下实现成本可控。

## 需求描述

四种天气,随机轮换:

- ☀️ 晴天
- 🌬️ 刮风:天空光照与晴天一致,植被摇摆、风中飘叶、风声(纯表现,不影响玩法数值)
- 🌧️ 雨天:雨滴粒子、明显压暗去饱和
- 🌨️ 雪天:雪花粒子飘落、天空蒙浅灰白(纯氛围表现,不影响玩法数值)

要求:

- 开局随机天气(按各天气概率掷出)。
- 天气随时间随机切换;每次轮换 1/20 概率切雨、1/25 概率切雪、1/10 概率切风,其余回晴;每种持续 50~110 秒。
- 切换时强度统一平滑过渡(10 秒),不做突变。
- HUD 时钟旁显示当前天气。
- 移动端友好:粒子数量与灯光调制成本可控。

## 设计方案

### 模块

- `src/game/systems/WeatherSystem.ts`:天气状态机。持有 `sun`/`hemi`/`scene` 引用,在 `DayNightSystem.update` **之后**执行,对昼夜系统输出的天空色、灯光强度、太阳颜色做一层调制(乘暗系数 + 颜色 lerp)。
- `src/game/fx/Rain.ts`:雨丝。单个 `THREE.LineSegments`(550 条,长度 0.3~0.6 随机,下落速度 14)在玩家周围 44×44 区域内下落循环,水平跟随玩家,透明度随雨量渐变,雨量为 0 时隐藏。
- `src/game/fx/RainImpact.ts`:雨滴落地交互。按雨量抽样(峰值约 22 个/秒)在玩家周围 20 半径内随机取落点,采样地形高度与水面高度:落到水面(海面/水洼)复用 `WaterFx.ripple` 泛涟漪,落到地面用 `Particles.burst` 溅 3 颗小水花。
- `src/game/SurvivalSystem`:新增 `thirstDrainMultiplier`(仅作用于口渴),由天气驱动;雨天淋雨口渴消耗 ×0.6。

### 数值

| 天气 | 天空调制 | 灯光 | 玩法 |
| --- | --- | --- | --- |
| 晴 | 无 | 无 | 无 |
| 风 | 无(同晴天) | 无 | 无(风向随机,输出植被摇摆与飘叶) |
| 雨 | lerp 向深灰蓝 `#5f7280` | 太阳 ×0.45 / 半球 ×0.55,颜色偏冷 | 口渴消耗 ×0.1、作物生长 ×1.3、火堆/烹饪台燃烧消耗 ×1.1、钓鱼档位权重上抬(见迭代记录) |
| 雪 | lerp 向冷灰蓝 `#8ea3b8` ×0.65 | 太阳 ×0.6 / 半球 ×0.7,颜色偏冷白 | 无(纯表现) |

### UI

`HudSnapshot` 新增 `weather` / `weatherLabel`,`Hud` 在时钟后显示 `☀️/🌧️/🌨️` 标签。

## 迭代记录

### 风归并为第四种天气(2026-09-11)

风从「晴天附属状态 + GM 风表现三态」归并为独立天气类型,天气成为晴/风/雨/雪四态:

- `WeatherType` 扩展为 `'sunny' | 'wind' | 'rain' | 'snow'`;风不再挂在晴天下按 1/10 附带掷出,而是轮换时独立 1/10 概率切到刮风天,风向在切入时随机。
- 强度过渡统一为 10 秒(原风起/风停 6 秒并入 `TRANSITION`);刮风天对天空/灯光无调制,仅 `windAmount` 目标为 1,消费端(植被摇摆、飘叶、风声)不变。
- GM:删除 `GmSystem.wind` 三态与面板「风表现」区块,「强制天气」增加「🌬️ 刮风」按钮;`gmSetWeather` 动作枚举与校验同步扩展 `'wind'`。
- 联机:`players` 快照 `weather` 枚举扩展 `'wind'`(按 windIntensity > 0.05 判定),`netSync` 按 windAmount ≥ 0.5 识别刮风天,风量/风向连续值通道不变。不入存档,`SAVE_VERSION` 不变。

### 雨水恩泽 buff(2026-09-10)

雨天激活全局增益 buff「雨水恩泽」(🌧️,`BuffSystem` 的 `rainBlessing`),雨量 > 0.5 时对全体玩家显示,文案不透露具体数值。四条效果均按雨量 `rainIntensity` 线性生效或以 0.5 为阈值触发:

- **口渴**:淋雨口渴消耗由 ×0.6 加强为 ×0.1(`WeatherSystem.thirstDrainMultiplier` = `1 - 0.9 × 雨量`)。
- **农作物**:`CropSystem.update` 生长计时乘 `1 + 0.3 × 雨量`;雨量两端同步,生长秒数沿用既有 5 秒容差柔和对账,无新增同步字段。
- **火堆/烹饪台**:`Campfire.update` 与 `CookingStationSystem.update` 的燃料消耗乘 `1 + 0.1 × 雨量`;燃料数值已有快照/对账通道,两端确定性计算。
- **钓鱼**:`FishTable.rollTier` 新增 `rainShift` 参数——有饵时二档权重扣 5 个百分点转给三档,裸钓时一档(杂物)扣 5 个百分点转给二档;由 `Game.startFishing` 按雨量 > 0.5 传入,仅房主权威结算端 roll 生效,不动联机协议。

### 新增雪天(2026-09-10)

- `WeatherType` 扩展为 `'sunny' | 'rain' | 'snow'`,`WeatherSystem` 新增独立的 `snowAmount` 强度插值与 `snowIntensity` 输出,与雨量互不干扰(玩法数值仍只消费 `rainIntensity`,雪天不影响雨水恩泽/作物/篝火/钓鱼/口渴)。
- 新增 `src/game/fx/Snow.ts`:420 颗柔和圆形点精灵雪花,玩家周围 44×44 区域内慢速下落(1.2~2.6 速度)并正弦水平摆动,透明度随雪量渐变,雪量为 0 时隐藏。
- 雪天天空调制:lerp 向浅灰白 `#aebac6` ×0.5,太阳颜色偏冷白、强度 ×0.7,半球 ×0.85,压暗幅度比雨天温和。
- 随机轮换:每次到期切换时 1/20 概率切雨、1/25 概率切雪,其余回晴;切换后同样 10 秒平滑过渡。
- GM:`gmSetWeather` 支持 `'snow'`,GM 面板「世界」tab 强制天气增加「🌨️ 雪天」按钮;雪天与「雪季预览」(地形植被覆雪)相互独立,互不驱动。
- 联机:`players` 快照 `weather` 枚举扩展 `'snow'` 并新增连续值 `snow`,客人端 `netSync` 携带雪量本地插值表现;`gmSetWeather` 动作枚举校验同步扩展。雪不入存档,`SAVE_VERSION` 不变。

### 雪花可见性增强(2026-09-10)

雪季地面与天空都偏白,白色雪花衬不出来。调整:

- 雪天天空加深为冷灰蓝 `#8ea3b8`(lerp ×0.65),太阳强度 ×0.6、半球 ×0.7,整体背景变暗,雪花与积雪拉开明暗差。
- 雪花加大(尺寸 0.22→0.34→0.5)、加密(420→520→620 颗)、不透明度 0.85→0.95,并带淡蓝白 `#e6effa` 色调。

# 游戏内界面统一样式

## 背景
游戏内 HUD 已采用浅奶油与浅鼠尾草半透明控件，其余面板需要使用相同的视觉语言。

## 需求描述
- 统一背包、物品详情、木箱、设置、配方图鉴、游戏图鉴、工作台、篝火、烹饪台、冶炼炉、纺织机、饵料桶、酿酒桶、工具与表情选择器、状态详情、信件、拍照操作与预览、宝藏抽奖外层、死亡与复活提示、GM 面板。
- 玩家头顶的作业提示标签(采浆果/砍树等)保持原有深色半透明样式,不套用本主题。
- 开始页、角色设置、联机大厅及荒岛传承不使用游戏内主题。
- 奶油/鼠尾草底色、深灰绿色文字、细边框、柔和圆角和轻阴影与 HUD 一致。选中状态使用鼠尾草底与描边，警告/丢弃/退出使用低饱和暖色；设施进度与物品图标保留语义色。
- 「暗场」全屏界面(拍照后的分享预览、死亡/复活结算及其分享降级弹层)使用 `gameDarkTheme` 深色主题:夜色松绿(波塞冬庇佑用深海青)渐变底、奶油文字与半透明描边控件,与浅色主题同源。
- 全局滚动条改为 6px 鼠尾草细圆条、透明轨道,替代浏览器默认样式;暗场界面滚动条换为奶油色。

## 设计方案
- `src/ui/gameTheme.ts` 集中管理游戏内颜色、面板、按钮和交互反馈；各组件复用样式对象，保留原有布局和业务职责。暗场界面复用同文件中的 `gameDarkTheme`(配色/底色)与 `gameDarkButtonStyle`(半透明描边按钮,主按钮用 `accent` 实底)。
- 游戏内根节点限定焦点、按压、禁用和减少动态效果规则，退出游戏后不影响开始页。
- 手机竖屏优先：面板扣除屏幕边距并限制可视高度，内容超出时在面板内滚动；操作按钮至少 44px 高，音量滑杆触控区 44px；背包格子与拖拽命中计算保持一致。短横屏工具选择器在屏幕中线居中，拍照预览按钮允许换行。
- 使用 CSS 渐变和阴影，不引入图片、全屏模糊或额外 WebGL 渲染。
- 滚动条统一样式放在 `src/app/globals.css`,对全部滚动容器生效(WebKit 伪元素 + Firefox `scrollbar-width/scrollbar-color`);颜色读 `--scroll-thumb`/`--scroll-thumb-hover` 变量,浅色默认值为鼠尾草,暗场滚动容器行内展开 `gameTheme.ts` 导出的 `gameDarkScrollVars` 覆盖为奶油色。刻意隐藏滚动条的容器(跑马灯视口、HUD 增益区)声明自身 `scrollbar-width:none`,优先级更高,不受影响。
- 房主与客人各自渲染同一套本地 UI；按钮继续使用既有回调，客人动作经 NetGuest.action 上行、房主权威结算、快照/事件回流照常。样式和按压反馈不新增网络字段，不修改存档和 SAVE_VERSION。

### 游戏内设置

声音设置使用独立浅奶油卡片，图标、标题与百分比对齐；音量轨道 5px、滑块 19px，保留 44px 高的拖动区域。任务指引使用独立整行可点卡片，20px 圆角勾选框配合至少 52px 高的标签触控区，并说明关闭后保留任务进度。控件支持焦点轮廓、原生滑杆与复选框语义，样式限定在 `SettingsPanel.module.css`，不影响其他面板。音量和指引仍即时应用并按原规则本机保存；单机、房主、客人共用外观，均为本地偏好，无新增联机协议或存档字段。

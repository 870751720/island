# 顶部 UI 边距与设置布局

## 背景

手机刘海、挖孔或容器遮挡可能让顶部 HUD 超出可见区域；设置选项增加后，长列表也使常用操作难以找到。

## 需求描述

- 设置按游戏、界面、声音排列为三个分类，默认打开游戏页，关闭与继续游戏固定可见；仅当前分类的内容在小屏或横屏下按需滚动。
- 界面分类提供顶部边距调整、任务指引开关和相机模式。声音保留音乐与音效；游戏保留多人入口与返回主界面。
- 玩家可统一下移左上角信息、任务卡、Buff、设置按钮及折叠/展开的小地图，实时查看效果并恢复默认。
- 背包始终提供入口，包括空背包；背包分类栏提供设置按钮，顶部被遮挡时仍可进入设置。

## 设计方案

- 复用 `.hud-top-edge` 作为统一定位基线，保留 `max(7px, env(safe-area-inset-top))` 自动安全边距，叠加玩家设置的 0–120 CSS 像素额外距离，步进 1 像素。
- 额外距离在当前视口最多生效 15dvh，避免旋转为横屏后过度下移；恢复竖屏后自动使用保存的选择。默认额外距离为 0。
- 独立底部调整面板显示实际 HUD，透明全屏遮罩拦截底下触控；调整期间顶部 HUD 不因闲置淡出。完成返回设置，死亡退出调整。
- `useHudLayout` 负责数值归一化与本机 localStorage 持久化，非法数据恢复默认，禁止存储时仍可在当前游戏中调整。
- 设备布局使用独立键 `island-hud-top-offset`，不进入世界存档或云存档，不改变 SAVE_VERSION。
- 房主、客人与单机各自在本机应用布局，不发送动作、不参与权威结算、不进入快照或事件补播。
- 控件触控区域至少 44px；新增表现仅为 React/CSS 布局，不增加 Three.js 渲染负担。

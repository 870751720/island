# 海中威胁(巨影)

## 背景

玩家可以游泳出海,但海里此前没有任何危险:泡多久都安然无恙,深海的压迫感只停留在氛围层面。希望「在海水里待太久」成为一条清晰的危险曲线——先用自言自语铺垫恐慌,最后真的有东西从深处上来咬人。

## 需求描述

- 玩家在海水中游泳时持续计时(只认真正的海水;水洼、涉水浅滩不算):
  - 第 **8 秒**:说一句恐慌向的自言自语(`seaPanic`,20 句池);
  - 再过 **5 秒**(第 13 秒):说一句「感觉海里有东西」的自言自语(`seaDread`,20 句池);
  - 再过 **4 秒**(第 17 秒):海中巨影现身,开始攻击玩家。
- 巨影咬击**固定 33 点伤害**(不吃装备防御/减伤),每 **2 秒**一次,直到玩家离开海水或死亡。
- 玩家一旦离开海水(或死亡、下线),计时整体作废、巨影下潜离场;再次入海从头计时。
- 视觉表现:海面上一条**大鱼影子**贴水游弋,背鳍露出水面一小截,绕着玩家转圈,咬击时冲向玩家并在咬点溅起水花。

## 设计方案

### 模块

- `src/game/systems/SeaThreatSystem.ts` — 计时与编排:每端各自本地运行,按会话累计泡海时长,推进三段剧本(台词 → 台词 → 刷巨影),并驱动咬击节奏。
- `src/game/entities/SeaPredator.ts` — 巨影纯表现实体:贴海面的大鱼影子(深色椭圆主身 + 摆动尾巴 + 双侧鳍,`renderOrder=1` 画在海面之后,深水区也看得见)+ 露出水的竖直背鳍三角面;状态机 `rise → circle → lunge ⇄ circle → dive`。
- `src/game/dialogue/mumbleLines.ts` — `seaPanic` / `seaDread` 两个台词池(各 20 句),不进 `MumbleSystem` 的触发规则表。
- `src/game/systems/MumbleSystem.ts` — 新增 `forceSay(trigger)`:外部按剧本时序点名说话,不走持续判定/条件冷却,也不受全局 20 秒间隔约束,但说完会重置全局计时,让普通台词为这条序列让路。
- `Game` 装配:构造注入会话列表与权威标记,主循环随 `waterFx`/`pondLife` 一起 update,`applySeaBite` 做权威端伤害结算。

### 判定与数值

| 项 | 值 |
|---|---|
| 入海判定 | `player.isSwimming && terrain.getWaterKind(x, z) === 'sea'`(水深过游泳线且不在水洼) |
| 恐慌台词 | 泡海第 8 秒,`forceSay('seaPanic')` |
| 察觉台词 | 泡海第 13 秒,`forceSay('seaDread')` |
| 巨影现身 | 泡海第 17 秒 |
| 咬击 | 每 2 秒一次,固定 33 伤害;现身后留 0.6 秒上浮起势再咬第一口 |
| 离水/死亡 | 计时作废、巨影下潜回收;再入海重新从 0 计时 |

### 视觉细节

- 影子贴在海面之上约 0.03:海面材质深水区几乎不透底,贴水渲染保证任何水深都看得清;与涟漪一致画在海面之后(`renderOrder=1`,`depthWrite=false`)。
- 游弋:绕目标半径约 3.1(随时间轻微呼吸),角速度约 1.15 rad/s,朝向按实际位移方向缓转;身后每 0.55 秒泛一圈涟漪(`WaterFx.ripple`)。
- 扑咬:0.3 秒加速冲到玩家所在点(实时跟踪),咬点溅水花(`WaterFx.splash`),0.5 秒撤回游弋轨道。
- 出场:0.7 秒自深处上浮淡入;退场:0.6 秒淡出下沉。

### 联机(房主权威)

- **计时与表现每端本地各自跑**:所依赖的玩家位置本就随姿态快照回流,两端看到的「谁泡在海里多久」一致(误差为快照延迟,无害);台词是纯表现层,只给本地玩家自己说。
- **伤害只在权威端(单机/房主)结算**:`survival.damage(33)` 后血量随快照回流,客人端的闪红与受伤音由既有「快照血量下降」检测驱动;受击粒子/伤害数字/音效复用狼袭的 `wildlifeHit` 事件给客人补播。
- 咬击标记 `markCombat`,战斗状态随既有 `combat` 快照字段回流(战斗音乐等表现沿用)。
- 无新增网络消息、无新增存档字段。

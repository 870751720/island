# 单机闲置休息

## 背景

HUD 在玩家连续闲置 5 秒后淡出，玩家可能暂时离开手机，需要同步暂停单机生存压力。

## 需求描述

- 仅单机生效，连续闲置 5 秒后停止饥饿、口渴的自然消耗和昼夜时间推进。动物、场景动画、天气、作物与设施生产照常运行。
- 移动或开始交互后继续，无需额外确认；继续沿用 HUD 淡出样式。
- 采集、制作、进食、睡觉、钓鱼和瞄准等操作中不进入休息。死亡后不暂停复活计时。
- 房主（包括尚无客人的房间）与客人均不启用此功能。

## 设计方案

`IdleRest` 复用会话的 HUD 闲置计时，并直接读取摇杆、键盘和自动寻路输入，保证移动能结束休息。`Game` 仅向昼夜系统传入零时间步长，并将生存系统的饥渴消耗倍率设为零；通用玩法 `simDelta` 不受闲置影响。动物、海中威胁、任务支援、天气与设施持续更新。体力恢复、游泳消耗和伤害结算照常，休息不提供无敌，饥渴已经归零时仍按原有规则掉血。单机拍照模式保持原有暂停行为。

闲置状态不持久化，不增加存档字段或修改版本。联机不使用休息判定，不新增动作、快照或事件。

本地验证关注：站定 5 秒后饥渴自然消耗与昼夜停止，动物仍活动、设施继续生产；移动及开始制作后继续；钓鱼和睡觉正常推进；死亡后的复活正常；房主和客人站定后世界继续运行。

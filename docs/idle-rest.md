# 单机闲置休息

## 背景

HUD 在玩家连续闲置 5 秒后淡出，玩家可能暂时离开手机，需要同步暂停单机生存压力。

## 需求描述

- 仅单机生效，连续闲置 5 秒后暂停世界玩法计时，饥饿、口渴和昼夜时间不再推进。
- 移动或开始交互后继续，无需额外确认；继续沿用 HUD 淡出样式。
- 采集、制作、进食、睡觉、钓鱼和瞄准等操作中不进入休息。死亡后不暂停复活计时。
- 房主（包括尚无客人的房间）与客人均不启用此功能。

## 设计方案

`IdleRest` 复用会话的 HUD 闲置计时，并直接读取摇杆、键盘和自动寻路输入，保证移动能唤醒暂停。`Game` 在单机休息时将玩法 `simDelta` 置零，冻结昼夜、天气进程、生存消耗、体力变化、作物与设施生产计时。动物模拟、海中威胁和任务支援计时暂停，伤害入口拦截休息中的攻击结算。水面、雨雪、相机和界面仍然渲染。

闲置状态不持久化，不增加存档字段或修改版本。联机不使用休息判定，不新增动作、快照或事件。

本地验证关注：站定 5 秒后饥渴与时间保持不变；移动及开始制作后继续；钓鱼和睡觉正常推进；死亡后的复活正常；房主和客人站定后世界继续运行。

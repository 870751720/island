# 场景装饰物(花/蘑菇/贝壳/海星)

## 背景

玩家把树等资源采集完后,场景容易显得光秃秃、单调。资源类道具(树/石/铁/浆果等)都有玩法预算,不适合靠加资源数量来充实画面,需要一批纯视觉装饰。

## 需求描述

- 新增一批不可采集、无碰撞、不影响任何资源平衡的纯装饰小物件:
  - 草地带:野花(白/黄/粉三色);
  - 沙滩带:贝壳(扇贝)、海星。
- 装饰物散布自然(成片聚簇),不进存档、不做网络同步,重复进入同一存档时布局一致。
- 面向手机 GPU 控制开销:每种装饰一个 `InstancedMesh`,整体只增加个位数 draw call,不开投影。

## 设计方案

- 模块:`src/game/world/Decorations.ts`,由 `Game` 在地形创建后实例化、`dispose` 时释放。
- 布局确定性:装饰布局只由 `terrainSeed` 决定(mulberry32 种子随机)。联机时 `terrainSeed` 本就通过 welcome 消息同步给客人,因此房主/客人各自本地生成即可得到完全一致的画面,不需要任何同步消息。
- 高度带划分(复用地形高度,不新增地形查询):
  - 沙滩:水线以上 0.05~0.7 米的低平地(贝壳、海星);
  - 草地:高于 0.7 米且不在任何水域边缘(花、蘑菇)。
- 散布:全岛均匀随机散布(不做聚簇)。
- 建模:延续程序化低模黏土风格,每种装饰由少量基础几何体合并(`mergeGeometries`)成一个几何体,用顶点色区分部件(如花茎绿/花冠彩色),材质统一一份 `MeshStandardMaterial`(vertexColors + flatShading + roughness 1)。
- 数量标定(约 890 个实例 / 5 个 draw call):白花 220、黄花 180、粉花 140、贝壳 260、海星 90。

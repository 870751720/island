# 营地复活
## 背景
死亡后优先返回玩家营地，减少回营负担。
## 需求描述
- 复活优先级为床、火堆、工作台、原始出生点，设施等级和火堆是否点燃不影响资格。
- 排除带有 `landmark_` 持久化标识的遗迹、村落和天然营地设施。挖走后由玩家重新安放的设施视为玩家设施。
- 同类设施按距死亡位置从近到远选择；在其旁边 1.5～3 米内寻找干地空位，避开水域、资源、设施和围栏。该类设施均无可用落点时顺延下一级，最终回到原始出生点。
## 设计方案
`RespawnPoint.ts` 统一选点，普通倒计时重生、复活石和波塞冬庇佑共用。庇佑赠礼放在实际复活落点附近。求生模式是否获得复活资格、死亡掉落和状态恢复规则保持原有设计。
联机由房主在实际复活时读取现存设施并结算，客人通过既有玩家位置快照恢复，不新增动作或网络字段。共享所有玩家安放的设施，不需绑定床位。沿用现有设施 ID，不修改存档版本。

# TapTap H5 手动云存档

## 背景

TapTap H5 玩家可能在退出容器后无法读取本地进度与个人档案。提供玩家主动操作的云端备份入口，保留现有自动保存、死亡清档、新局、启动和联机规则。

## 需求描述

- 仅 TapTap H5 包在开始主界面底部工具行显示一个「云存档」入口，与形象、开新档和传承入口并排，触控高度不小于 44px，不增加独占按钮行或常驻说明。点击后在弹窗内选择「上传存档」「下载存档」，沿用雾蓝和奶油色。
- 上传前确认：备份本地已保存的岛屿进度、全局配置与荒岛传承，替换该账号上次手动备份。即使已经死亡、没有进行中的岛屿，仍可单独备份全局数据与传承。
- 下载先读取、校验云端内容，展示生存天数与备份时间。只有点击「确认覆盖并读取」才写入本地，明确提示会替换现有进度、全局配置及传承，不能撤销。备份没有岛屿时额外提示会清除当前岛屿存档。
- 覆盖成功后通过「返回主界面」整页重载，清除旧内存缓存，让名字、传承及全局配置一起生效。
- 不做自动上传、自动下载、启动恢复或额外自动保存。新进度需要玩家返回开始主界面再次上传。

## 设计方案

### 渠道隔离

`next.config.mjs` 仅在 `H5_EXPORT=1` 且非小红书构建时设置 `NEXT_PUBLIC_TAPTAP_H5=1`。开始页按编译期常量动态引入 `TapTapSaveControls`；GitHub Pages 和小红书构建不引入云存档界面或平台调用。H5 界面样式独立限定在弹窗内，弹窗小屏及横屏可滚动；主界面复用原工具行布局与响应式规则。

`game/platform/taptap/SaveBundle.ts` 负责白名单数据打包、校验与覆盖；`TapCloudApi.ts` 封装平台接口；`ui/taptap/` 负责按钮和弹窗。原本地存档模块不改动，`SAVE_VERSION` 保持 32。

### 数据范围

| 本地键 | 数据 |
| --- | --- |
| `island.save.v1` | 世界、背包、角色、房主保存的队友进度等完整游戏存档 |
| `island.profile.v1` / `island.nickname` | 名字、形象与旧昵称 |
| `island.meta.v1` | 荒岛传承点数及全部已解锁节点等级 |
| `island.firstDeathBlessing.v1` | 首次死亡资格 |
| `island-game-mode` | 新局模式偏好 |
| `island-audio-settings` / `island-menu-sound` | 音乐、音效音量与菜单声音开关 |
| `island.quest-guide` | 任务指引开关 |
| `island.gameplayZoom.v1` | 游戏画面缩放 |

共 10 个固定键；未设置的字段明确保存为 null，下载覆盖时删除对应本地项，让原配置读取器恢复默认值。联机恢复令牌、上次房间记录、云端上传限流时间不是游戏全局配置，不参与备份。旧备份中多余的 `island.landmarkChances.v1` 键(2026-09-19 移除的地标概率配置)读取时忽略,不再恢复。

### 平台与失败处理

遵循 [TapTap 云存档接入指南](https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/cloud-save-tutorial/)，使用宿主提供的全局 `tap`，无需另装 SDK。只有手动操作时才获取文件与云存档管理器。平台不可用、请求失败或超时均提示玩家，不模拟成功。

- 固定槽位 `island_manual_save`。上传先查询槽位，再将 UTF-8 JSON 写到 `tap.env.USER_DATA_PATH` 下，随后创建或更新云档；以平台成功回调为准。
- 平台每分钟最多上传一次。客户端按上次尝试及平台更新时间保留 65 秒间隔，尽量跨刷新保留限流时间，超限提示稍后重试。
- 下载按槽位 uuid/fileId 获取临时文件，校验备份格式、存档版本和关键数据，再展示覆盖确认。文件上限 10 MiB。
- API 串行、30 秒超时，操作中禁止重复提交。下载/校验失败不改本地；覆盖遇到写入失败时尝试回滚全部白名单项，回滚未完整成功则明确报告。云端原备份不变。
- 多个 localStorage 键不是事务：覆盖时强杀进程可能只写入部分字段，可再次下载完整云档恢复。正常覆盖后整页重载，避免旧传承、指引、缩放等模块内存缓存回写旧值。

### 联机

入口仅在开始主界面，下载时没有正在运行的 Game，不与会话自动保存争抢。房主本地档内的 `others` 队友数据随完整世界备份；客人只能备份自己设备已有的本地岛，不会将当前远端岛转换成本地存档。不新增动作、快照或协议字段。

### 验证与交付

执行类型检查、默认 GitHub Pages 构建及 H5/小红书渠道构建；核对非 H5 产物无云存档入口或平台调用，验证 ZIP 完整性、入口和 Deflate 压缩。H5 ZIP 由用户在 TapTap 客户端验证；代码提交部署沿用仓库流程，GitHub Pages 保持关闭云存档入口。不起开发服务器或进行浏览器运行测试。

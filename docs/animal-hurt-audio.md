# 羊与野牛受击叫声
## 背景
羊与野牛受攻击时需要可辨识的叫声反馈。
## 需求描述
羊与野牛分别使用用户提供的「羊.mp3」「牛.mp3」压缩采样。有效受击包含致命命中均播放，未命中不播放。本地试听 HTML 及辅助文件在选定后删除。
## 设计方案
GameplaySampleAudio 预解码并缓存 64 kbps 单声道 MP3，羊约 1.1 秒、野牛约 1.1 秒，保持录音音高与速度，使用音效音量总线。压缩方案见 audio.md。
Wildlife.applyDamage 在房主权威扣血后发出位置音效，位于存活与死亡分支之前；沿既有 sfxAt 可靠事件广播。房主与客人仅播放各自 20 米内的声音。房主结算客人动作时，本地动物叫声绕过交互静音；客人不预测播放，避免重复。复用现有协议，不修改存档版本。

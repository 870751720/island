# 羊与野牛受击叫声
## 背景
羊与野牛受攻击时需要可辨识的叫声反馈。
## 需求描述
羊采用第二轮试听的第 1 版短促咩叫，野牛采用第 1 版低沉闷吼。有效受击包含致命命中均播放，未命中不播放。本地试听 HTML 及辅助文件在选定后删除。
## 设计方案
AnimalHurtAudio 使用声门脉冲、声道共鸣与气声合成选定波形，每个音频上下文按动物缓存，后续命中复用缓冲。羊时长约 0.72 秒、野牛约 0.95 秒，使用音效音量总线。
Wildlife.applyDamage 在房主权威扣血后发出位置音效，位于存活与死亡分支之前；沿既有 sfxAt 可靠事件广播。房主与客人仅播放各自 20 米内的声音。房主结算客人动作时，本地动物叫声绕过交互静音；客人不预测播放，避免重复。复用现有协议，不修改存档版本。

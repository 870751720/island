# 食物的吃与喝

## 背景
饮料、羊奶、牛奶和汤品需要与固体食物区分使用文案、角色动作和音效。

## 需求描述
- 食物定义必填 `consumeType: 'eat' | 'drink'`，供所有使用入口共用。
- 可乐、无糖可乐、羊奶、牛奶、各类酒、汤和粥标记为喝；果实、鱼肉、烤制食物、煮浆果和煮蟹肉标记为吃。
- 背包使用按钮、饥饿提示卡、头顶进度文案统一显示吃或喝；液体连续使用按钮显示“连续喝”。触控区域沿用手机布局。

## 设计方案
- `Food.ts` 提供 `foodVerb`、`foodAction`、`foodSound`，进食动画保留浆果与鱼肉两类，饮用统一使用现有 `drink` 抬头动作。
- `EatingSystem` 在每份 2 秒完成后扣除一份并恢复属性（连续进食与背包饮品共用该时长），移动或游泳时中断。液体在每份 2 秒内连续播放两遍喝水采样，每遍按实际采样时长轻微调速至 1 秒，进度终点淡出收声，不产生食物碎屑；固体播放咀嚼声与碎屑，吞咽按采样实际时长提前排程并对齐进度终点，吞咽期间停止咀嚼声。
- 完成帧不再触发下一口音效，每份完成或中断时停止当前声音；饮品不播放固体食物的完成吞咽声。客人在食物清空、切换、连续使用进度归零或死亡快照到达时同步停止声音。
- 连续使用仍以饥饿恢复满或库存用尽为终止条件，恢复数值、酿酒增益和物品 ID 保持原定义。
- 客人操作仍由 `NetGuest.action` 上行、房主权威执行；动作随已有姿态快照同步，客人从 HUD 食物名称查同一食物定义补播对应声音与特效。
- 属性属于静态配置，不增加存档和网络字段，`SAVE_VERSION` 不变。

## 动物喂食标签

每个 `Food` 必填 `eaters`，显式声明兔子、羊、野牛、狼、熊、薯条中哪些可以吃；空数组表示不能投喂。食物详情只描述来源、外观、口感及加工用途，不展示使用对象、可喂动物、恢复数值或增益效果，也不使用管饱、解渴、滋补等效果暗示。地面投喂、食料桶、薯条成长统一读取该标签。首次驯养与猫狗伙伴沿用玩家饥饿恢复值；已驯养动物通过 `HusbandryFood.ts` 使用独立恢复量，生物图鉴食谱分别标注首次驯养与日常爱心恢复。自然草丛和灌木的啃食恢复另由驯养系统定义，纤维与树枝不视为食物。详见 [动物驯养](animal-husbandry.md)。

### 食品道具描述

所有食品（含饮品、酒、汤品和烤制品）统一使用 `Items.ts` 的描述，背包与配方书共用；背包不再按 `Food.eaters` 拼接喂食对象与每份加成。规则同样适用于新增食品。实际食谱、恢复数值、酒类增益及吃喝按钮保持原逻辑。单机、房主和客人共用同一展示，不新增动作、快照或事件，存档版本不变。

## 隐藏料理

隐藏料理共 43 份，保留草莓奶糕、苹果派和鲜肉馅饼并扩充 40 份。`HiddenRecipeCatalog.ts` 统一登记名称、用量、恢复值与视觉类型，`Food.ts` 据此生成食物定义。汤碗类料理使用「喝」与现有饮用动作、音效，其他糕点、饼、盘菜、菜卷、肉串及南瓜盅使用「吃」；每份仍在两秒完成时扣除并恢复属性，客人由房主结算。

全部隐藏料理的 `eaters` 为空，不可地面投喂、投入食料桶或喂猫狗；也不进入研究食材白名单。食物描述只说明食材、外观与加工，喂食限制列在图鉴属性中。恢复数值、研究搭配和制作方式统一见 [料理研究台](./recipe-research.md)。研究成功、实际获得食物或 GM 全解锁会开放个人永久食谱与图鉴。新增物品不改变存档版本，旧档和原有食物 ID 保持兼容。

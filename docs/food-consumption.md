# 食物的吃与喝

## 背景
饮料、羊奶、牛奶和汤品需要与固体食物区分使用文案、角色动作和音效。

## 需求描述
- 食物定义必填 `consumeType: 'eat' | 'drink'`，供所有使用入口共用。
- 可乐、无糖可乐、羊奶、牛奶、各类酒、汤和粥标记为喝；果实、鱼肉、烤制食物、煮浆果和煮蟹肉标记为吃。
- 背包使用按钮、饥饿提示卡、头顶进度文案统一显示吃或喝；液体连续使用按钮显示“连续喝”。触控区域沿用手机布局。

## 设计方案
- `Food.ts` 提供 `foodVerb`、`foodAction`、`foodSound`，进食动画保留浆果与鱼肉两类，饮用统一使用现有 `drink` 抬头动作。
- `EatingSystem` 仍在 1.5 秒完成后扣除一份并恢复属性，移动或游泳时中断。液体每半秒触发一次约 0.25 秒的柔和啜饮声，不产生食物碎屑；固体播放咀嚼声与碎屑。
- 完成帧不再触发下一口音效，每份完成或中断时停止当前声音；饮品不播放固体食物的完成吞咽声。客人在食物清空、切换、连续使用进度归零或死亡快照到达时同步停止声音。
- 连续使用仍以饥饿恢复满或库存用尽为终止条件，恢复数值、酿酒增益和物品 ID 保持原定义。
- 客人操作仍由 `NetGuest.action` 上行、房主权威执行；动作随已有姿态快照同步，客人从 HUD 食物名称查同一食物定义补播对应声音与特效。
- 属性属于静态配置，不增加存档和网络字段，`SAVE_VERSION` 不变。

## 动物喂食标签

每个 `Food` 必填 `eaters`，显式声明兔子、羊、野牛、狼、熊、薯条中哪些可以吃；空数组表示不能投喂。食物详情只描述来源、外观、口感及加工用途，不展示使用对象、可喂动物、恢复数值或增益效果，也不使用管饱、解渴、滋补等效果暗示。地面投喂、食料桶、薯条成长统一读取该标签。自然草丛和灌木的啃食恢复另由驯养系统定义，纤维与树枝不视为食物。详见 [动物驯养](animal-husbandry.md)。

### 食品道具描述

所有食品（含饮品、酒、汤品和烤制品）统一使用 `Items.ts` 的描述，背包与配方书共用；背包不再按 `Food.eaters` 拼接喂食对象与每份加成。规则同样适用于新增食品。实际食谱、恢复数值、酒类增益及吃喝按钮保持原逻辑。单机、房主和客人共用同一展示，不新增动作、快照或事件，存档版本不变。

# 碎石小路

## 背景
营地需要可由玩家铺设的道路，改善往返效率，并保持手工黏土的自然外观。

## 需求描述
- 三级及以上工作台「设施」配方：石头 ×1 → 碎石小路 ×2，支持批量制作。
- 制作后进入背包，使用或从设施选择面板手持；沿用面前整数格预览、站定 2 秒铺一格、移动后可继续铺的触屏操作。
- 每格 1×1 米，干地放置，遵守设施占格、资源阻挡和水边限制；道路不阻挡玩家移动。
- 玩家脚下在路面覆盖的方格内且没有游泳时获得「碎石路加速」，移速乘以 1.1；与已有移速效果相乘，同类道路不叠加，离开即失效。HUD 展示名称、图标及说明。
- 手持铲子在附近站定可拆除最近路格，耗时按铲子等级计算，每格回收 1 个碎石小路道具，背包溢出掉落。

## 设计方案
- `GravelPath` 用薄砂砾底层与低面数碎石程序化拼装。坐标决定每格碎石数量、不规则散点、大小、旋转和四种灰褐色，避免连续铺路重复同一纹样；读档与各联机端外观一致。
- 底层及四种石子模板经 `ModelInstances` 空间分批实例化，静态更新、接收阴影、不增加投影开销；大量铺路时共享几何体和材质。
- `GravelPathSystem` 独立管理占格、回收进度、快照和增量变更；按整数格 Map 查询脚下加速，查询成本不随道路总数增长。
- `AutoPlaceSystem` 注册设施，配方、背包、自绘道具图标、掉落物模型及 Buff 展示复用现有入口。
- 单机与房主在移动前计算每个玩家脚下的道路；客人使用同步路面计算本地预测移动。制作、放置、扣物品及回收由房主结算，沿用既有动作上行、玩家快照、世界 add/remove 增量和反馈事件；完整同步含全部路面。
- 存档新增可选 `gravelPaths`，缺省空数组，保持 `SAVE_VERSION` 不变。联机协议版本为 34，避免旧客户端缺少道路与移速规则。

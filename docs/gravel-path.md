# 碎石小路

## 背景
营地需要可由玩家铺设的道路，改善往返效率，并保持手工黏土的自然外观。

## 需求描述
- 三级及以上工作台「设施」配方：石头 ×1 → 碎石小路 ×2，支持批量制作。
- 制作后进入背包，使用或从设施选择面板手持；沿用面前整数格预览、站定 2 秒铺一格、移动后可继续铺的触屏操作。
- 每格 1×1 米，干地放置，遵守设施占格、资源阻挡和水边限制；道路不阻挡玩家移动。
- 玩家脚下在路面覆盖的方格内且没有游泳时获得「步履轻快」，移速乘以 1.1；与已有移速效果相乘，同类道路不叠加，离开即失效。HUD 展示名称、图标及说明：「碎石铺成的小路让脚步更轻快。在路上移动速度提升 10%，离开后恢复。」
- 手持铲子在附近站定可拆除最近路格，耗时按铲子等级计算，每格回收 1 个碎石小路道具，背包溢出掉落。

## 设计方案
- `GravelPath` 用贴地砂砾底层与低面数碎石程序化拼装。每格 14～18 颗碎石，散点最小间距 0.16 米，保留更明显的石间空隙；坐标决定数量、不规则散点、大小、旋转和四种灰褐色，避免连续铺路重复同一纹样；读档与各联机端外观一致。
- 路底通过 `GroundPatch` 裁剪实际地形三角面，保留坡折并抬高 0.012 米避免闪烁；每颗碎石独立采样高度和坡面法线，随坡面落位，旧路面读档后也重新贴地。
- 路面内部按世界坐标生成连续的不规则露土斑块，砂砾底色混合比例为 0～70%，让原本草地或泥土从石间透出；此混色仅影响路底，不改变碎石尺寸和加速覆盖。
- 道路外沿约 0.2 米逐渐与原地形顶点色混合，边缘宽度按世界坐标轻微起伏；外沿碎石缩小、稀疏，弱化正方形轮廓。边缘复用地表季节调色，相邻格共享边处不收边，拐角和拆路后重新计算周围八格。
- `StaticMeshBatch` 按 16 米空间块合并路底，四种石子模板经 `ModelInstances` 实例化。铺设/拆除仅标记附近路格重建，帧末统一刷新；路底每格采用 8×8 混色细分并裁剪地形折线，不逐帧重建、不按路格增加 drawcall。
- `RoadFacility` 让落格预览随目标位置贴地并按外沿覆盖裁出轮廓，手持模型使用缩略平面造型。
- `RoadSystem` 由道路种类驱动，共用占格、回收进度、快照和增量变更逻辑；按整数格 Map 查询脚下加速，查询成本不随道路总数增长。
- `AutoPlaceSystem` 注册设施，配方、背包、自绘道具图标、掉落物模型及 Buff 展示复用现有入口。
- 单机与房主在移动前计算每个玩家脚下的道路；客人使用同步路面计算本地预测移动。制作、放置、扣物品及回收由房主结算，沿用既有动作上行、玩家快照、世界 add/remove 增量和反馈事件；完整同步含全部路面。
- 存档新增可选 `gravelPaths`，缺省空数组，保持 `SAVE_VERSION` 不变。联机协议版本为 35，避免旧客户端缺少道路与移速规则。

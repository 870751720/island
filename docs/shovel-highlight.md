# 铲子目标高亮

## 背景
手机小屏上，相邻设施与资源点容易混淆，玩家需要直接看出铲子正在处理哪一件物体。

## 需求描述
- 挖掘期间，被铲物体表面显示琥珀色呼吸高亮、边缘增强与纵向扫光。
- 覆盖可挖资源、设施、围栏及门、土壤和道路；有作物时先高亮作物，之后才高亮土壤。
- 移动、游泳、切换工具、死亡、目标消失或拍照时隐藏高亮，不增加触屏按钮。

## 设计方案
- 各系统的 `getDigTarget` 只读当前实际作业目标；`DigTargetPresentation` 统一读取和解析，沿用原有权威判定、距离与优先级，不另外挑选最近对象。
- `DigHighlight` 使用独立 ShaderMaterial 重绘当前目标的不透明表面，提供基础染色、视角边缘光与扫光；深度测试保持开启，不透墙，关闭深度写入并使用 polygon offset 避免重叠闪烁。
- 普通模型复用网格几何体；实例模型和静态道路通过 `ModelVisualParts` 提供所属实体的只读部件，避免整批高亮。部件变换每帧跟随原模型；替换和删除时更新登记。
- 只增加当前目标各部件的绘制，不引入全屏后处理、阴影贴图或额外灯光；覆盖网格复用，销毁时只释放高亮材质，几何体仍归原模型所有。
- 房主为每位客人的 HUD 下发可选 `digTarget`（系统标识和落点）；客人按指定系统、精确落点找模型，只播放效果，不运行挖掘结算。旧快照缺字段时隐藏；超过一秒未收到更新时隐藏，移动和切工具立即清除旧目标。
- 高亮是持续状态，不需要动作上行或一次性事件补播；恢复连接后由后续 HUD 恢复。存档格式与 `SAVE_VERSION` 不变，HUD 字段可选，无需破坏性协议升级。

# 游戏模式
## 背景
为希望持续经营岛屿的玩家提供可复活的悠然模式，同时保留求生规则。

## 需求描述
- 模式名称为悠然／求生，首次默认悠然；本机记住新档模式偏好，刷新后保留。
- 两种模式的饱食、水分自然消耗与动物攻击力一致。
- 悠然死亡沿用联机流程：复活石优先，否则部分随身物品掉落，倒计时后在复活落点重生，工具及其等级保留，其余背包物品、装备与弹药按既有联机规则重置，世界进度保留。悠然不触发单机首次死亡庇佑或随机庇佑。
- 悠然无法获得荒岛传承点；死亡结算和放弃旧档结算统一返回零。已有传承及其增益不删除。
- 模式绑定存档，继续游戏时隐藏模式按钮和文本，不允许更改。旧档无字段时视为求生。

## 设计方案
`GameMode.ts` 管理模式类型与新档偏好；`SaveData.gameMode` 为可选字段，SAVE_VERSION 不变。Game 恢复存档时优先采用存档模式，仅新世界读取启动选项。

开始页无存档时显示一行轻量切换。开始新游戏及开新档均进入 `NewGameDialog`，说明所选模式、开局后不能切换；悠然明确说明无法获得传承点。有旧档时同时说明原世界会被替换及旧档能结算的传承点，结算资格只取决于旧档模式。

取消弹窗或形象设置不删除存档、不发点；实际开始新档时才结算原档并清档。模式选择持久化与世界存档分离，更改新档偏好不会修改旧档。

联机保持原有死亡复活机制，房主新建世界可选模式，续档隐藏选择并锁定存档模式；欢迎包随全量存档同步模式，死亡掉落、倒计时、数值和事件继续由房主权威结算与回流。悠然联机存档退出后也不能通过重开或单机继续获取传承点。

死亡复活落点统一遵循 [营地复活](respawn.md) 的床、火堆、工作台、出生点优先级。

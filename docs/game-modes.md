# 游戏模式
## 背景
为希望持续经营岛屿的玩家提供可复活的悠然模式，同时保留求生规则。

## 需求描述
- 模式名称为悠然／求生，首次默认悠然；本机记住新档模式偏好，刷新后保留。
- 两种模式的饱食、水分自然消耗与动物攻击力一致。
- 悠然死亡沿用联机流程：复活石优先，否则部分随身物品掉落，倒计时后在复活落点重生，工具及其等级保留，其余背包物品、装备与弹药按既有联机规则重置，世界进度保留。悠然不触发单机首次死亡庇佑或随机庇佑。
- 悠然无法获得荒岛传承点；死亡结算和放弃旧档结算统一返回零。已有传承及其增益不删除。
- 模式绑定存档，继续游戏时隐藏模式按钮和文本，仅允许在单机游戏设置中从求生永久转为悠然。旧档无字段时视为求生。

## 设计方案
`GameMode.ts` 管理模式类型与新档偏好；`SaveData.gameMode` 为可选字段，SAVE_VERSION 不变。Game 恢复存档时优先采用存档模式，仅新世界读取启动选项。

开始页无存档时显示一行轻量切换。开始新游戏及开新档均进入 `NewGameDialog`，模式选择行保留「游戏模式」文字，并在胶囊选项左侧同行展示所选模式的彩色标签：悠然为「可复活」（绿）、「无传承」（灰），求生为「不可复活」（红）、「有传承」（金）；弹窗不再有模式描述文字，也不提示求生可永久转为悠然，转换入口统一在设置内（见「游戏内永久转换」）。开始页与创建房间的模式选择行同样如此。有旧档时同时说明原世界会被替换及旧档能结算的传承点，结算资格只取决于旧档模式。

取消弹窗或形象设置不删除存档、不发点；实际开始新档时才结算原档并清档。模式选择持久化与世界存档分离，更改新档偏好不会修改旧档。

联机保持原有死亡复活机制，房主新建世界可选模式，续档隐藏选择并锁定存档模式；欢迎包随全量存档同步模式，死亡掉落、倒计时、数值和事件继续由房主权威结算与回流。悠然联机存档退出后也不能通过重开或单机继续获取传承点。

死亡复活落点统一遵循 [营地复活](respawn.md) 的床、火堆、工作台、出生点优先级。

## 游戏内永久转换

- 当前模式展示在设置面板底部「继续游戏」按钮上（如「继续游戏: 悠然模式」）。设置的「游戏」页不再展示当前模式说明块；单机求生存档的玩家存活时在该页可选择「转为悠然模式」，悠然存档与联机房主、客人的设置均不显示模式转换区域。
- 转换入口收起时仅显示「转为悠然模式」按钮，不带说明文案；点击后才在设置内展开说明，勾选理解不可逆及传承点影响后，才启用「确认转为悠然」。可随时选择「暂不转换」或关闭设置；未确认不改变游戏。
- 转换保留世界、建筑、物品、生存天数及已有传承增益；本局全部生存天数不再结算传承点，转换时也不提前结算。悠然死亡复活仍有随身物品损失，饥渴与伤害不变。
- 联机不支持模式转换，方法层同时拒绝房主和客人调用。单机转换后再开放联机时，欢迎包携带已转换的悠然存档；无需新增动作、事件或快照字段。
- Game 只暴露只读模式和单向转换方法，不提供转回求生的入口。确认时再次校验身份、模式与存活状态；先将悠然模式写入存档，写入失败展示可重试错误，成功后切换运行时模式并通知已保存。SAVE_VERSION 不变，旧存档仍按缺省求生读取。
- 手机端说明区可滚动，转换与取消按钮至少 44px；确认勾选默认关闭。
- 点击开启多人模式后，在创建房间的等待期间立即隐藏整个模式转换区域，卸载并清除未完成的确认与勾选状态。创建失败后恢复单机入口，需重新确认；创建成功后继续隐藏。

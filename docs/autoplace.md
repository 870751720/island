# 限定位置自动安放

## 背景

围栏(`fence.md`)引入了「限定位置 + 自动安放」的放置体验:整数格网吸附、面前落点常驻预览、站定自动放置、一次停止移动只放一个。而其余可放置道具(木箱/铁箱、工作台、床、神龛类、饵料桶、酿酒桶、净水器、冶炼炉、纺织机、烹饪台、熄灭的火堆、挖回的浆果丛/灌木丛/草丛/蚯蚓窝)仍是背包里点「使用」立刻放在玩家脚下的自由坐标,摆放不整齐、无预览、体验与围栏割裂。

## 需求描述

上述道具全部对齐围栏体验:

- **限定位置**:与围栏共用同一整数格网(`FENCE_GRID = 1`),落点吸附到玩家面前一格的**格中心**;位置校验统一为:干地基础条件(不在游泳/离水 1 米外/不在水里/1 米内无资源点)+ 落点同格被任何已放置实体占据即不可放;净水器保持湿沙滩限定。
- **点「使用」直接放置**:背包里点「使用」与围栏一致——在面前附近一圈格中心里选**就近最优的可放格**直接放下;全都放不下时用提示(toast)给出原因。
- **工具按钮逐个切入**:工具循环里背包中每种可放置道具(含木围栏/石围栏/围栏门)各占一格,按背包顺序排在普通工具之后,点工具按钮逐个切换;图标用各自物品图标,角标显示剩余个数。手持时手里举着该物体的真实建模(整体缩到最大边约 0.3),面前落点常驻半透明幽灵预览,**绿=可放、红=不可放**,附近一圈全放不下时头顶显示不可放原因(与「需要斧子」同款提示)。
- **站定自动安放**:手持站定不动累计进度(统一 2 秒),走满自动放置,头顶圆环走进度;移动即复位,一次停止移动只放一个;切其他工具或道具耗尽即结束安放。
- 预览模型复用各实体/资源点的真实程序化建模,统一换成半透明幽灵材质。
- **校验返回原因**:各系统 `canPlaceAt` 返回 `null`(可放)或原因短语(如「离水太近」「被树挡住」「被浆果丛挡住」「这格已经放了东西」「要放在海边湿沙滩上」,资源点占位会点名具体东西),红色预览、头顶提示与放置失败 toast 共用;落点可放但放置仍失败时,若道具已不在背包,提示「背包里已经没有这个道具了」。

## 设计方案

- **通用基座** `src/game/systems/AutoPlace.ts`:`AutoPlaceSystem` 持有 `ResourceKind → AutoPlaceDef` 注册表,`AutoPlaceDef = { valid(actor,x,z), buildPreview(), place(actor) }`。进度计时、原地一次限制(`lastPlaceX` 记位、移动复位)、预览生成与绿/红切换、忙碌让位(`isSessionBusy(..., 'autoPlace')`)全部在基座内,各系统只提供校验与模型。
- **落点**:`snapAheadCell(actor)` 取玩家面前 0.9 处吸附到最近整数格中心;`Game.autoPlaceCell` 再查地形高度得到世界坐标,作为各 `useXxx` 的统一落点传入。
- **注册**:`Game.registerAutoPlaceDefs()` 集中注册全部可安放道具;预览模型经 `buildGhost` 在一次性场景里复用实体构造器(木箱/床/工作台/桶/炉/机/烹饪台/火堆/神龛)或 Props 的建模函数(丛/蚯蚓窝)构建,统一接管材质。
- **各系统改造**:各系统把原私有 `canPlace`(取玩家脚下)改为公开 `canPlaceAt(actor, x, z)`(取指定落点),`use/place` 增加落点参数;`CampfireSystem` 新增 `placeDead`(放置熄灭的火堆道具,放下时未点燃),`Game.useDeadCampfire` 为其共用入口。净水器的湿沙滩限定保持不变,只是判定点从脚下改为落点格。
- **UI**:背包「使用」对可安放道具统一路由到 `Game.useAutoPlaceItem(kind)`(就近最优格直接放置,漂流瓶/信/种子/围栏仍走原入口);`Backpack.isUsable` 补入 `deadCampfire`;工具按钮循环与角标支持安放工具(角标为手持道具剩余个数)。
- **进度环**:`Game` 头顶进度环优先取 `autoPlace.getPlaceProgress`,围栏沿用原逻辑。
- **联机**:不改变同步协议。放置动作仍走各自 `useXxx` 上行、房主权威结算;安放工具的切换走既有 `tool` 动作;新增 `useDeadCampfire` 动作;客人端 `updatePreviewFor` 本地驱动预览(同围栏模式)。详见 `multiplayer.md`。
- **存档兼容**:不改变任何持久化 ID 与存档结构,`SAVE_VERSION` 不变(仅放置坐标来源从脚下自由坐标变为格中心)。

- 2026-09-09(迭代):校验改为返回原因并点名挡住的资源点;工具循环改为按道具逐格切换(每种可放置道具单独切入,图标/角标/手持模型跟随具体道具),围栏/围栏门一并并入同一机制;背包「使用」改为与围栏一致的就近最优格直接放置(替换原「进入安放模式等待站定」方案,移除 `autoPlaceHold` 动作)。
- 2026-09-09(迭代):手持模型统一为各物体真实建模缩小(`Player.setPlaceModel` 动态挂载,替代围栏的原静态手持模型),远程玩家经姿态快照 `PlayerState.placeKind` 同步;`tool` 动作携带具体道具种类。
- 2026-09-09(迭代):**安放判定条件全部统一**。新增共享占格服务 `src/game/systems/PlaceOccupancy.ts`,11 个放置系统(工作台/箱/饵料桶/酿酒桶/净水器/冶炼炉/纺织机/烹饪台/床/火堆/神龛)各实现 `blocksCell(p)` 注册进去;各系统 `canPlaceAt` 的同类间距特殊值(神龛 1.2、床 1.1、其余 0.8/0.9)全部删除,统一为「落点同格(1 米内)被任何已放置实体占据即不可放」,预览与结算共用同一份判定;原火堆/工作台没有的占格检查一并补上。放置失败提示补漏:道具已不在背包时明确提示,不再笼统「这里放不下」。

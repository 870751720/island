# 限定位置自动安放

## 背景

围栏(`fence.md`)引入了「限定位置 + 自动安放」的放置体验:整数格网吸附、面前落点常驻预览、站定自动放置、一次停止移动只放一个。而其余可放置道具(木箱/铁箱、工作台、床、神龛类、饵料桶、酿酒桶、净水器、冶炼炉、纺织机、烹饪台、熄灭的火堆、挖回的浆果丛/灌木丛/草丛/蚯蚓窝)仍是背包里点「使用」立刻放在玩家脚下的自由坐标,摆放不整齐、无预览、体验与围栏割裂。

## 需求描述

上述道具全部对齐围栏体验:

- **限定位置**:与围栏共用同一整数格网(`FENCE_GRID = 1`),落点吸附到玩家面前一格的**格中心**;位置校验沿用各系统原规则(干地、离其他建筑/资源点足够远、神龛互斥、净水器湿沙滩等)。
- **点「使用」进入安放模式**:背包里点「使用」不再立刻放置,而是进入手持安放模式;面前吸附格中心常驻半透明幽灵预览,**绿=可放、红=不可放**(不隐藏,玩家能看出为什么放不了)。
- **站定自动安放**:站定不动累计进度(统一 2 秒),走满自动放置,头顶圆环走进度;移动即复位,一次停止移动只放一个;切其他工具自动退出安放模式;道具耗尽自动退出。
- 预览模型复用各实体/资源点的真实程序化建模,统一换成半透明幽灵材质。

## 设计方案

- **通用基座** `src/game/systems/AutoPlace.ts`:`AutoPlaceSystem` 持有 `ResourceKind → AutoPlaceDef` 注册表,`AutoPlaceDef = { valid(actor,x,z), buildPreview(), place(actor) }`。进度计时、原地一次限制(`lastPlaceX` 记位、移动复位)、预览生成与绿/红切换、忙碌让位(`isSessionBusy(..., 'autoPlace')`)全部在基座内,各系统只提供校验与模型。
- **落点**:`snapAheadCell(actor)` 取玩家面前 0.9 处吸附到最近整数格中心;`Game.autoPlaceCell` 再查地形高度得到世界坐标,作为各 `useXxx` 的统一落点传入。
- **注册**:`Game.registerAutoPlaceDefs()` 集中注册全部可安放道具;预览模型经 `buildGhost` 在一次性场景里复用实体构造器(木箱/床/工作台/桶/炉/机/烹饪台/火堆/神龛)或 Props 的建模函数(丛/蚯蚓窝)构建,统一接管材质。
- **各系统改造**:各系统把原私有 `canPlace`(取玩家脚下)改为公开 `canPlaceAt(actor, x, z)`(取指定落点),`use/place` 增加落点参数;`CampfireSystem` 新增 `placeDead`(放置熄灭的火堆道具,放下时未点燃),`Game.useDeadCampfire` 为其共用入口。净水器的湿沙滩限定保持不变,只是判定点从脚下改为落点格。
- **UI**:背包「使用」对可安放道具统一路由到 `Game.holdAutoPlaceItem(kind)` 进入安放模式(漂流瓶/信/种子/围栏仍走原入口);`Backpack.isUsable` 补入 `deadCampfire`。
- **进度环**:`Game` 头顶进度环优先取 `autoPlace.getPlaceProgress`,围栏沿用原逻辑。
- **联机**:不改变同步协议。放置动作仍走各自 `useXxx` 上行、房主权威结算;新增 `autoPlaceHold [kind|null]` 动作把客人的安放模式状态同步到房主侧(用于忙碌让位),新增 `useDeadCampfire` 动作;客人端 `updatePreviewFor` 本地驱动预览(同围栏模式)。详见 `multiplayer.md`。
- **存档兼容**:不改变任何持久化 ID 与存档结构,`SAVE_VERSION` 不变(仅放置坐标来源从脚下自由坐标变为格中心)。

# 玩家交互动作

## 背景

整根四肢绕肩髋摆动、双臂同频和姿势瞬切让角色显得僵硬。手机俯视画面需要通过身体轮廓、重心和节奏表现不同交互。

## 需求描述

- 砍树、凿石体现蓄力、快速发力、短暂停顿和回收；双手握住同一根工具柄，右手带动工具，左手跟随柄下方的第二握点。
- 拾取屈膝俯身并分为伸手、合拢抓握、停顿、屈肘拉回和松手复位，掌部轻微收拢强化抓取轮廓；制作一手操作一手辅助，烹饪表现单手搅动。
- 吃喝屈肘抬手，头部配合；抛竿一次前挥后衔接持竿；射箭和套索按实际右手工具展示，挥剑带动腰肩并保留移动。
- 走路按实际位移摆腿，带屈膝和轻微重心起伏；游泳采用屈肘划水；各动作进入退出平滑衔接。
- 男女模型、穿戴装备、本地及联机角色使用同一套动作；保持手机触控操作方式。

## 设计方案

- `PlayerModel` 增加腰部组、两个肘关节和两个膝关节，使用现有低面数几何体分段塑形；每人仅多两个上臂网格，不加载动画文件或引入 AnimationMixer。
- `PlayerAnimator` 独立负责姿态求值，复用 Euler 缓冲，每帧固定数量关节更新。指数平滑不依赖固定帧率，作业节奏使用动作开始后的局部时间。循环作业采用分段平滑曲线；挥剑/射箭保持 0.35 秒表现窗口，抛竿保持 0.7 秒。
- `ArmReach` 以两段手臂长度解析求解肩肘姿态，砍树和挖矿时右掌沿胸前轨迹运动，左掌目标从右前臂及工具柄的真实变换推导。进入动作时逐渐建立握点约束，退出后恢复普通姿态。斧、镐、铲和锄均沿用相同工具安装角度；不增加模型网格、每帧迭代求解或物理约束。
- 上身围绕腰部转动，头部轻微反向补偿，手肘与腿膝配合。衣服和背包挂腰部，工具及安放道具挂右前臂，伤口挂随动表面；游泳、睡眠、死亡收起手持物。睡眠/死亡释放辅助关节，重生重置动画。
- 视觉偏移限制在模型内部；移动、碰撞、资源产出、攻击判定及存档保持原有规则。走路速度取水平实际位移，撞墙时不再按输入持续大幅摆腿。未引入脚底 IK，转向、坡地和网络插值下仍可能有轻微滑步。
- 房主和客人沿用动作上行、动作类型快照回流及既有玩法事件；各端从观察到动作时开始本地播放，网络延迟允许相位差，不新增动画相位同步。详见 `multiplayer.md`。
- 验收使用 TypeScript 类型检查和生产构建；手机上的实际动作观感及联机显示由用户在线体验确认。

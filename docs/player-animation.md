# 玩家交互动作

## 背景

整根四肢绕肩髋摆动、双臂同频和姿势瞬切让角色显得僵硬。手机俯视画面需要通过身体轮廓、重心和节奏表现不同交互。

## 需求描述

- 砍树、凿石体现蓄力、快速发力、短暂停顿和回收；双手在身体右侧握住同一根工具柄，腰肩向右转动蓄力，再向前下方挥落；右手带动工具，左手跟随柄下方的第二握点。
- 采集屈膝俯身，双手持续伸在身前，错半拍左右拨动、向内扒拢，握拳略有松紧，身体轻微跟随晃动；制作一手操作一手辅助，烹饪表现单手搅动。
- 进食时双拳捧到嘴边，按实际嘴部位置求解肩肘；喝水保持抬手仰头。抛竿和持竿都在身前居中双手握住竿尾；射箭和套索按实际右手工具展示，挥剑带动腰肩并保留移动。
- 走路按实际位移摆腿，带屈膝和轻微重心起伏；游泳采用屈肘划水，身体前倾约 0.55 弧度，水线对齐实际头部中心，只露出上半个头并保留轻微浮动；各动作进入退出平滑衔接。
- 男女模型、穿戴装备、本地及联机角色共用动作系统；原版男孩使用专用肩肘与膝踝步态，女孩保留现有节奏；保持手机触控操作方式。

## 设计方案

- `PlayerModel` 增加腰部组、两个肘关节和两个膝关节，使用现有低面数几何体分段塑形；每人仅多两个上臂网格，不加载动画文件或引入 AnimationMixer。
- `PlayerAnimator` 独立负责姿态求值，复用 Euler 缓冲，每帧固定数量关节更新。指数平滑不依赖固定帧率，作业节奏使用动作开始后的局部时间。循环作业采用分段平滑曲线；挥剑/射箭保持 0.35 秒表现窗口，抛竿保持 0.7 秒。
- `ArmReach` 以两段手臂长度解析求解肩肘姿态，砍树和挖矿时右掌沿偏右的抬起—前下挥落轨迹运动，配合腰肩向右转动和侧倾，形成双手右侧握持轮廓，左掌目标从右前臂及工具柄的真实变换推导。进入动作时逐渐建立握点约束，退出后恢复普通姿态。斧、镐、铲和锄均沿用相同工具安装角度；不增加模型网格、每帧迭代求解或物理约束。
- 上身围绕腰部转动，头部轻微反向补偿，手肘与腿膝配合。衣服和背包挂腰部，工具及安放道具挂右前臂，伤口挂随动表面；游泳、睡眠、死亡收起手持物。睡眠/死亡释放辅助关节，重生重置动画。
- 视觉偏移限制在模型内部；移动、碰撞、资源产出、攻击判定及存档保持原有规则。走路速度取水平实际位移，撞墙时不再按输入持续大幅摆腿。未引入脚底 IK，转向、坡地和网络插值下仍可能有轻微滑步。
- 房主和客人沿用动作上行、动作类型快照回流及既有玩法事件；各端从观察到动作时开始本地播放，网络延迟允许相位差，不新增动画相位同步。详见 `multiplayer.md`。
- 验收使用 TypeScript 类型检查和生产构建；手机上的实际动作观感及联机显示由用户在线体验确认。

- 鱼竿模型相对右手沿竿身平移 0.3，使主手握在尾部；副手仍追踪同一竿柄的第二握点，竿梢取世界坐标，所以钓线继续连在正确位置。
- `SwordTrail` 为每人复用一份 16 三角形带状网格，在挥剑 0.03–0.28 秒采样实际剑刃位置，加色材质产生闪光，停止挥动后 0.12 秒内淡出。无额外灯光、纹理或后处理；隐藏时不绘制，死亡、睡眠、游泳、重生清空，玩家销毁时释放。
- 游泳每帧按变换后的头部中心校正玩家高度，避免倾斜或动作过渡导致整个头露出；各端依据本地水位和模型独立执行。水体仍使用原有透明材质，水下身体可透过水面看到。

- 所有单手持物统一由角色自身右手主握（朝向 +Z 时为局部 -X），双手动作由左手辅助；鱼竿、弓、剑、采集工具、套索、围栏及安放道具共用此规则。姿态侧向分量与握点坐标按角色左右定义适配，双手捧食、采集节奏及玩法结算不变。

- `BoyGait.ts` 为原版男孩计算分段步态：肩部摆动时肘部保持自然弯曲并错相屈伸；摆腿中段屈膝收脚，前伸落地时伸膝。脚踝反向补偿髋膝合成角度，摆动时适当抬脚尖。速度权重和平滑沿用现有逻辑，停步回到微屈膝、屈肘姿态。
- 脚踝节点挂袜子和鞋，静止挂点与原位置一致，不增加绘制网格。作业和游泳时清零步态脚踝目标，睡眠、死亡、重生统一释放或重置；女孩及整套预览不使用此步态。无脚底锁定或地面 IK，不保证足部精确贴地。

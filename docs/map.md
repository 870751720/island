# 玩家地图

## 背景

长条岛屿与联机玩法需要一个适合手机触屏的地图入口，方便玩家确认队友和主要生存设施的相对位置。

## 需求描述

- 在右上角设置按钮右侧增加自绘地图按钮。
- 点击入口后按钮消失并显示小地图；点击小地图后在屏幕中央显示大地图。
- 大地图打开时点击地图外区域，关闭大地图和小地图并恢复地图按钮。
- 地图始终以本地玩家为中心，显示全部存活玩家的位置与名字，以及工作台、床、火堆的位置。

## 设计方案

- `Game.getMapSnapshot()` 提供只读地图快照，包含直接从当前 `IslandTerrain` 高度与水体判定采样得到的 100×500 地形栅格、玩家坐标/昵称/存活状态和三类设施坐标；地形只采样一次，不把地图表现状态写入存档。
- `MapPanel.tsx` 将真实地形栅格绘制成海水、沙滩、草地、高地和内陆水洼贴图，再使用 SVG 叠加自绘设施/玩家标记。地图外区域使用与采样海面相同的纯色，不额外叠加虚构海浪。小地图为右上角 136px 触控区域，大地图按手机视口等比例放大并以遮罩承接地图外关闭操作。
- 大小地图采用相同的正方形比例、本地玩家中心和约 60 米世界可视范围，大地图只放大显示尺寸，不改变地图内容。打开期间每 200ms 从游戏实例读取一次快照，让标记平滑跟随且不增加主 HUD 的逐帧 React 更新负担。
- 地图入口与小地图沿用非必要 HUD 的闲置淡出规则，触控入口不小于 44px。

### 联机

- 房主端地图读取权威会话与世界设施状态。
- 客人端读取已有玩家姿态快照和世界设施增量在本机形成的状态，不新增动作上行或地图专用网络协议；昵称与坐标随既有快照回流。

## 迭代记录

- 地图底图改为直接采样当前程序化地形，移除与实际海岸不一致的椭圆示意图。

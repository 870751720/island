# 玩家地图

## 背景

长条岛屿与联机玩法需要一个适合手机触屏的地图入口，方便玩家确认队友和主要生存设施的相对位置。

## 需求描述

- 在右上角设置按钮右侧增加自绘地图按钮。
- 点击入口后按钮消失并显示小地图；点击小地图后在屏幕中央显示大地图。
- 大地图打开时点击地图外区域，关闭大地图和小地图并恢复地图按钮。
- 地图始终以本地玩家为中心，显示全部存活玩家的位置与名字，以及工作台、床、火堆的位置。

## 设计方案

- `Game.getMapSnapshot()` 提供只读地图快照，包含岛屿尺寸、玩家坐标/昵称/存活状态和三类设施坐标；不把地图表现状态写入存档。
- `MapPanel.tsx` 使用 SVG 绘制海面、岛屿和自绘设施/玩家标记。小地图为右上角 136px 触控区域，大地图按手机视口自适应并以遮罩承接地图外关闭操作。
- 地图采用本地玩家居中的坐标换算；小地图显示附近视野，大地图自动缩放到整座岛均可见，便于查看远处设施和队友。打开期间每 200ms 从游戏实例读取一次快照，让标记平滑跟随且不增加主 HUD 的逐帧 React 更新负担。
- 地图入口与小地图沿用非必要 HUD 的闲置淡出规则，触控入口不小于 44px。

### 联机

- 房主端地图读取权威会话与世界设施状态。
- 客人端读取已有玩家姿态快照和世界设施增量在本机形成的状态，不新增动作上行或地图专用网络协议；昵称与坐标随既有快照回流。

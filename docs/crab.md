# 沙滩螃蟹

## 背景

海岸线只有静态场景,缺少活物点缀。希望沙滩边有少量螃蟹来回爬动,增加氛围与探索乐趣。

## 需求描述

- 沙滩边刷新少量螃蟹(有程序化模型)。
- 螃蟹只在沙滩附近走动:不进海、不进岛内草地。

## 设计方案

- 模块:`src/game/entities/Crab.ts`,`Crabs implements Updatable`,在 `Game.ts` 构造时生成并加入主循环。
- 模型:程序化低多边形(黏土质感)——扁圆壳 + 腹甲 + 双眼柄 + 8 条腿 + 2 只钳子,腿/钳均为独立 mesh 供运行时动画。
- 活动范围:地形高度带 `[0.02, 0.14]`(湿沙以上、草地以下的沙滩带)。所有移动(游荡、逃跑、选目标)每步都校验目标点高度是否在带内,越界即换向/换目标,从根本上保证不进海也不进草地。
- 出生:沿随机角度从岛外向内找第一处连续落在沙滩带上的点;数量随岛尺寸取 5~9 只。
- 行为:随机选 3m 内沙滩目标慢速横行(身体朝向与移动方向垂直,符合螃蟹横行),到点后随机歇息 1~4 秒;玩家靠近 2.2m 内会加速逃离(直路被带边界挡住时沿切线绕行)。
- 动画:移动时腿交替摆动、身体轻微起伏;受惊时钳子快速开合。
- 死亡与刷新:提供 `killNearby(pos, range)` 击杀接口(供后续攻击手段调用,当前无调用方);被击杀后模型消失,25 秒后在海岸其他位置重新刷新,维持沙滩螃蟹数量。

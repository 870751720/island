# 飞鸟

## 背景

岛上已有螃蟹、蝴蝶等小生物增添生气,但空中和地面缺少大一些的活物。鸟是荒岛氛围的经典元素:远处盘旋、偶尔落地觅食、被惊扰时四散飞走。

## 需求描述

往场景中添加一群鸟,行为要求:

- 大部分时间在空中飞来飞去;
- 偶尔飞到浆果丛附近落地走走;
- 也可能停在空地上踱步;
- 也可能落在水洼边;
- 玩家靠近时被惊飞。

## 设计方案

- 实现:`src/game/entities/Birds.ts`,挂在 `Game` 循环中,共 5 只,不与任何玩法系统交互(纯氛围)。
- 建模:沿用程序化黏土风格 —— 椭圆身体 + 头喙(低头啄食用)+ 扁锥尾 + 两片平面轮廓长翅(左右 pivot 绕身体纵轴扑动,镜像侧旋转取反保证同上同下),与蝴蝶同款方案。
- 状态机(每只鸟独立):
  - `fly` 巡航:朝目标点飞行,高度平滑趋向「地形 + 巡航高度」(带爬升速度上限);抵达目标后 35% 概率选落脚点进入降落,否则换一个巡航点。
  - `land` 降落:较慢速度朝落点滑降,接近后落地进入踱步。
  - `walk` 踱步:在落脚点周围随机小步走动,间隙低头啄食,收翅站姿;停留 6~18 秒后起飞回巡航。
  - `flee` 惊飞:仅地面踱步中的鸟触发(飞行、降落、滑翔中的鸟不怕人),玩家水平距离 < 5 时背离玩家直线急飞并爬升约 2.8 秒,随后回巡航。
- 落脚点权重:浆果丛旁 40%、水洼边缘 30%(水面圆盘外沿)、空地 30%(玩家周围离水干地,随机重试采样)。
- 巡航目标选在玩家周围 8~26 单位的环内(并 clamp 在岛内、地形高于水线),保证玩家在正交相机视野内总能看到鸟,又保持自由飞翔的观感。
- 朝向约定与蝴蝶一致:heading = atan2(dx, dz),rotation.y 使身体 +z 朝运动方向;惊飞方向是 atan2(dz, dx) 约定,需换算。
- 移动端性能:每只鸟约 6 个 mesh、翅为平面轮廓几何,5 只总量极低;投影与阴影开销可忽略。

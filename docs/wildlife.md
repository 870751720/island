# 野生动物(兔/羊/鹿/熊)

## 背景

岛上此前只有螃蟹(沙滩)与小鸟/蝴蝶,草地生态单一。需要增加陆地野生动物:见人就跑的猎物与会主动攻击玩家的威胁。

## 需求描述

- 新增四种草地动物:**兔子、绵羊、鹿**(玩家靠近即逃跑)与**熊**(会追击并扑击玩家造成伤害)。
- 均可用弓箭猎捕,击杀后掉落兽肉;熊更耐打(需多箭)且掉肉更多。
- 死亡后在岛上其他草地重新刷新;不进沙滩与水域。

## 设计方案

- `src/game/entities/WildlifeModels.ts`:四种低多边形黏土质感模型(程序化拼装),统一返回 `{ group, legs, head, tail }` 供动画。
- `src/game/entities/Wildlife.ts`:`Wildlife` 管理器,物种配置表驱动(数量、游荡/逃跑/追击速度、感知范围、熊的扑击距离/伤害/冷却、HP、掉肉份数、刷新时间)。
  - 行为:游荡(选草地目标点走一段歇一段)→ 玩家进入感知范围后,食草动物背向逃跑、熊追击;熊进入扑击距离按冷却造成伤害(头部前顶动画)。
  - 移动只在草地高度带(`y ≥ 0.16` 且岛内)内,前方不可走时试切线方向。
  - 对外接口:`nearestAlive`(弓箭索敌)、`damageNearby`(箭矢命中,返回击倒物种/受伤/未命中)、`lootOf`(按物种掉肉份数)。
- 弓箭(`BowSystem`):索敌范围加入野生动物;击杀掉落 `gameMeat`(按物种 1~3 份);受伤未死不掉肉、箭消失。
- 玩家受伤:`SurvivalSystem.damage(amount)`,熊扑击时由 Game 侧结算掉血 + 红色粒子 + 音效;玩家死亡或游泳时不触发追击。
- 新道具:`gameMeat` 兽肉(生吃 +20 饥饿)与 `cookedGameMeat` 烤兽肉(+42),可在火堆烹饪;含掉落模型。

# 相机模式(拍照模式)

## 背景

玩家在荒岛上建造、经营出自己的风景后,有把画面拍下来分享出去的诉求。此前的分享能力只在死亡结算卡(docs/share-card.md)中,无法在存活时主动拍照。相机模式提供一个自由取景、拍照并生成引流分享卡的玩法外功能。

## 需求描述

- 游戏内设置面板新增「📷 相机模式」入口。
- 进入后隐藏全部玩法 UI(摇杆、HUD、按钮、飘字、头顶气泡等)。单机模式下世界模拟冻结(时间不流逝、玩家无敌);联机模式下世界照常运行(不暂停)。
- 取景交互:
  - 单指拖动平移视角(脱离玩家跟随,以进入位置玩家为圆心限制漂移半径 45);
  - 双指捏合缩放(0.6×–5×);
  - 双指旋转绕注视点 360° 水平旋转,双指上下滑动俯仰(约 12° 低角度 ~ 85° 近俯视);
  - 底部仅保留快门,全部取景操作由手势完成;顶部:退出按钮与当前倍率。
- 点击快门:白闪反馈后抓取当前画面,合成分享卡并进入预览;预览可「分享」「保存」「重拍」。
- 分享卡:拍照画面为底,顶部「游戏名 + 生存第 N 天」水印,底部渐晕 + 从 40 条文案池随机取一条(占位符 `{day}` 替换为天数)+ 指向线上地址的引流二维码。
- 分享走 `navigator.share`(文件 + 文案),不支持时提示长按图片保存;「保存」直接下载 PNG。

## 设计方案

- **相机状态** `src/game/systems/PhotoCamera.ts`:`PhotoCamera` 持有注视点/缩放/旋转角,提供 `pan/zoomBy/rotate/offset`;纯本地表现状态,不进存档、不联机同步。
- **Game 接入**(`src/game/Game.ts`):
  - `updateCamera()` 相机模式下注视 `PhotoCamera.center`,位置由 `offset()`(基础斜俯偏移绕竖轴旋转 yaw)直接硬置以保证拖动 1:1 跟手;常规模式保持原有跟随插值,退出时自然平滑回到玩家。
  - 缩放用 `camera.zoom` + `updateProjectionMatrix()`,不改动 `VIEW_SIZE` 与 resize 逻辑。
  - `requestPhoto(cb)`:立即渲染一帧再 `toDataURL` 读回,不依赖 `preserveDrawingBuffer`。
  - 进入时 `setJoystick(0,0)` 清掉移动输入(摇杆层随 UI 卸载收不到抬起事件)。
- **UI 层**:
  - `src/ui/PhotoMode.tsx`:全屏取景层,Pointer Events 手势(触点集合 + 单指起点/双指基线,触点数变化后重算基线);控制栏圆钮半透明深色底白描边,快门 72px。
  - `src/ui/photoCard.ts`:40 条文案池 `CAPTIONS`、`renderPhotoCard()`(离屏 2D canvas 合成)、`sharePhotoCard()`;二维码/游戏名/线上地址复用 `shareCard.ts` 的导出。
  - `src/ui/GameplayUI.tsx`:`photoMode` 状态统一条件渲染隐藏各 UI 兄弟节点;死亡时自动退出相机模式。
- **联机**:相机模式只影响本地相机与 UI,不上行任何动作、不同步状态;房主/客人可各自进入互不干扰。快照照常回流,退出后相机回到跟随本地玩家。

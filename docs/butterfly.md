# 蝴蝶氛围生物

## 背景

岛上只有螃蟹一种小动物,植被区缺少生机感。希望浆果丛、树、灌木丛旁偶尔有蝴蝶飞舞,增加氛围;玩家靠近时蝴蝶受惊飞走消失,避免与采集交互冲突。

## 需求描述

- 蝴蝶偶尔出现在浆果丛 / 树 / 灌木丛旁,围绕植被缓缓盘旋。
- 玩家靠近(约 2.6 格内)时,蝴蝶背离玩家方向快速振翅飞升,飞出一段距离后消失。
- 消失后延迟一段时间在别的植被旁重新出现。

## 设计方案

- `src/game/entities/Butterflies.ts`,与 `Crabs` 同构的池化实体系统,实现 `Updatable`,在 `Game.ts` 中随游戏循环更新。
- 建模:程序化低多边形——细长椭球身体 + 两片三角面翅膀(双面渲染),绕身体纵轴对拍模拟扑翼;配色从浅粉/鹅黄/天蓝等柔和色板随机取。
- 行为状态机:
  - 盘旋:以植被旁随机点为锚,用利萨如曲线绕锚点漂移,扑翼频率低;
  - 惊飞:玩家进入 `FLEE_RANGE` 后沿背离玩家方向水平飞离并上升,扑翼频率加倍,约 2.5 秒后隐藏并进入重生倒计时;
  - 重生:`RESPAWN_TIME`(12 秒)后从 `props.list` 随机选 berry/shrub/tree 作为新锚点重新出现。
- 常驻 6 只,模型复用不销毁,仅切换 `visible`。
- 朝向由每帧水平位移平滑推得,身体纵轴对准运动方向。

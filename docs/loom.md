# 纺织机与布料

## 背景

中期材料链止步于绳线,高级床缺少一个专属的软材料。新增纺织机,把绳线自动织成布料,并让三级床用上布料。

## 需求描述

- 新增物品「布料」:由纺织机产出,不可直接制作。
- 工作台新增配方「纺织机」(需三级工作台):木头×15 + 树枝×5 + 绳线×5 + 皮毛×5,产物为纺织机道具,背包里点「使用」直接落在就近最优格(与冶炼炉同一套摆放规则,详见 autoplace.md)。
- 纺织机类似冶炼炉:靠近后按数量把背包里的绳线投入机内(也可随时取回还没织的绳线),每 2 根绳线自动织出 1 匹布料(每匹 6 秒),存放在机内待收取;织布时机内梭子左右穿行,空机时停住。
- 纺织机可被锄头整机挖走(命中数与冶炼炉一致),变回纺织机道具,机内剩余绳线与布料一并回到背包/掉落。
- 靠近纺织机时工具按钮变为纺织机图标,点击打开投料/收取面板;持锄头面对纺织机时按钮不劫持(意图是挖走)。

## 设计方案

- `src/game/entities/Loom.ts`:程序化建模(仿框架织布机:底部双轨 + 后倾立柱 + 斜撑,顶部绕线梁与前下方卷布辊之间张 9 根斜向经线,中部综片杆 + 枣核形梭子),织布时梭子左右穿行、综片上下提落,卷布辊随机内布料数变粗。
- `src/game/systems/LoomSystem.ts`:复用冶炼炉系统模式(放置校验/投料/收取/锄头挖回/权威端计时/网络增量);`LoomSave = { id, x, y, z, rotY, rope, cloth, tickLeft }`。
- `Inventory.ts`/`Items.ts`:新增 `cloth`(布料)与 `loom`(纺织机)道具;`Crafting.ts` 新增 `loom` 配方(`minBenchLevel: 3`)。
- `DropModels.ts`:布料为叠摞折布造型,纺织机为小木机架造型。
- `Game.ts`:`useLoom/loomFeed/loomCollect` 三个入口(客人端动作上行);HUD 快照 `nearLoom`/`loomInfo`;织布计时只在权威端(单机/房主)推进,客人端本地倒数做表现。
- 网络:世界段 `looms` 进 `WorldPatch`,动作 `useLoom/loomFeed/loomCollect` 进 `Actions.ts`(同冶炼炉约定)。
- 存档:`SaveData.looms`,缺省视为无,`SAVE_VERSION` 不变(向后兼容)。
- UI:`LoomPanel.tsx`(机内绳线/布料 + 织布进度 + 投入/收取按钮),`ToolButton` 纺织机模式(🪡,优先级 工作台 > 火堆 > 木箱 > 饵料桶 > 冶炼炉 > 纺织机 > 床)。

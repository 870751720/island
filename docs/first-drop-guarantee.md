# 首份燧石与经验书保底

## 背景

避免开荒玩家因连续未掉落燧石或经验书而卡住营火制作与工作台升级。

## 需求描述

- 每位玩家单局前2次完整采石至少产出1燧石，前3次击杀狼至少掉落1本冒险家的经验书。
- 两项保底独立且各只生效一次；自然提前掉出对应物品也结束该项保底，此后沿用燧石25%、狼经验书30%的普通概率。
- 采石以一个资源点完成一次采集为单位，不按挥镐次数或石头数量计数；包括碎石堆、岩石、铁矿与陨石。
- 剑、弓、归属玩家的狗协助击杀狼均计数，其他动物不计数。

## 设计方案

FirstDropGuarantee独立管理次数与结束标记，由PlayerSession持有。采石完成普通及双倍产出后统一结算，自然产出和保底产出不会重复给；满包走原有溢出掉落流程。狼在权威端生成战利品后补足保底，拾取前即结束保底，掉落丢失不重发。箱子、钓鱼、熊等其他来源不计入这两项来源限定的首份保底。

可选firstDrops字段随单机玩家及房主保存的各远程玩家会话持久化；读档与重连不重置，新局重置。旧档缺省为空，从更新后开始累计，不提高SAVE_VERSION。客人不自行抽取保底，沿既有动作上行与世界掉落同步接收结果。

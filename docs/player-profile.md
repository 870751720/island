# 玩家个人档案(昵称与性别)
## 背景
昵称原先只能在「加入房间」时输入,单机玩家没有名字;性别此前只有 GM 面板能改。需要一个玩家档案:昵称 + 性别,首次开始游戏前强制设置,之后可随时修改。
## 需求描述
- 首次点击「开始游戏 / 继续游戏 / 开新档」时弹出设置弹窗:昵称(≤8 字)+ 性别(男孩/女孩),性别选择需实时展示黏土小人 3D 模型;设置完成后无缝进入游戏。
- 已设置后想修改:开始界面面板右上角的头像徽章(👦/👧 + 昵称)点开同一弹窗,不新增按钮。
- 「加入房间」页不再有昵称输入框:昵称与性别统一来自档案,未设置时点昵称行可直接设置。
- 游戏内 GM 面板改性别时,同步写回个人档案。
## 设计方案
- 持久化:`src/game/playerProfile.ts`,localStorage key `island.profile.v1`,存 `{ name, gender }`;旧 key `island.nickname` 只作首次设置时的默认昵称迁移。
- UI:
  - `src/ui/ProfileSetup.tsx` 设置弹窗(首次无取消按钮,编辑态有取消);内嵌 `src/ui/PlayerPreview.tsx` —— 用 Three.js 单独小画布渲染 `createPlayerModel`,自转展示,`setGender` 切换显隐,无需重建模型。
  - `src/ui/StartScreen.tsx` 面板右上角头像徽章为修改入口;开始按钮在无档案时先弹设置,完成后接着进入原目标模式。
  - `src/ui/RoomLobby.tsx` 客人侧昵称行展示档案昵称,未设置时禁用「加入房间」并引导设置;房主昵称同样取自档案。
- 性别生效与联机:
  - 单机/房主:`Game` 构造恢复存档后,本地玩家性别以档案为准(`applySave` 后 `setGender(profile.gender)`),续档时改形象立即生效。
  - 客人:`NetGuest.join` 携带 `gender` 进 hello;房主 `NetHost.welcome` 对新角色应用该性别(断线恢复/认领旧角色沿用存档性别),之后随快照回流。
  - GM 改性别:本机角色同步 `saveProfileGender` 写回档案(客人端在动作上行前写本地档案)。

# 羊奶与牛奶

## 背景

成年驯养羊和野牛提供可持续乳品。驯养和持续投喂规则见 [动物驯养](animal-husbandry.md)。

## 需求描述

- 羊奶 `milk` 与牛奶 `cowMilk`：食用生命 +5、饥饿 +10、饥渴 +25；不可烤、煮或制鱼饵，两份同种奶可以酿一瓶现有奶酒。
- 只有成年、已驯养且爱心大于零的羊/牛产奶，每十分钟准备一份；未收取不累计，不要求套索或打桩。
- 小羊小牛成年后开始计时，旧版仅套索产奶不再生效。重新套住或解绳不重置产奶进度；爱心归零失去驯养时清除产物和进度。
- 头顶奶瓶提示可收取；站定在 2.2 米内自动挤奶，动作 0.6 秒，移动、游泳或其他交互占用时中断。手持剪刀时改为剪毛。

## 设计方案

`AnimalHusbandry` 按运行秒数统一推进奶毛计时，保存剩余时间及待收标记。`LivestockHarvestSystem` 维护每个玩家的采集进度，显示挤羊奶、挤牛奶或剪羊毛提示。`Game.harvestAnimal` 在房主验证成年、驯养、工具、距离和产物后结算入包，满包沿用发放掉落规则。

## 联机与存档

动物姿态携带 `milk` 与 `husbandry`，客人展示奶瓶、爱心和短毛状态。`harvestAnimal [animalId, wool]` 上行动作统一由房主结算，重复请求不能重复领取。保存新计时字段，旧档缺省为未驯养、无产物，保持 `SAVE_VERSION` 不变。

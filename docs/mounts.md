# 坐骑系统
## 背景
为手机触屏探索提供独立坐骑栏，首个坐骑为滑板。
## 需求描述
- 一级工作台消耗木头6、石头4、绳子2制作滑板，沿用装备制作完成自动装备规则；也可从背包点击“乘骑”，在角色坐骑栏点击“下骑”放回背包。背包满时保留乘骑状态。
- 滑板乘骑时陆地移速增加100%（基础5提升至10），与道路、冰面、天气和状态倍率相乘。虚拟摇杆操作保持一致。
- 涉水、游泳、站定作业、攻击、搬运设施、睡眠和死亡时暂时收起，恢复条件后自动乘骑。滑行不生成步行脚印。
- 平衡、压低重心、舒展三种程序姿态，移动时每5～9秒随机切换到另一姿态，停止时保持平衡站姿，关节平滑过渡。
## 设计方案
- Equipment新增mount栏位和skateboard持久化ID；复用现有制作、装备、背包、存档和HUD流程。旧档缺少坐骑时恢复为空，不修改SAVE_VERSION。
- Skateboard负责低面数模型创建/释放，SkateboardPose负责关节姿态；模型只在装备后存在，不增加灯光、阴影贴图或渲染分辨率。
- 联机装备/下骑动作走NetGuest.action → Actions权威结算，equipment快照同步；本人沿用现有owner-driven移动架构，坐骑倍率在公共Player移动逻辑计算。
- 房主选择mountPose并放入玩家差分快照，客人及旁观者只使用收到的姿态，不独立抽签；晚加入者可从全量快照恢复，无需一次性事件补播。协议版本52阻止旧客户端不识别坐骑。
- 物品图鉴从Items、Crafting和Equipment自动生成获取方式与移速属性；自绘图标、掉落模型、GM物品列表同步可用。

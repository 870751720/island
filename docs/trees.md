# 树木:三种树种、生长阶段与播种

## 背景

岛上原本只有一种通用树,砍倒后不会再生,也没有种植玩法。需要引入三种树、掉落种子/果实的机制,以及种树玩法,让木材与食物成为可再生资源。

## 需求描述

- 三种树:橡树、松树、棕榈树,各有专属造型、种子与可食用果实。
- 砍成树第一阶段(树冠 → 树桩)时,100% 掉落本树种种子,1/10 概率掉落本树种果实。
- 砍倒一棵成树(第一阶段)时,岛上另处会自然补种一棵同树种树苗(发芽阶段),随生长机制长回成树,树木总量不因砍伐减少。
- 树有三个生长阶段:发芽(种子种下即发芽)→ 小树 → 成树;每棵未成树每 1 分钟有 1/2 概率长到下一阶段;只有成树可砍。
- 橡树种子、松树种子、果树种子归为「设施」,背包「使用」或工具按钮循环/长按选择后进入手持安放模式。显示发芽树苗的绿/红幽灵预览,按设施整数网格选取面前附近最近可放格,站定 2 秒消耗 1 粒种子种下,移动后可继续种植。不能在水中、水边或被设施/资源占用的位置播种,无需开垦土壤。

## 设计方案

- `src/game/world/TreeSpecies.ts`:树种/生长阶段类型与配置表(`SEED_OF`/`FRUIT_OF` 道具映射、掉落概率、生长间隔与概率、树模型统一放大量 `TREE_MODEL_SCALE = 1.3`)。
- `src/game/world/Props.ts`:
  - 树的外观按 `(species, stage)` 程序化拼装(发芽嫩芽、小树细干、成树三种造型、树桩),阶段变化时整体替换子网格。
  - 自然生成的树随机分树种、均为成树；玩家种下的树通过 `plant()` 加入同一资源列表。
  - `update` 内累计 60 秒生长计时,未成树每轮 1/2 概率升阶;幼树不参与碰撞阻挡、不可采集。
  - 存档:自然树与玩家种下的树都保存种类、坐标、朝向和生长状态，恢复时按完整列表重建。
- `src/game/systems/CollectSystem.ts`:树第一段砍伐的产出回调改为接收 prop,按树种概率额外入包种子/果实(直接进背包并触发拾取提示)。
- `src/game/Game.ts` 为三种树种注册 `FacilityDef`,复用 `AutoPlaceSystem` 选格、预览、站定进度与 `dryCellReason` 占位检查;`placeTree` 在房主端复核落点后扣除种子并调用 `Props.plant`。预览复用 `makeTreeSproutPreview`,与真实树苗共用程序模型和缩放。
- 客人通过 `tool` 动作同步手持种子,本地显示预览,房主推进站定放置并结算;树苗通过 props 增量同步,背包与手持状态通过快照回流。移除独立 `useSeed` 动作,联机协议版本为 33。种子 ID、树木存档结构和 `SAVE_VERSION` 不变,旧档兼容。
- 道具:`Inventory`/`Items`/`Food`/`DropModels` 注册 3 种种子与 3 种果实(果实可直接食用,恢复少量饥饿/口渴,椰子额外解渴)。

## 迭代记录

### 数量/体型/掉率调整与自然补种(2026-09)

- 树数量提升 1.5 倍:`PropSpawner` 树撒点密度 60 → 90(每万平方米)。
- 所有树模型统一放大 1.3 倍:`Props.applyTreeLook` 按阶段重建外观后对树整体 `scale = TREE_MODEL_SCALE`,各生长阶段与树桩等比;树干碰撞半径 0.3 → 0.4。
- 树种子掉率 60% → 100%(`SEED_DROP_CHANCE`)。
- 自然补种:`Props.seedRegrowTree` 由 `CollectSystem` 在砍倒成树第一阶段后调用(仅房主端结算,客人经 props 增量同步复现)。选点规则:采样干地格子,排除水边/动物通道/被资源占位/所有玩家周围 18 米(防树苗当着玩家面凭空出现),再按「与最近可见树的距离最接近 6 米目标间距」打分取最优,补种落在密林边缘的过渡地带,既不加密成片密林也不落在光秃地上。

### 未成树不可砍(2026-09)

- 明确设计:发芽与小树两个阶段完全不可砍伐、不可交互,只有成树可砍。原实现中小树长出即 `ready = true` 可被砍(1 斧出 1 树枝),已移除:`CollectSystem` 删除 `sapling` 作业配置,`Props.updateTreeGrowth` 仅在长成成树时置 `ready`;存档恢复时未成树强制 `ready = false`(兼容旧档小树已写入的 ready)。

### 果树摘果与挂果再生(2026-09)

- 果树成树分「挂果/无果」两个外观状态:挂果时树冠点缀 12 颗红果,摘果后模型不带果子,3 分钟(`FRUIT_REGROW`)后重新挂果。
- 挂果中的果树空手(持斧以外的任意状态)靠近即自动摘果,一次随机 1-5 个果子(`FRUIT_PICK_MAX`);手持斧头时照常砍树,两种交互按手持工具自动区分(`CollectSystem.kindOf` → `fruitTree`)。
- 摘果只摘走果子,树保留且仍可砍:`Props.pickFruit` 置 `fruited = false` 并启动挂果计时,`updateFruitRegrow`(房主端推进,睡觉快进同走 `advance`)到点翻回挂果并重建外观;`fruited`/`fruitLeft` 入存档与联机 props 增量(缺省视为挂果,旧档兼容)。
- 头顶作业提示显示「摘果子」;自动切斧提示不再打断摘果(挂果果树上不提示切换斧子)。


## 采摘时的工具保护

采集范围内存在果树时均不自动切换斧头（即使摘完后目标转向旁边的普通树），不依赖是否挂果、采集目标切换或离开后返回；摘果完成和联机快照更新不会解除保护。玩家必须主动选择斧头才能砍果树。客人本地使用同样规则，主动切换仍走既有 tool 动作上行与房主结算。

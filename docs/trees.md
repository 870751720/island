# 树木:三种树种、生长阶段与播种

## 背景

岛上原本只有一种通用树,砍倒后不会再生,也没有种植玩法。需要引入三种树、掉落种子/果实的机制,以及种树玩法,让木材与食物成为可再生资源。

## 需求描述

- 三种树:橡树、松树、棕榈树,各有专属造型、种子与可食用果实。
- 砍成树第一阶段(树冠 → 树桩)时,1/3 概率掉落本树种种子,1/10 概率掉落本树种果实。
- 树有三个生长阶段:发芽(种子种下即发芽)→ 小树 → 成树;每棵未成树每 1 分钟有 1/2 概率长到下一阶段;只有成树可砍。
- 玩家把工具切换到「种子」并原地停留 2 秒即自动播种,规则与工作台摆放一致:不能在水中/水边,落点不能被资源点占住。

## 设计方案

- `src/game/world/TreeSpecies.ts`:树种/生长阶段类型与配置表(`SEED_OF`/`FRUIT_OF` 道具映射、掉落概率、生长间隔与概率)。
- `src/game/world/Props.ts`:
  - 树的外观按 `(species, stage)` 程序化拼装(发芽嫩芽、小树细干、成树三种造型、树桩),阶段变化时整体替换子网格。
  - 自然生成的树随机分树种、均为成树,记录在 list 前段(`naturalCount`);玩家种下的树通过 `plant()` 追加在后段。
  - `update` 内累计 60 秒生长计时,未成树每轮 1/2 概率升阶;幼树不参与碰撞阻挡、不可采集。
  - 存档:自然资源点状态不带坐标按序恢复,种下的树带 `x/z` 坐标单独重建;旧存档无 species/growth 时按橡树成树兼容。
- `src/game/systems/CollectSystem.ts`:树第一段砍伐的产出回调改为接收 prop,按树种概率额外入包种子/果实(直接进背包并触发拾取提示)。
- `src/game/systems/PlantingSystem.ts`:手持种子、站定、落点合法且无其他占用双手行为时,2 秒后消耗背包中第一种可用种子,在脚下种下对应树种的发芽树苗;进度走头顶圆环「播种中…」。
- 道具:`Inventory`/`Items`/`Food`/`DropModels` 注册 3 种种子与 3 种果实(果实可直接食用,恢复少量饥饿/口渴,椰子额外解渴)。
- 工具:Player 手持工具增加「种子」(种子袋模型),工具按钮循环顺序为 空手→斧→镐→鱼竿→弓→种子;拥有任意种子即可切换,种子用完自动收回手。
- 忙碌互斥:播种与采集/合成/进食/钓鱼/射箭/喝水互斥,互相让位。

# 围栏与围栏门

## 背景

玩家需要在岛上圈出一块封闭区域(养动物、围院子)。原有放置物都是自由坐标(玩家脚下),无法保证对齐,难以围出没有缝隙的闭合图形;动物也没有任何碰撞,即使围起来也会穿过去。

## 需求描述

- 二级工作台可制作:1 木头 → 2 个木围栏;1 石头 → 2 个石围栏;2 木头 → 1 个围栏门。
- 围栏之间自动连接,玩家能方便地围出没有缝隙的正方形封闭区域。
- 围栏能挡住玩家和动物(兔/羊/鹿/熊/蟹);围栏门玩家可通过,动物不会开门。
- 围栏/门可用锄头挖回道具,可存档。

## 设计方案

### 网格顶点吸附 + 自动连接

- 围栏网格边长为 1。围栏柱吸附在整数格点 `(gx, gz)` 上,背包「使用」时落在玩家面前约 0.9 处最近的格点。
- 每根柱子检查四个相邻格点(±1, 0 / 0, ±1)是否有围栏或门,自动向这些方向伸出两根横杆(各覆盖半格),相邻柱合起来即无缝;放置/挖除后刷新自身与四邻的网格。
- 玩家沿正方形边走一圈逐个放置,天然闭合,无需任何对齐操作。

### 围栏门

- 门占一条格点边(东西边或南北边),放置时吸附到玩家面前最近的边;该边已有门或已有围栏横杆(两端都有柱)时不可放。
- 门框两端立柱,门扇绕一端立柱旋转;玩家靠近(约 1.25)自动开、走远自动关,无需任何按钮,动物不会开门。

### 阻挡

- 围栏连接与「关着的门」构成阻挡线段集合(`FenceSystem.segments`)。
- 玩家:接入 `ObstacleSolver`,移动时被线段推出(`resolveCollision`,点到线段推挤)。
- 动物:`Wildlife.isGrass` / `Crabs.isSand` 可走性判定注入 `isBlocked(x, z)` 回调,围栏线段附近视为不可走;动物寻路本来就是「直行失败试切线」,围栏闭合时切线也失败,即被圈住。

### 挖除与存档

- 手持锄头靠近站定自动拆(2 次命中,精致锄 1 次),变回对应道具入包。
- 存档:`fences: {x, z, kind}[]`、`fenceGates: {x, z, dir}[]`(门的开合状态由玩家距离即时推导,不入档);`SAVE_VERSION` 升到 21,旧档丢弃。

### 相关文件

- `src/game/entities/Fence.ts` / `FenceGate.ts`:程序化建模(木柱/石柱/横杆/门扇),连接变化时重建。
- `src/game/systems/FenceSystem.ts`:放置、连接刷新、阻挡线段、自动门、挖掘、快照。
- `Player.ts`(`setObstacles` 支持多个阻挡源)、`Wildlife.ts` / `Crab.ts`(注入 `isBlocked`)、`Game.ts`(接线)。
- `Inventory.ts` / `Items.ts` / `Crafting.ts` / `DropModels.ts`:道具 `fenceWood` / `fenceStone` / `fenceGate`、配方(均 `minBenchLevel: 2`)与掉落模型。
- `Backpack.tsx` / `GameplayUI.tsx`:背包「使用」分发。

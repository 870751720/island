# 多敌对生物分散追击

## 背景

多个敌对生物直接追逐同一个玩家坐标，原移动逻辑只检查地形和静态障碍，导致追击路线收敛、模型重叠。

## 需求描述

- 普通追击时柔和避让附近敌对生物，近距离从不同方向接近玩家。
- 保留攻击距离、伤害、冷却和同时攻击资格，以及熊体力和扑击、鳄鱼出场扑咬、野牛激怒等规则。
- 不改变目标选择、夜袭绑定、套索限制和单机死亡撤离规则。
- 面向手机控制邻域检测开销，单机与联机房主使用相同逻辑。

## 设计方案

- `WildlifePursuit` 独立负责转向，不修改动物坐标或结算伤害。每帧建立边长 3 米的空间网格，保存敌对动物帧初位置，避让仅检查周边九格；熊和野牛半径 0.7 米、鳄鱼 0.6 米、狼 0.45 米。
- 进入目标 5 米内，从当前来向附近选取接近角度，优先避开追击同一玩家的已有接近方向。落点位于攻击距离的 85% 处，避免停在攻击范围外。方向持续保留，目标改变、落点不可站立或玩家移动令方向偏离过大时重选；同目标重选至少间隔 0.6 秒，失效记录在 0.5 秒后清理。
- 相邻个体按重叠程度产生柔和分离转向，完全重合时按 ID 生成互相反向的分离方向。追击时限制分离分量，维持向前运动；进入攻击距离后继续按原规则攻击，以最高 0.8 米/秒缓慢挪开重叠，不改变面向目标的朝向。
- 所有最终移动仍经过 `canStand`，遵守草地、水洼、围栏、树石、安全区和木桩牵引范围。普通追击保留既有局部转向避障；近身分离遇阻停下。该模块不提供全局寻路。
- 熊扑击的蓄力、锁定方向腾跃和恢复，以及鳄鱼出场过程不接入转向；草食动物逃跑、牵引、游荡和死亡撤离不接入。特殊动作期间其他追击动物仍可避让其身体。
- 房主独占协调计算，客人沿用战斗动物 25Hz 姿态快照和本地插值。接近角度为短期运行态，不进入存档，不增加网络字段或修改版本。

## 验证

- 类型检查和 H5 构建。
- 纯逻辑模拟检查单只直追、完全重合的双向分离、五只狼持续追击后进入攻击范围并保持间距，以及无可用接近落点时返回有效方向。
- 本地运行由用户验证：移动中多狼追击、停下后近身围攻、树石和围栏附近、熊扑击、鳄鱼出场、拴桩狼熊，以及联机房主和客人画面。

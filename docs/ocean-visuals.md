# 无限海域与海水视觉
## 背景
固定海面和方形海底会暴露世界边缘，玩家也被限制在岛屿网格内。
## 需求描述
手机端海面连续覆盖镜头，玩家可持续向外游；浅水透底、深水遮蔽海底边缘，辅以轻微波纹。保留生存消耗和溺水规则。
## 设计方案
- 阶段一：取消玩家方形移动限制，地形外返回统一海底高度 -2.1；修复网格边界索引。海面按正交相机四角与水面交点覆盖，复用两个三角形。小地图保留岛屿底图，将远海玩家沿岛心方向投到地图内沿。
- 阶段二：一次生成深度纹理，浅水透明、深水完全遮蔽；使用标准材质响应昼夜天气。
- 阶段三：世界坐标驱动轻量波纹与柔和波光，不移动实际水位。
- 房主继续由摇杆输入权威计算移动，客人预测与姿态快照沿用现有流程；各端海面跟随本地镜头。无新增动作和持久化字段，SAVE_VERSION 不变。远海坐标仍按原字段保存；海域不生成新陆地或无限探索网格。
- 分阶段类型检查、构建、commit；全部完成后才 push 并等待部署验收。用户负责线上视觉与手机性能测试。

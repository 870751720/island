# 采集产出满包落地
## 背景
采集与钓鱼直接添加背包时，未收下的产出会丢失。
## 需求描述
背包装不下的采集物、鱼获、珍宝、作物与种子保留为地面掉落物，腾出空间后可捡回。
## 设计方案
资源采集、钓鱼、作物采收与翻土通过注入回调调用 Game.giveItem。可收下的数量进背包，剩余交给 DropSystem.dropOverflow，落在操作者身旁；渔获不掉到浮漂水面。加成产出同样处理，钓鱼翻倍概率不受背包容量影响。复用掉落物存档格式，不修改 SAVE_VERSION。
联机由房主对每位玩家会话结算；客人上行动作，背包随 HUD 快照回流，地面物品通过世界增量同步，客人不重复生成物品。

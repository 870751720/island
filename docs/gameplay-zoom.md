# 游戏画面双指缩放

## 背景

手机玩家需要放大场景查看细节，并在下一局与退出相机模式后保留习惯的大小。

## 需求描述

- 普通游戏画面空白处双指捏合缩小、张开放大，范围为原始视野的 1～2 倍。
- 只缩放 3D 场景，HUD 和触控按钮保持原尺寸，竖屏与横屏使用相同倍率。
- 新游戏、继续游戏、刷新后恢复本机倍率；退出相机模式恢复进入前的游戏倍率。拍照取景仍使用独立的 0.6～5 倍范围。
- 双指操作暂停摇杆输入，所有触点松开后才可重新单指移动；按钮区域不参与捏合，移动加动作键不会误触缩放。

## 设计方案

- `useJoystickPinch` 管理空白触控层 Pointer Events 的触点和距离，触点变化时重建基线，处理取消与捕获丢失。
- `GameCameraController` 持有游戏倍率并限制到 1～2，通过正交相机 zoom 更新投影；相机模式倍率独立，退出恢复游戏倍率。
- `GameplayZoom` 使用独立 localStorage key `island.gameplayZoom.v1`，在手势结束、进入拍照与游戏销毁时保存，避免移动每帧同步写盘。无记录或异常时使用 1，越界值夹紧；存储不可用时保留会话内偏好。
- 房主和客人各自在本机执行同样的镜头与手势逻辑，不发送缩放动作、快照字段或补播事件；世界结算与存档版本保持原约定。

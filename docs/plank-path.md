# 木板路

## 背景
在疏松碎石小路之外，提供木质道路，供玩家按营地风格选择铺设。

## 需求描述
- 三级及以上工作台「设施」配方：木头 ×1 → 木板路 ×2，支持批量制作。
- 背包使用后进入手持安放模式，沿用触屏选取、整数格预览和站定铺设。每格占地 1×1 米，遵守干地、资源及设施占格限制，不能与碎石路叠放；不提供水上架桥能力。
- 五片木板留出板缝，直接露出原地形；板宽、长度、端头错位、木色及木纹按坐标确定，连续铺设时不重复整格图案。
- 玩家在木板路上获得「步履轻快」：移速提升 10%，离开失效。与碎石路共用道路加速规则，不叠加，与其他移速效果相乘。
- 手持铲子附近站定可拆除，耗时随铲子等级变化；每格回收 1 个木板路道具，背包溢出掉落。

## 设计方案
- `RoadSystem` 按 `RoadKind` 管理碎石路和木板路；共用放置、占格、挖掘、旧档恢复和增量同步实现。各道路种类保留独立世界列表和模型。
- `PlankPath` 使用低面数木板盒体与细木纹平面。每片木板顶点细分后取地形高度，板缝不铺实心底层；长短和色调变化由世界坐标决定，不保存额外随机字段。
- 相邻木板路沿东西方向连接时木板转为横跨该方向，南北连接和交叉口使用默认排列；新增或拆除后刷新附近八格。`RoadFacility` 共用贴地预览逻辑，目标格或邻域变化时才更新模型。
- 木板及木纹带顶点颜色，交给 `StaticMeshBatch` 按 16×16 米区域合并，每个区域共用一次绘制，不逐木板增加 drawcall。仅放置、回收和同步改变邻域时重建，复用黏土材质和季节表现。
- 联机中制作、扣材料、铺设和回收由房主结算；工具选择沿用动作上行，路面位置通过 `plankPaths` 世界快照和 add/remove 增量同步，玩家背包与 Buff 通过既有快照回流，音效沿用反馈事件。房主及客人本地预测均按脚下路格计算速度。
- `SaveData.plankPaths` 为可选字段，旧档缺省空数组；原 `gravelPaths` 字段、持久化道具 ID 和 `SAVE_VERSION` 保持不变。联机协议版本 35，避免缺少木板路规则的旧客户端加入。

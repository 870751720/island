# 狗窝

## 背景

为全队共享的博美「薯条」提供营地里的睡觉设施，并让四级工作台获得新的成长辅助配方。

## 需求描述

- 四级工作台解锁「狗窝」：木头 ×10、布料 ×5、铁锭 ×3、羊毛 ×5，单次制作一个，产物进入背包。
- 模型采用海岛草棚：四根木柱、敞口棕榈叶屋顶、低木栏、浅色布垫与铁箍；保留从斜上方看见薯条的空间。
- 背包使用后进入手持安放模式，站定放置；持铲站定可回收完整狗窝道具，背包满则掉落。
- 薯条自然触发白天小睡或夜间长睡时，若当前跟随玩家距离狗窝不超过 4 米，优先选最近的一座。没有狗窝时保持原有睡觉行为。
- 薯条先步行到正面入口，再进入睡垫，抵达后才开始睡眠倒计时。保留原有白天 9–15 秒、夜间 20–40 秒的睡眠时长。
- 在窝里完整睡完一次额外获得 5 点成长经验；两次奖励至少间隔 120 秒，满阶仍使用成长系统原有上限。
- 食物、战斗、游泳、召回、狗窝被拆或跟随玩家离开狗窝 4 米范围时中断，不发本次奖励。前往狗窝超过 12 秒仍未抵达则放弃目标，在原有行为规则下就地休息或跟随，不隔着障碍瞬移。

## 设计方案

- `entities/Doghouse.ts`：Three.js 基础几何体程序化拼装，与世界设施、放置预览和小型掉落模型共用。静态黏土网格合并，维持低面数与低 drawcall；拆除时释放独占资源。
- `systems/DoghouseSystem.ts`：世界设施清单、干地与统一占格校验、回收进度、稳定 ID 和快照同步。安放与挖掘共用现有手机触屏入口、进度提示及目标高亮。
- `systems/DoghouseRest.ts`：只管理一次回窝睡眠的目标、入口/睡垫抵达、超时与奖励冷却，伴侣移动继续复用现有绕障逻辑。`Pomeranian` 保留食物与护主等优先级，通过 `DogGrowth.add` 发放经验。
- 睡垫高度随权威狗姿态中的 `y` 同步；前往狗窝时同步普通行走状态，抵达后才同步 `sleep`，客人端不独立选择狗窝或增加经验。
- 新增可选存档字段 `doghouses`，旧档默认空数组；`dog.doghouseRewardCooldown` 默认 0。仅保存奖励冷却，不保存途中或未完成的睡眠，加载不会补发奖励。`SAVE_VERSION` 保持不变。
- 联机制作/使用沿用 `NetGuest.action` 和房主 `Actions.ts`；房主校验材料、工作台等级与安放条件。狗窝增删走 `doghouses` 世界快照增量与全量补发，薯条位置、睡姿和经验使用原有伴侣姿态回流。经验升级沿用可靠 `dogStage` 事件及姿态序号恢复，不增加独立睡眠奖励事件。

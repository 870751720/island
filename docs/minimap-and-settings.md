# 小地图与游戏内设置

## 背景

原先右上角只有一个「第 N 天」角标,信息量低;玩家放置了工作台/火堆/床之后没有途径找回它们的位置;游戏进行中也无法调整音乐音量或返回主界面。

## 需求描述

- 「第 N 天」从右上角移到左上角状态栏下方。
- 右上角新增小地图:点击放大查看,放大后有文字标注;地图左上角有折叠按钮可收起。
- 小地图用图标显示工作台 🛠️ / 火堆 🔥 / 床 🛏️ 的位置。
- 战争迷雾:未探索的区域不可见(地形与标记都不透出),随玩家移动逐渐点亮,并随存档持久化。
- 左上角状态栏右侧新增设置按钮 ⚙️,打开设置面板:音乐/音效滑杆(实时生效并持久化)、返回主界面。

## 设计方案

### 数据侧(`src/game/`)

- `systems/MinimapSystem.ts`:战争迷雾网格。岛屿按 2 米一格切成 80×80 的 `Uint8Array`,玩家每帧点亮周围半径 24 米的格子;`isExplored(x,z)` 供标记过滤;`serialize()/restore()` 随存档持久化。
- `WorkbenchSystem` / `CampfireSystem` / `BedSystem` 新增 `positions` getter,返回场上所有落点。
- `Game` 新增三个公开接口:
  - `getMinimapSnapshot()`:每帧返回岛屿尺寸、玩家落点、已探索标记(未探索区域的标记直接过滤掉)与迷雾网格;
  - `getGroundKind(x,z)`:采样地形高度映射为水/沙/草/深草四色,供小地图绘制底图;
  - `setAudioSettings()`:热应用音量并写 localStorage。
- `audio/GameAudio.ts`:保留音乐/音效总线 GainNode 引用,新增 `setVolumes()` 平滑过渡更新音量。
- `systems/SaveSystem.ts`:`SAVE_VERSION` 23 → 24,新增 `fog?: number[]`(0/1 网格按行展开),旧档按约定丢弃。

### UI 侧(`src/ui/`)

- `Hud.tsx`:状态栏下方加「第 N 天」分隔行;右侧并排 ⚙️ 设置按钮(≥38px 触控区)。
- `Minimap.tsx`:右上角小地图组件。
  - rAF 循环直接从 Game 拉快照绘制,不经过 React 状态,避免每帧重渲染。
  - 底图按岛屿采样一次(128×128)后缓存;迷雾网格铺成小图再放大绘制,得到柔和的探索边缘。
  - 点击地图打开放大层(点空白关闭),放大层在图标下方绘制文字标注;小地图左上角「−」按钮折叠,折叠后只留一个 🗺️ 按钮。
  - 玩家为白心蓝圈圆点,始终可见。
- `SettingsPanel.tsx`:模态设置面板,音乐/音效 range 滑杆(0~100%)拖动即热应用并持久化;「返回主界面」卸载游戏回到开始界面(自动存档仍按 5 秒间隔保证);「继续游戏」关闭面板。

## 迭代记录

### 2026-08-31 初版

- 「第 N 天」移至左上角状态栏下方;右上角改为小地图。
- 小地图含战争迷雾、建筑图标、点击放大(带文字)、左上角折叠按钮。
- 左上角新增 ⚙️ 设置按钮:音乐/音效滑杆 + 返回主界面。
- 存档新增 `fog` 字段,`SAVE_VERSION` 23 → 24。

### 2026-08-31 二版

- 小地图默认收起,只显示右上角 🗺️ 按钮,点开才展开。
- 主界面改为:有存档时「继续游戏」+「开新档」双按钮(开新档先清旧存档),无存档时仅「开始游戏」。
- 主界面移除声音设置区与操作提示,音量设置只保留在游戏内设置面板。

### 2026-08-31 三版

- 设置按钮 ⚙️ 从左上角状态栏旁移到右上角,位于小地图按钮左边,二者组成一个右上角按钮组。
- 新增「忙碌时淡出 HUD 按钮」:玩家移动中或处于任一交互进行中(制作/工作台/火堆/围栏/床/木箱/挖除/吃饭/钓鱼/拉弓)时,设置、地图、背包、工具按钮以 0.5s 透明度过渡淡出且不可点击;停下或交互结束后淡回。按钮原有「不显示」条件(如无道具时不显示背包按钮)优先于淡出。
- 实现:`HudSnapshot` 新增 `busy` 字段(`Game.isPlayerBusy` 汇总各系统工作状态,变化时立即推送 HUD);UI 侧共享 `src/ui/fade.ts` 的 `fadeStyle(hidden)` 提供透明度过渡与禁点样式。

### 2026-08-31 四版

- 淡出条件调整:不再有淡入延迟,`busy` 即时切换;且仅由交互(制作/工作台/火堆/围栏/床/木箱/挖除/吃饭/钓鱼/拉弓等作业)触发,纯移动不淡出(`isPlayerBusy` 移除 `player.isMoving`)。
- 淡出范围扩展到弹出卡片:手搓合成(CraftPrompt)、进食(EatPrompt)、捡回(DropPrompt)卡片同样用 `fadeStyle(hud.busy)` 淡出并禁点。钓鱼拉竿按钮因必须在钓鱼(忙碌)中操作,不参与淡出。
- 玩家死亡后不再可操控:`Player.setDead()` 让角色原地向前扑倒侧躺(取消作业/睡眠姿态、收起手持工具),此后忽略一切输入;死亡触发点在 `Game` 主循环检测到 `dead` 置位时调用。

# 玩家男孩与女孩模型

## 背景

玩家需要在手机俯视视角下拥有明确的儿童轮廓和亲切的面部形象。

## 需求描述

- 基础角色可选黏土风格男孩与女孩，保留眼睛高光和小鼻子；女孩保留淡腮红，男孩不画腮红。男孩头部均匀收窄成自然椭圆脸，女孩保留圆脸。男孩为深棕蓬松短发（圆顶鼓起、几乎没有刘海）；女孩为棕色双马尾、对分刘海与珊瑚色蝴蝶结。
- 男孩默认奶油色短袖、蓝色短裤；女孩默认珊瑚色短袖、紫色短裤。共用浅色袜子与棕色圆头鞋，基础服装不属于装备，不提供属性。
- GM 面板「玩家 → 性别」可设置当前玩家为男孩或女孩。选择持久化，旧档与新角色默认男孩。
- 基础人物由本模块负责；帽子、衣服、裤子和背包的立体穿搭由 `entities/equipment/` 模块负责，详见 `equipment.md`。工具展示沿用原有机制。
- 兼顾手机性能与联机显示，保留移动、采集、战斗、游泳、睡眠和受伤表现。

## 设计方案

- `src/game/entities/PlayerModel.ts` 独立负责程序化建模，用低分段球体及半球拼装，不使用外部模型或动画文件。
- 高粗糙度、平面着色；五官与头发按材质合并几何体，减少绘制调用。材质在每个玩家内部复用，不跨玩家共享，防止受击泛红和装备换色互相影响。
- 脚底保持在局部 Y=0，朝向 +Z，男孩总高约 1.74、女孩约 1.68；保留原碰撞半径、水深判定和移动速度。
- 身体使用腰部、肩肘、髋膝和脚踝关节组，身体表面网格作为子节点。`PlayerAnimator.ts` 统一驱动程序动作，工具挂在右前臂末端，伤口跟随前臂和小腿表面；衣服和背包跟随腰部，帽子跟随头部。详见 `player-animation.md`。
- 未装备或卸下衣裤时恢复默认短袖、短裤颜色；手臂、小腿和鞋子使用独立材质。
- 男孩和女孩共用身体、动作关节与装备挂点。两套发型分别按材质合批，切换改变发型显隐、未装备衣裤的底色，并由 `BoyHeadShape` 从原始顶点恢复女孩或应用男孩头脸轮廓，不重建模型、不中断动作，已穿装备保持原状。
- 房主、本地客人及远程角色共用模型工厂。`gmSetGender` 经房主校验，仅修改发起者的会话；`PlayerState.gender` 和 HUD 快照回流，各端应用离散外观变化，无需事件补播。
- `SaveData`、`SessionSave` 增加可选 `gender`（boy/girl）；房主设置成功后保存全员会话，初次加入、读档、重连均恢复。缺省为 boy，非法值忽略，`SAVE_VERSION` 不变。

- 身体朝向 +Z，角色自身右手/右腿在局部 -X，左手/左腿在 +X；关节数组统一为 `[左, 右]`。工具和安放道具始终挂右前臂，左右穿搭及伤口沿用相同语义，不能按正面观看时的屏幕左右命名。

### 原版男孩造型强化

- 男孩默认启用新的肩肘、膝踝步态。`BoyHeadShape` 处理原始头脸和男孩头发，五官同步变形，吃东西目标同步调整；附件不缩放，女孩头脸不受影响。
- `BoyUpperBody` 为男孩提供平缓肩线的一体上衣、下移并收小的胶囊袖根和较短圆柱脖颈，头部上移 0.065，领口与下巴之间露出一截脖子。保持肩肘挂点，嘴部和帽子随头节点移动；切换女孩时恢复原始几何与头部位置，销毁时释放专用几何。
- `BoyHair` 用圆顶发壳加头顶和后脑体积拼蓬松短发，按材质合为一次绘制；女孩发型保持原样。腮红单独成组，仅女孩显示。

# 玩家小男孩模型

## 背景

玩家需要在手机俯视视角下拥有明确的儿童轮廓和亲切的面部形象。

## 需求描述

- 基础角色为黏土风格小男孩：大头圆脸、棕色侧分短发、眼睛高光、小鼻子和淡腮红。
- 默认穿奶油色短袖、蓝色短裤、浅色袜子和棕色圆头鞋；基础服装不属于装备，不提供属性。
- 基础人物由本模块负责；帽子、衣服、裤子和背包的立体穿搭由 `entities/equipment/` 模块负责，详见 `equipment.md`。工具展示沿用原有机制。
- 兼顾手机性能与联机显示，保留移动、采集、战斗、游泳、睡眠和受伤表现。

## 设计方案

- `src/game/entities/BoyModel.ts` 独立负责程序化建模，用低分段球体及半球拼装，不使用外部模型或动画文件。
- 高粗糙度、平面着色；五官与头发按材质合并几何体，减少绘制调用。材质在每个玩家内部复用，不跨玩家共享，防止受击泛红和装备换色互相影响。
- 脚底保持在局部 Y=0，朝向 +Z，总高约 1.68；保留原碰撞半径、水深判定和移动速度。
- 手臂与腿分别使用肩部、髋部关节组，身体表面网格作为子节点。`Player.ts` 沿用程序动作，工具随手端摆动，伤口挂载身体表面。
- 未装备或卸下衣裤时恢复默认短袖、短裤颜色；手臂、小腿和鞋子使用独立材质。
- 房主、本地客人及远程角色共用模型工厂，动作和姿态继续通过现有上行及快照同步。纯显示变化，无新增结算、消息或存档字段，`SAVE_VERSION` 不变。

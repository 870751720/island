# 季节系统

## 背景

游戏以四季轮换表现荒岛气候。夏季强调浓绿与清透日光,秋季强调金黄、橙红的植被层次,配合春季原色与冬季积雪形成清晰的季节区别。

## 需求描述

- 以现有天数系统(`DayNightSystem.dayCount`)为基础,按天数划分季节,当前默认春季。
- 夏秋保留植被原有明暗差异,草地与树冠分开配色,沙滩、泥土保持原色;手机端不增加模型、纹理或 drawcall。

## 设计方案

- `src/game/world/SeasonVisuals.ts`:季节视觉表现层,通过全场材质共享的三个连续 shader uniform 驱动换季变色:
  - `uDry`(盛夏浓绿)、`uAutumn`(秋季橙红)、`uSnowAmount`(积雪),经 `onBeforeCompile` 注入 `MeshStandardMaterial`,shader 内按 原色→夏绿→秋色→积雪 的固定顺序混合,换季过渡天然平滑。
  - 积雪仍按表面朝向(`normal.y`)只覆朝上的面,覆盖曲线 smoothstep(-0.15, 0.6, normal.y),锥形树冠各朝向吃满雪,垂直墙面只留薄层;不新增模型与 drawcall,移动端友好。
  - 材质季节类别 `SeasonKind`:`foliage`(落叶树冠、灌木、草丛)、`terrain`(地表)、`plain`(其余物件,仅积雪)。`SeasonPalette.ts` 将 sRGB 调色板转换为 shader 线性颜色,以原始绿色优势筛选参与夏秋染色的区域,避免沙滩、泥土与非绿色部件被统一染色。
  - 夏季植被在深绿 `#286c46` 与叶绿 `#78b84c` 之间按原始绿色亮度取色,混合强度 64%;草地 38%。秋季树冠由陶红 `#b95b3e` 到金黄 `#e5b853` 分层,混合强度 88%;草地独立使用橄榄色到浅草黄,强度 48%,保留原色细节。颜色来自材质/顶点色,合批前后保持一致,不依赖每帧随机数。
  - 冬季落叶植被转枯黄褐上限 85% 后叠雪;松柏常绿走 plain。
  - `updateSeasonVisuals(delta)`:三系数各自向 GM 目标季节的预设(spring 全零/summer dry=1/autumn autumn=1/winter snow=1)以 0.08/秒平滑过渡。
- 光照季节调制:`DayNightSystem.apply()` 使用共享季节系数:夏季蓝天 `#7fc4e8`,日光强度 +5%、环境光 +4%;秋季淡蓝天 `#b9d3e3`、柔金阳光 `#ffe3b5`,日光强度 -4%。夏秋调制按太阳高度 smoothstep(0, 0.4) 淡入,保留晨昏和夜空。冬季延续苍白天空、冷光与原有强度。天气调制随后叠加。
- 材质接入:`src/game/world/ClayMaterial.ts` 提供全场统一的 `clayMaterial(color, foliage?)`(flatShading + 高粗糙度 + 自动注入季节 shader),各建筑/物件/植被模块统一引用;`IslandTerrain.ts` 的地表材质(顶点色)以 `terrain` 类别单独注入;水面不注入;`mergeClayMeshes` 按 `season-plain`/`season-foliage` 缓存 key 分批合并。
  - 已接入:树/灌木/岩石等场景物件(`Props.ts`)、庄稼(`cropMeshes.ts`)、栅栏/门、工作台、织布机、熔炉、烹饪台外的容器(木箱、酒桶、饵料桶)、净化器、神龛、木桩、兔洞、土壤、帐篷。
  - 落叶标记(wither):橡树/果树的成树与树苗树冠、灌木、浆果丛、草丛;松树、嫩芽、小型动物、玩家与穿戴装备、火焰类自发光材质(营火/烹饪台火光)不参与。大型野兽(野牛、熊)的皮毛材质接入积雪,背上随雪量落一层薄雪,角/蹄/眼/口鼻保持原色。
- 驱动入口:季节真实状态由 `src/game/systems/SeasonSystem.ts` 持有——以 18 天为一季,春→夏→秋→冬循环;新开局掷初始季节(91% 春季第一天,夏/秋/冬各 3%,均从该季第一天开始),房主/单机在游戏循环内每帧按天数对账换季(GM 大幅改天数可跨季连跳,回拨天数仅重锚不改标签)。换到冬季当日由房主 `weather.force('snow')` 强制降雪。GM 面板「世界」tab 的季节按钮(`GmSystem.season`)改为「跟随(auto,默认)/春/夏/秋/冬」覆盖开关:auto 时视觉跟随真实季节,强制态仅覆盖视觉表现、不改变真实季节状态;覆盖走 `gmSnapshot/gmApply`,联机时全房间同步,主机与客人各自本地执行过渡表现。
- HUD:左上角天数行展示当前季节(`第 N 天 · 🌸春` 等),季节值随 `HudSnapshot` 下发,客人端 HUD 自动一致。
- 存档:`SaveData` 新增可选字段 `season` 与 `seasonStartDay`(季节锚点天数),旧档缺省视为春季、锚点 1,`SAVE_VERSION` 不变;入冬强制降雪不落盘(只影响当时天气,天气本身不入档)。
- 水洼结冰(第二期玩法化):约 6 成水洼在生成时按地形种子确定性标记 `freezable`(主客由相同 terrainSeed 得到一致集合)。雪量 ≥ 0.7(`IslandTerrain.FREEZE_SNOW`)时这些水洼结冰:
  - 表现:每个可冻水洼在 `terrain.iceGroup` 中有一片共享冰面材质的圆盘(略高于洼面),透明度随雪量在 0.4→0.7 区间渐显,无雪时整组隐藏,零新增 drawcall 负担仅在有雪时出现。
  - 玩法:`getHeight` 对结冰水洼把地面高度钳到洼面(冰面高度),因此 `getWaterKind` 在冰上返回 null——玩家可在冰上行走(不游泳不涉水),也无法在冰面上触发喝水(`WaterSystem`)或向该水洼抛竿钓鱼(`FishingSystem` 的目标水体判定);海水永不结冰。冰面滑行:`Player` 在冰上移动速度 ×2(判定走 `terrain.isOnIce`)。
  - 联机:无新增协议——季节设置走既有 `gmConfig` 同步,结冰集合由 terrainSeed 确定,主客各自本地计算一致;冰上行走是各端本地物理,天然一致。

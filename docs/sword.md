# 木剑(近战武器工具)
## 背景

岛上唯一的猎捕手段是弓箭,远程拉弓需要走位瞄准;缺少一把贴近动物自动攻击的近战武器。新增工具「木剑」:靠近动物时按固定频率自动挥砍。

## 需求描述

- 新增工具「木剑」:**2 个木头(log)合成,需二级工作台**(`minBenchLevel: 2`)。
- 持剑靠近动物(攻击范围 1.4m)时,按固定间隔(0.8s)自动挥砍,每刀伤害 10;击杀掉落战利品,与弓箭猎捕共用掉落逻辑。
- **剑不参与自动切换**:靠近动物不会自动切剑,空手站定也不会被自动切上;只能手动(工具按钮/Q 键循环)切换。
- 剑不赋予任何采集资格:持剑时采集按徒手规则(树/大石不可采)。
- 暂只有木剑(tier 1),无精致升级。

## 设计方案

- 工具沿用「永久拥有、等级制」模型:`ToolId` 增加 `sword`,配方 `cost: { log: 2 }`、`station: 'workbench'`、`minBenchLevel: 2`。
- 新系统 `src/game/systems/SwordSystem.ts`(每会话一份):
  - 持剑且非忙碌、非游泳时,经 `Wildlife.nearestId` 索敌范围内最近活动物;命中即进入 0.35s 挥砍动作(复用 `chop` 作业动画)+ 0.8s 冷却。
  - 权威结算调 `wildlife.damage(id, 10)`,击杀经回调在玩家身旁掉落战利品(与弓共用 DropSystem 掉落)。
  - 挥砍期间占用双手:`isSessionBusy` 新增 `sword` 交互类别,其他站定交互让位。
- 手持模型:程序化 `makeSwordModel()`(木柄 + 十字护手 + 扁木剑身 + 剑尖),挂右臂末端,与其他工具同风格。
- 音效复用 `chop`(挥砍声响会惊动附近动物,持剑强攻有代价)。

### 联机(房主权威 + 客人本地判定,与弓箭同约定)

- 客人端本地完整跑索敌与命中判定,播本地挥砍表现;命中经 `swordHit` 动作上行(参数:动物 id)。
- 房主收到 `swordHit`:校验该会话持剑后,`netPlaySwing()` 补放挥砍动作(经姿态快照的 `action` 字段同步给各端)+ `settleNetHit(id)` 权威结算伤害与掉落;挥砍音效由房主经 feedback 事件补播给挥剑者本人。
- 动物血量/死亡/掉落本就随野生动物姿态快照与世界增量回流,无需额外同步字段。
- 快照:`toolTiers` 展开(新增 sword 字段,旧档/旧端缺省 0)、手持 `tool` 字段自动携带 `'sword'`。

### 存档兼容

`sword` 为新增可选工具字段(`Partial<Record<ToolId, number>>`),旧档缺省 0,`SAVE_VERSION` 不变。

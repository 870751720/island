# 游戏 HUD 与触控反馈

## 背景
游戏内入口与生存信息需要适配手机触屏，让玩家在观察世界的同时迅速识别状态、当前工具和可交互对象。

## 需求描述
- 左上角用三只小玻璃瓶的剩余液位表示生命、饱食、水分，取消大底板、横条、常驻数值与额外状态图标。
- 背包、工具、设置使用浅奶油／浅鼠尾草色半透明底与细边框；保留按压、长按选择和面板入场反馈。
- 玻璃瓶与液体使用程序 shader 绘制，液面有轻微波动，补充和消耗时平滑过渡。
- 手机竖屏优先，兼容存档、单机与房主/客人联机。

## 设计方案
### 信息层级与瓶体绘制
- `src/ui/hud/VitalBottles.tsx` 编排三只瓶子，每只占 44×48px，底部一行小字区分生命／饱食／水分，低于或等于 20% 时替换为危险／饥饿／缺水。天数和季节置于瓶子下方的浅色小条，基础状态区约 132×79px，不含 buff。
- `bottleShader.ts` 用有符号距离函数绘制圆肚生命瓶、方肚饱食瓶、细长水瓶与玻璃瓶口、软木塞。红／金／蓝液位对应现有 0–100 状态；叠加两层正弦液面、窄高光、微弱焦散和气泡。形状、颜色和简短标签共同区分状态，不额外绘制心形等图标。
- `BottleCanvas.tsx` 用一个 Three.js ShaderMaterial 平面绘制三瓶，透明画布 132×48 CSS 像素，一个 draw call，像素比上限 1.5、约 30fps、无阴影。液位使用指数平滑，不逐帧触发 React 更新。
- 数值归一化限制在 0–1；零值不绘制液体，满值到瓶颈。`role=meter` 提供准确数值的无障碍语义，不常驻显示数字。
- 不支持 WebGL 或上下文丢失时，显示 SVG 瓶体与真实液位；上下文恢复后恢复 shader。后台暂停，减少动态效果时关闭波动并仅在状态变化时绘制；卸载释放几何、材质、渲染器与该画布独立上下文。
- 生命瓶保留 44×48px 的隐藏 GM 入口。buff 使用 44px 按钮，保留持续时间与详情。无底板空白区域不阻挡场景触控。

### 操作入口
- `hud/HudIcon.tsx` 使用代码绘制背包、齿轮图标；工具与设施继续复用既有道具图标。
- 背包与工具为 72px 圆角方形按钮，设置和地图为 46px；按压时缩小并加深阴影，设置齿轮轻转、背包图标轻微倾斜。背包和设置面板有短暂入场动效。
- 工具按钮显示当前工具或设施名称，保留弹药数量角标；设施出现时外圈提示三次，避免持续缩放干扰。下方提示「长按选择」。
- 按住工具 350ms 时外圈进度完成并打开选择器，吞掉这次点击；超过 12px 的滑动、离开、取消、按钮隐藏或组件卸载会取消计时。按 pointerId 区分触点，不要求主触点，兼容另一手操作摇杆。
- 保留单击切换、附近设施优先交互、打桩、解绳和长按选择流程；闲置隐藏时禁用按钮，死亡时隐藏背包入口。

### 适配与性能
- `hud/styles.ts` 集中管理浅色控件样式，`GameplayUI.tsx` 统一挂载。竖屏右侧上下排列入口，500px 以下短横屏改为右下方并排，避开右上角展开的小地图。
- 375px 竖屏状态瓶在左上角，350px 以下窄屏下移到设置按钮下方，避免与展开地图时的设置入口相交；buff 继续依据右侧预留宽度换行。
- 控件使用 CSS 渐变、SVG 与有限次数提示；仅三瓶共用一个极小 WebGL 画布，不为各瓶单独创建上下文，不使用大面积背景模糊。
- 遵循 `prefers-reduced-motion`，关闭 CSS 过渡与动画，同时保留低值文字、颜色和长按逻辑；瓶体 shader 按需静态绘制。

### 联机与存档
- 房主/客人的 HUD 均读取现有本地玩家 `HudSnapshot`；权威生存结算、动作上行、快照回流与事件补播维持现有职责。
- 按压、液位和低值动效仅为各端本地表现，不增加网络动作或快照字段。不改持久化数据及 `SAVE_VERSION`。

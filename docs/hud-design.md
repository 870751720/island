# 游戏 HUD 与触控反馈

## 背景
游戏内入口与生存信息需要适配手机触屏，让玩家在观察世界的同时迅速识别状态、当前工具和可交互对象。

## 需求描述
- 左上角用三只小玻璃瓶的剩余液位表示生命、饱食、水分，使用紧凑浅色卡片承托，取消横条、常驻数值与额外状态图标。
- 背包、工具、设置使用浅奶油／浅鼠尾草色半透明底与细边框；保留按压、长按选择和面板入场反馈。
- 玻璃瓶与液体使用程序 shader 绘制，液面有轻微波动，补充和消耗时平滑过渡。
- 手机竖屏优先，兼容存档、单机与房主/客人联机。

## 设计方案
### 信息层级与瓶体绘制
- `src/ui/hud/VitalBottles.tsx` 编排三只瓶子，每只布局宽 36px，保持瓶身原有尺寸，底部贴近瓶身的一行小字区分生命／饱食／水分，低于或等于 20% 时替换为危险／饥饿／缺水。三瓶与下方天数／季节小条放在同一浅奶油半透明卡片中，天数／季节不加独立底色，整体卡片约 118×81px，不含 buff。
- `bottleShader.ts` 用有符号距离函数绘制统一的细长水分瓶造型与玻璃瓶口、软木塞。红／金／蓝液位对应现有 0–100 状态；叠加两层正弦液面、窄高光、微弱焦散和气泡。液体颜色和简短标签共同区分状态，不额外绘制心形等图标。
- `BottleCanvas.tsx` 用一个 Three.js ShaderMaterial 平面绘制三瓶，透明画布 108×48 CSS 像素，一个 draw call，像素比上限 1.5、约 30fps、无阴影。液位使用指数平滑，不逐帧触发 React 更新。
- 数值归一化限制在 0–1；零值不绘制液体，满值到瓶颈。`role=meter` 提供准确数值的无障碍语义，不常驻显示数字。
- 不支持 WebGL 或上下文丢失时，显示 SVG 瓶体与真实液位；上下文恢复后恢复 shader。后台暂停，减少动态效果时关闭波动并仅在状态变化时绘制；卸载释放几何、材质、渲染器与该画布独立上下文。
- 生命瓶保留 44×48px 的隐藏 GM 入口。buff 使用 26.4px 按钮，保留持续时间与详情。卡片背景与空白区域不阻挡场景触控。

### 操作入口
- 设置、小地图展开/折叠、任务卡导航与展开/折叠和背包共用 `pressAction.ts`：有效按下立即执行，忽略后续指针 click，保留键盘/辅助技术激活。此行为仅用于无滚动、拖拽和长按语义的入口。
- `useHudInteraction.ts` 在本机提供分区闲置宽限：操作设置/地图后，右上区至少保持可用 5 秒；操作状态区（含任务卡、Buff 列表）后，该区至少保持可用 5 秒，每次操作重置计时。地图仍可在宽限结束后随角色闲置隐藏。分区计时不修改游戏的 `hud.busy` 或角色闲置时间，不影响工具与附近设施入口。
- Buff 图标由 `hud/BuffButton.tsx` 在有效按下时直接显示详情并播放音效，不等待松手，不保存跨事件触点状态；保留键盘/辅助技术激活，尾随指针 click 不重复执行。按钮点击范围保持原尺寸，仅内部图标缩小反馈，随 HUD 隐藏或死亡禁用。
- Buff 按下不阻止默认手势，列表保留原生滚动；滚动时收起详情。详情与遮罩作为 HUD 的同级节点呈现，脱离状态区的淡入淡出、inert 与容器查询布局；阅读期间状态区保持显示，点击遮罩关闭或死亡时清除。普通弹窗、工具长按选择菜单保持原有交互方式。
- 背包入口在有效 `pointerdown` 时立即打开，与按压音效同步；接受非主触点，支持另一手操作摇杆时打开。后续指针 `click` 不重复切换，键盘与辅助技术的零点击计数激活仍可打开。避免按下与松手之间闲置隐藏禁用按钮、触屏手势取消点击造成只反馈不打开。死亡和闲置隐藏时仍禁用入口。
- `hud/HudIcon.tsx` 使用代码绘制背包、齿轮图标；背包采用暖棕色块、侧面暗部和柔和高光，与道具图标的手工质感呼应；工具与设施继续复用既有道具图标。
- 背包与工具为 72px 圆角方形按钮，设置和地图为 46px；取消按钮内部的装饰轮廓，仅保留外边框；按压时缩小并加深阴影，设置齿轮轻转、背包图标轻微倾斜。背包和设置面板有短暂入场动效。
- 工具按钮显示当前工具或设施名称，保留弹药数量角标；设施出现时外圈提示三次，避免持续缩放干扰。下方提示「长按选择」。
- 按住工具 350ms 时外圈进度完成并打开选择器，吞掉这次点击；超过 12px 的滑动、离开、取消、按钮隐藏或组件卸载会取消计时。按 pointerId 区分触点，不要求主触点，兼容另一手操作摇杆。
- 保留单击切换、附近设施优先交互、打桩、解绳和长按选择流程；闲置隐藏时禁用按钮，死亡时隐藏背包入口。

### 适配与性能
- `hud/controlStyles.ts` 独立管理按钮尺寸、定位、触控与浅色外观，`hud/styles.ts` 管理状态瓶／卡片并组合按钮样式，由 `GameplayUI.tsx` 统一挂载。按钮不继承状态区的定位和 pointer-events:none。竖屏右侧上下排列入口，500px 以下短横屏改为右下方并排，避开右上角展开的小地图。
- 375px 竖屏状态瓶在左上角，可用空间不足时状态瓶排到 Buff 下方，保持顶部对齐；Buff 紧挨信息卡片右侧，从顶部横向排列，到设置按钮左边界自动换行；地图折叠时右侧控件宽 100px，展开时宽 190px，另计屏幕右侧安全区。Buff 按钮为 26.4px，列间距 4px；不足一列时信息卡片换到 Buff 下方。大量 Buff 限高为 40dvh，可触屏纵向滚动。
- 控件使用 CSS 渐变、SVG 与有限次数提示；仅三瓶共用一个极小 WebGL 画布，不为各瓶单独创建上下文，不使用大面积背景模糊。
- 遵循 `prefers-reduced-motion`，关闭 CSS 过渡与动画，同时保留低值文字、颜色和长按逻辑；瓶体 shader 按需静态绘制。

### 联机与存档
- 房主/客人的 HUD 均读取现有本地玩家 `HudSnapshot`；权威生存结算、动作上行、快照回流与事件补播维持现有职责。
- 按压、液位和低值动效仅为各端本地表现，不增加网络动作或快照字段。不改持久化数据及 `SAVE_VERSION`。

### 游戏内面板
- HUD 配套面板与提示统一复用 `src/ui/gameTheme.ts` 的奶油／鼠尾草主题，覆盖范围、手机适配和样式职责见 [游戏内界面统一样式](game-ui-theme.md)。开始页与荒岛传承保持各自样式。

### 顶部界面显示规则

Buff 气泡整体尺寸为 26.4×26.4 CSS px（原 44px 的 60%），图标、圆角与剩余时间同步按 60% 缩小。状态区和设置/小地图区共用 hud-top-edge 顶部安全区偏移。状态区可用宽度不足 148px 时（包括浏览器放大后），Buff 保持顶部，状态瓶卡片排到下一行，避免窄屏规则把整个状态区下移而错位。

### 任务指引

状态卡下方的“荒岛起步”卡采用同一奶油／鼠尾草主题，只显示当前任务。卡片主体可点击自动前往任务目标，再点停止，右上角独立按钮展开/折叠目标，短横屏隐藏辅助行，保留手机44px触控区；Buff继续排列在信息卡右侧。任务完成、关闭设置或拍照时按对应规则隐藏，详见 [任务指引](quest-guide.md)。

# 游戏 HUD 与触控反馈

## 背景
游戏内入口与生存信息需要适配手机触屏，让玩家在观察世界的同时迅速识别状态、当前工具和可交互对象。

## 需求描述
- 左上角以生命、饱食、水分三条图形化状态条取代常驻数值；天数与季节作为次级信息。
- 背包、工具、设置使用统一深海色半透明底、细边框和柔和阴影；背包与设置采用手绘 SVG 图标。
- 提供按压反馈、状态值平滑过渡、低值警示、工具长按进度和设施交互提示。
- 手机竖屏优先，短横屏避让小地图；兼容存档、单机与房主/客人联机。

## 设计方案
### 信息层级
- `src/ui/hud/VitalMeter.tsx` 读取现有 0–100 状态，生命条略粗，饱食与水分条分行排列；用图标、文字与珊瑚红／沙金／水蓝共同区分，四段刻度辅助判断余量。
- 数值通过 `role=meter` 与无障碍属性提供，不常驻显示数字。状态值限制在 0–100 内；归零时条为空。
- 状态条使用 transform 过渡，浅色延迟层体现变化。任一状态 ≤20 时显示「危险／饥饿／缺水」并缓慢闪动图标，阈值与角色旁既有低值提醒一致。
- `Hud.tsx` 保留生命图标隐藏 GM 入口，触控区 44px；buff 为 44px 按钮，保留持续时间与详情。卡片为小地图预留宽度，空白区域不阻挡场景触控。

### 操作入口
- `hud/HudIcon.tsx` 使用代码绘制背包、齿轮和状态图标；工具与设施继续复用既有道具图标。
- 背包与工具为 72px 圆角方形按钮，设置和地图为 46px；按压时缩小并加深阴影，设置齿轮轻转、背包图标轻微倾斜。背包和设置面板有短暂入场动效。
- 工具按钮显示当前工具或设施名称，保留弹药数量角标；设施出现时外圈提示三次，避免持续缩放干扰。下方提示「长按选择」。
- 按住工具 350ms 时外圈进度完成并打开选择器，吞掉这次点击；超过 12px 的滑动、离开、取消、按钮隐藏或组件卸载会取消计时。按 pointerId 区分触点，不要求主触点，兼容另一手操作摇杆。
- 保留单击切换、附近设施优先交互、打桩、解绳和长按选择流程；闲置隐藏时禁用按钮，死亡时隐藏背包入口。

### 适配与性能
- `hud/styles.ts` 集中管理样式，`GameplayUI.tsx` 统一挂载。竖屏右侧上下排列入口，500px 以下短横屏改为右下方并排，避开右上角展开的小地图。
- 使用 CSS 渐变、SVG 与有限次数提示，不新增渲染器、逐帧 React 更新、音频上下文或大面积背景模糊。
- 遵循 `prefers-reduced-motion`，关闭过渡与动画，同时保留低值文字、颜色和长按逻辑。

### 联机与存档
- 房主/客人的 HUD 均读取现有本地玩家 `HudSnapshot`；权威生存结算、动作上行、快照回流与事件补播维持现有职责。
- 按压、进度条和低值动效仅为各端本地表现，不增加网络动作或快照字段。不改持久化数据及 `SAVE_VERSION`。

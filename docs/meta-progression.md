# 荒岛传承(局外养成)

## 背景

单机模式下给玩家一个跨局成长的长期目标:每一段生存沉淀为"求生心得",用于在局外领悟三分支(采集/钓鱼/捕猎)共九个节点的本领,让下一局从开局就带着经验活得更久。

## 需求描述

- 单机模式下,按生存天数获得局外货币**求生心得**:**生存超过 2 天**的局才结算(死亡或主动重开),`心得 = 天数 × 10`。
- 三分支九节点,每节点 3 级,每级一个独立效果(特性/机制型为主,非纯数值堆叠)。
- 消耗标准档:每级 **30 / 60 / 120**,单节点 210,全树 1890。
- 主菜单提供「荒岛传承」面板入口;**心得为 0 且无任何已解锁节点时隐藏入口**(新玩家第一次结算后才出现)。
- 联机对局不生效(房主/客人都不带加成),不做同步。
- GM 面板可直接设置求生心得数值。

## 设计方案

### 数据与存储

- 独立 localStorage key `island.meta.v1`,与存档完全无关,死亡清档不影响它。结构 `{ points, levels: {节点id: 等级} }`,读取时对未知节点/越界等级做归一,天然向后兼容。
- `src/game/meta/` 三件套:
  - `MetaTree.ts` — 分支/节点/效果文案/消耗的静态定义(UI 与逻辑共用);
  - `MetaProgress.ts` — 持久化与 API(`points/setPoints/grant/level/upgrade`),含 `legacyPointsForDay`;
  - `MetaDaily.ts` — "每天第一次"类标记的运行时状态,Game 主循环里 `ensure(day)` 跨天重置,不入档。
- 注入接口 `MetaHooks.ts`(`CollectMeta`/`FishingMeta` + 空实现):Game 按单机/联机提供真实实现或空实现,玩法系统只依赖接口。

### 结算链路

- **死亡**:单机死亡 `buildDeathReport` 时计算 `legacyPointsForDay(day)` 并 `MetaProgress.grant`,写入 `DeathReport.legacyPoints`;死亡界面心得 >0 显示金色"求生心得 +N(生存了 M 天)",≤2 天显示灰字"生存不足 2 天"。
- **主动重开**:开始界面"开新档"且旧档超 2 天时弹确认("放弃这座岛?"),确认后结算心得再清档。

### 九节点效果与注入点

| 分支 | 节点 | Ⅰ | Ⅱ | Ⅲ | 注入点 |
|---|---|---|---|---|---|
| 采集·巧匠 | 拾穗 | 草丛/灌木 10% 额外 1 份 | 摘果 10% 多 1 果 | 每日首次采集双倍(再结算一次 yield) | `CollectSystem.applyMetaYield` |

### 联机约定

- 局外加成只在单机生效:`Game.metaOn = !hostRef && !guestMode`,联机下所有 `metaLevel()` 恒 0、每日标记不可消费,房主/客人结算一致,无同步改动。

### UI

- `src/ui/MetaPanel.tsx`:全屏面板,顶部心得余额,三分支分节、节点卡片(壹/贰/叁效果列表 + 领悟按钮),点满显示"圆满";竖屏适配、按钮 ≥44px。
- `StartScreen` 新增「荒岛传承」入口(有心得/已解锁时显示)与开新档确认弹窗。
- GM 面板「玩家」tab 新增"求生心得(局外)"步进设置。

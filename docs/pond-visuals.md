# 水洼视觉

## 背景
内陆淡水需要与海水保持相近的水面质感,呈现更平静、清澈的池水。

## 需求描述
- 水边浅绿透底,向洼心过渡为深青色,保留鱼影与涉水反馈,偶尔冒出小气泡并产生小水波。
- 加入缓慢交错的细波、柔和反光,岸线保持稳定。
- 手机端使用单层水面,支持结冰与融化,兼容现有存档和联机玩法。

## 设计方案
- `PondPlacement` 在生成时以不超过 1 米的间隔采样整个外接方形,向外增加 2.6 米地形网格余量。水位不超过最低采样地势减 0.3 米,覆盖地表微起伏并保留干岸;水位最低为海面以上 0.35 米且不低于中心地面减 1.2 米,无法满足时跳过该候选位置。相邻水洼外接圆之间保留 2.6 米,避免挖坑相互破坏岸边。
- 下挖深度最多消耗原地面到海面以上 0.1 米之间的土层,不抬升原本较低的地面,坑边连续接回原地形。水面仍依靠实际水深渐隐,不以透明度掩盖漏水边界。
- 候选点、筛选和水位均由同一地形种子确定,仅初始化采样,不增加逐帧开销。旧档可继续读取且不修改存档版本;重建时部分水洼的位置、水位会调整。
- `PondMaterial` 基于 `MeshStandardMaterial` 注入程序颜色与世界空间波纹法线,保留场景光照、昼夜和雾效果。
- 每处水洼初始化时按最终地形三角网格插值高度生成 64×64 单通道深度纹理,根据真实水深调整颜色和透明度。贴岸渐隐,深处逐渐遮蔽洼底。
- 水面不叠加点阵光斑;波纹只改变着色法线,水位与轮廓固定,与玩法判定一致。
- 每处水洼维持一个绘制批次,不增加反射相机、后处理或逐帧地形采样。透明水面关闭深度写入,保留深度测试;退出时释放水面纹理、材质与几何体。
- 可冻水洼随雪量淡出并隐藏,融化时每帧恢复透明度与可见性。
- 主客各自运行材质时间,地形种子与季节沿用已有同步。喝水、钓鱼、鳄鱼和游泳结算不变,无需新动作、快照字段或事件,存档版本不变。

- `PondBubbles` 每处水洼每 7～14 秒尝试生成一个微小气泡,全场上限 24 个,共用几何体和材质。只在足够深的未结冰淡水生成,上浮到水面后移除并调用 `WaterFx.ripple` 产生四分之一尺寸的细波;结冰时直接移除。

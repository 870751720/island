# 钓鱼(鱼竿制作流程)

## 背景

荒岛求生需要更多食物与玩法来源,规划钓鱼系统。第一步先落地鱼竿的获取链路:鱼竿 = 树枝 + 绳线,其中绳线是新引入的基础材料,为后续弓、绷带等绳类配方复用。

## 需求描述

玩家在岛上采集草丛获得「植物纤维」,用手搓配方把 3 个纤维搓成 1 条「绳线」,再用 1 木材 + 2 绳线合成「鱼竿」。鱼竿作为可拥有、可切换手持的工具,与斧子/镐子同级。

## 设计方案

- 新资源点「草丛」(`grass`):6 片交叉低多边形叶片,单次采集(1 命中,pick 动作)产出 2 植物纤维,180 秒再生;岛上散布 26 处。
- 新道具「植物纤维」(`fiber`)与「绳线」(`rope`):进背包格子制,可叠加、可丢弃,掉落物外观为八面体(绿/米黄)。
- 配方系统升级(`Crafting.ts`):`Recipe` 区分两类——工具类(`tool` 字段,制作后永久拥有并拿在手上,一次性)与材料类(`output` 字段,产物进背包,可反复制作)。
  - 绳线:纤维 ×3 → 绳线 ×1(可重复手搓)
  - 鱼竿:木材 ×1 + 绳线 ×2(一次性工具)
- 鱼竿手持模型:细长树枝圆柱 + 竿梢垂下的浅色钓线,握右手,循环切换 空手 → 斧子 → 镐子 → 鱼竿。
- 合成卡片 UI:工具类在未拥有且材料齐时出现;材料类只要材料齐就出现。

## 迭代记录

### 2026-09-07 鱼饵改为独立弹药存储

鱼饵不再进背包格:数量存于 `PlayerSession.ammo`(`AmmoStore`,与 tools/equipped 同级,无上限叠加),饵料桶收取/掉落物捡回经 `Game.giveItem` 分流入弹药;抛竿消耗改读弹药存储。工具按钮持鱼竿角标显示 🧆+剩余鱼饵数,死亡按 `DEATH_DROP_RATIO` 掉落。蚯蚓(`worm`)仍是背包道具,仅作为饵料桶投喂原料。详见 `docs/bow.md` 的弹药存储说明。

### 2026-09-07 杂物池新增燧石

石类资源点不可再生,燧石长期会被火堆点火耗尽。一档杂物池(`JUNK_LOOT`)新增燧石 `flint`(权重 2,介于石头/树枝与可乐之间),让钓鱼成为燧石的补充来源。

### 2026-09-07 水洼/海水分域钓池 + 新增鱼种

钓点水域(`IslandTerrain.getWaterKind`:海水 `sea` / 内陆水洼 `pond`)区分二三档鱼池;一档杂物与四档珍宝两域共用,珍宝保底(已抽中降权、集齐重置)不变。`FishingSystem.start()` 在浮漂落点取水域,传入 `rollLoot(tier, waterKind)`;结算仍在房主端,联机无需新增同步字段。

| 水域 | 小鱼(二档) | 大鱼(三档) |
|---|---|---|
| 水洼 | 鲈鱼、虾、泥鳅、河豚、蟹肉 | 巨鲶、草鱼(新) |
| 海水 | 沙丁鱼、墨鱼、鳀鱼(新)、竹荚鱼(新)、小黄鱼(新)、秋刀鱼(新)、带鱼(新) | 石斑鱼、剑鱼、魔鬼鱼 |

新增 6 种鱼(均为食物,生食数值随档位:小鱼 +10 饱食/+5 口渴,大鱼 +20/+10;可烤成烤小鱼/烤大鱼,饵料桶兑换小鱼 4、大鱼 10):

- 鳀鱼 `anchovy`(海水二档,权重 4,最常见)、竹荚鱼 `horseMackerel`(3)、小黄鱼 `yellowCroaker`(3)、秋刀鱼 `saury`(2,细长)、带鱼 `hairtail`(2,细长)
- 草鱼 `grassCarp`(水洼三档,与巨鲶各半权重)

### 2026-09-07 调低珍宝与裸钓概率

有饵四档权重由 25/40/30/5 调整为 25/40/34.5/0.5(珍宝 5%→0.5%,差额给大鱼);无饵裸钓权重由 90/6/3/1 调整为 90/6/3.9/0.1(珍宝 1%→0.1%,差额给大鱼)。改动位置:`GmSystem.fishingTierWeights` 与 `FishTable.BAITLESS_TIER_WEIGHTS`,抽取逻辑不变。

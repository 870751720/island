# 钓鱼(鱼竿制作流程)

## 背景

荒岛求生需要更多食物与玩法来源,规划钓鱼系统。第一步先落地鱼竿的获取链路:鱼竿 = 树枝 + 绳线,其中绳线是新引入的基础材料,为后续弓、绷带等绳类配方复用。

## 需求描述

玩家在岛上采集草丛获得「植物纤维」,用手搓配方把 3 个纤维搓成 1 条「绳线」,再用 1 木材 + 2 绳线合成「鱼竿」。鱼竿作为可拥有、可切换手持的工具,与斧子/镐子同级。

## 设计方案

- 新资源点「草丛」(`grass`):6 片交叉低多边形叶片,单次采集(1 命中,pick 动作)产出 2 植物纤维,60 秒再生;岛上散布 26 处。
- 新道具「植物纤维」(`fiber`)与「绳线」(`rope`):进背包格子制,可叠加、可丢弃,掉落物外观为八面体(绿/米黄)。
- 配方系统升级(`Crafting.ts`):`Recipe` 区分两类——工具类(`tool` 字段,制作后永久拥有并拿在手上,一次性)与材料类(`output` 字段,产物进背包,可反复制作)。
  - 绳线:纤维 ×3 → 绳线 ×1(可重复手搓)
  - 鱼竿:木材 ×1 + 绳线 ×2(一次性工具)
- 鱼竿手持模型:细长树枝圆柱 + 竿梢垂下的浅色钓线,握右手,循环切换 空手 → 斧子 → 镐子 → 鱼竿。
- 合成卡片 UI:工具类在未拥有且材料齐时出现;材料类只要材料齐就出现。

- 2026-08-28:钓鱼玩法落地(`FishingSystem` + `FishingControls`)。
  - 可钓点:水洼边(与喝水同逻辑,距水洼 1.2 内的干地)或海边(距海面水线水平 1.5 米内,`IslandTerrain.isNearSea`);玩家持有鱼竿且空手站定 3 秒自动切换到鱼竿(与斧/镐自动切换同机制,头顶显示「切换鱼竿…」)。
  - 流程:手持鱼竿站定 → 屏幕中下方出现「🎣 钓鱼」按钮 → 点击抛竿(0.7 秒,浮漂抛物线落水溅起涟漪)→ 等待 4~9 秒随机(浮漂随水轻晃、周围泛涟漪)→ 咬钩:浮漂猛沉+水花+全屏橙色闪烁提示「咬钩了!点一下屏幕!」→ 1.3 秒内点击屏幕任意处即收竿(鱼抛物线飞向玩家、旋转翻腾,进背包);超时鱼跑,涟漪散开收竿。
  - 反馈:头顶指示文字(抛竿…/等待上钩…/咬钩了!/收竿!)+ 进度圆环(抛竿进度、咬钩倒计时、收竿进度);咬钩瞬间 HUD 立即推送不节流。
  - 交互让位:钓鱼期间采集/喝水/进食让位;移动、游泳或其他占用双手的行为立即中断钓鱼(浮漂与鱼清除,不给鱼);喝水进行中也无法抛竿。
  - 鱼为背包道具(`fish` 🐟),可叠加可丢弃;烤鱼/食用留待后续迭代;背包满时收竿鱼会掉落消失(灰色粒子提示)。

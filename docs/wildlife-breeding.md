# 羊与牛的幼崽和自然繁殖

## 背景

绵羊和野牛按栖息地分布，每处基础投放三只。加入无需喂养的野生繁殖，让玩家在探索中遇见幼崽，同时保持手机端可控的动物数量。

## 需求描述

- 每个栖息地最多四只，其中最多一只未成年；野生动物走远、被牵走或拴桩仍占原栖息地名额；驯养成功后退出野生名额和繁殖配对。
- 初始投放和常规补刷时，若该栖息地没有幼崽，每只新动物有 10% 概率是幼崽。任务保底补羊和 GM 生成保持成年。
- 两只同类成年动物自然繁殖，不区分公母、不需要喂养。已有幼崽或总数达到四只时不繁殖。
- 出生前五秒，两只父母停下，头顶显示薯条同款爱心 SVG；没有白色背景。出生或繁殖中断时消失。
- 小羊、小牛固定小体型，经过五个游戏日直接变成成年体型；离线不推进，睡觉跨天计入成长。
- 幼崽被击杀固定掉落一块兽肉和一份皮毛，不追加季节、养成加成或牛的种子掉落；成年恢复原有掉落。
- 幼崽生命为成年一半：小羊 50，小牛 75；成年恢复正常上限，并保留生命百分比。小牛受击只逃跑，不激怒或攻击；幼羊和幼牛可套索驯养，成年后才开始十分钟产奶计时；成年驯养羊已有完整羊毛可立即剪，剪后十分钟重新长好，详见 `animal-husbandry.md`。

## 设计方案

### 栖息地与繁殖

`WildlifeLifecycle` 独立负责成长、配对和数量规则。个体通过原栖息地关联统计。常规补刷只恢复到三只；繁殖最多补至四只。出生优先使用空缺基础名额，否则使用同一栖息地的第四个名额；正在繁殖的栖息地暂停常规补刷。

成年动物生成或幼崽成熟后等待一个游戏日才可配对；同栖息地成年同类距离不超过六米、未受惊、未激怒且未被套索控制时开始五秒提示。成功出生后双方冷却三个游戏日。受伤、死亡、套索、受惊、距离超限或找不到出生落点会取消本次繁殖，等待 0.1 个游戏日再尝试。

出生落点在父母旁草地，检查阻挡、其他动物和栖息地边界，不使用常规补刷的离玩家 45 米限制。幼崽平静游荡时优先选择同栖息地成年动物附近的目标；落单时继续在栖息地活动。

### 模型与提示

复用程序化羊/牛模型，幼崽整体为成年尺寸的 55%，头部相对放大为 118%。保留原成年模型比例，成熟时一次性恢复。爱心复用 `DOG_EMOJI_SVG['❤️']`、屏幕空间投影和缩放尺寸规则，DOM 层禁用点击，不增加模型 drawcall。

### 存档

世界存档新增可选 `wildlife`，保存存活羊/牛的位置、所属栖息地、生命值、出生日期、繁殖可用日期、拴桩和产奶状态，以及基础名额补刷冷却。读档恢复个体并重新分配名额，不再额外生成同一只拴桩羊。正在进行的求偶不保存五秒进度，读档后若仍符合条件，重新显示完整五秒提示。

`SAVE_VERSION` 保持 32；旧档缺少字段时沿用原来的栖息地生成和按桩恢复羊，新生成幼崽从读档时刻开始计龄。

### 联机

房主独立运行配对、出生、成长、掉落和存档，客人只插值位置与播放表现。动物快照新增 `juvenile`、`breeding` 布尔字段，始终携带以便差分清除；新生动物沿用未知 ID 创建机制。当前网络协议版本为 43，详见 `multiplayer.md`。

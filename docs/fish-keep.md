# 鱼护与箱子交互
## 背景
海边连续钓鱼需要就近收存鱼获，避免占满玩家背包。
## 需求描述
- 鱼护为设施类道具，四级工作台解锁，配方为10绳线、2木头、2铁锭。
- 采用顶部开口的圆筒网兜、三道金属支撑圈及交错绳网，场景、手持、掉落模型和图标造型统一，提供20格空间，沿用箱子堆叠与手动存取规则。
- 与海水净化器共用放置条件：浅海或距海线1.5米内湿沙滩，不允许水洼、游泳时放置或占用已有设施/资源点。
- 收获时按玩家水平位置查找10米内（含边界）最近且能容纳该水产的鱼护。鱼获直接存入鱼护，模型从浮漂飞入鱼护，不飞向玩家。
- 包含普通鱼、大鱼、虾、墨鱼、蟹肉和黄金鱼；杂物、种子及其他珍宝沿用背包收获。多个鱼护时跳过无法容纳的；无可用鱼护时进背包，背包满则按既有规则落地。同类物品可以继续堆叠。
- 靠近可通过触屏工具按钮打开存取面板，铲回时鱼护和内容物一起返还，背包装不下则落地。
- 木箱、铁箱、鱼护的工具按钮、面板与挖掘提示均展示实际种类，修复铁箱被显示为木箱的问题。
## 设计方案
- 扩展现有CrateKind，复用CrateSystem的存取、占格、挖掘、存档与世界增量；共用wetBeachCellReason避免与净化器放置规则分叉。
- 房主在钓鱼收获回调中权威选择鱼护、更新槽位；客人沿用钓鱼与箱子动作上行，依靠crates槽位增量接收结果。
- fishKeepFly事件携带鱼获、数量、浮漂起点及鱼护终点，每个客人（包括钓鱼本人）补播一次飞行；不产生背包增加事件。每批鱼获的最后一个飞行模型到达后，在鱼护上方显示金色“鱼护入鱼”，沿用任务完成提示的1.6秒淡入上浮动效；20米内播放一次现有pickup入包音效。提示逐帧投影跟随相机，不进入存档。
- HUD同步crateKind驱动名称和图标，不按容量猜测种类。打开界面与铁箱一致，以5列4行直接展示20格，无翻页，面板可滚动，模型采用基础几何体并合并网格。
- 新增持久化ID fishKeep，不修改已有ID或SAVE_VERSION，旧档无需新增字段即可继续读取。加载较大容量的容器时先将超出格子合并到可用格，仍放不下的由权威端生成鱼护旁掉落，防止缩容丢失物品。

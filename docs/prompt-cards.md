# 弹出提示卡片

## 背景

捡回、进食和手搓制作卡片共用工具按钮下方的位置,按优先级互斥。制作提示用于引导,单机用户点过的配方无需反复提醒。

## 需求描述

- 制作、捡回、进食(含吃饱按钮)的卡片统一位于右侧工具按钮下方,上边缘为 `calc(50% + 61px)`,右侧保留安全区。
- 单机制作卡片按配方记录点击,本局点过后不再弹出该配方（当前任务需要的配方除外）;不以制作成功为记录条件。未点过的其他配方仍正常提示。
- 捡回与进食继续按原有条件反复出现。联机房主与客人的制作卡片也保留原有重复提示规则。
- 移动中隐藏;同一时刻按捡回 > 进食 > 制作显示。

## 设计方案

- `promptCard.ts` 提供共享外观和定位,卡片白色 2px 边框、奶油底,沿用 HUD 闲置淡出。
- `useCraftPromptHistory` 仅在本次 GameplayUI 生命周期的内存中保存已点击配方 ID；退出、刷新或新游戏后清空。不再读取或写入 localStorage，不改变世界存档或 `SAVE_VERSION`。
- `topHandRecipe` 排除本局已点击的非任务配方，当前任务及其前置配方绕过点击历史过滤;触屏卡片和桌面 F/G 快捷键共享筛选规则,F 触发制作时也记入历史。背包制作列表不受影响。
- 适用的制作卡片:木斧、木镐、工作台、火堆、草衣、草裤、草帽、草包。火把原本不弹卡,工作台配方不属于手搓提示。
- 捡回仍要求附近有掉落物、未死亡、未移动且背包关闭;进食仍要求饥饿低于阈值、有食物且非进食中,多份食物显示吃饱按钮。制作仍要求材料齐全、配方可见、工具尚未拥有且无制作进行中。
- 点击历史仅是单机本地 UI 偏好;切换为联机房主时不应用历史。联机制作仍经原动作上行、房主权威结算和快照回流,不新增网络消息。

任务需要的可制作手搓卡片使用任务描边和六枚暖金光点，沿卡片边缘4.8秒匀速环绕，不遮文字、不接收触控。任务卡片不因闲置而淡出；移动、制作中及拾取/进食优先级仍生效。关闭任务指引后恢复普通卡片样式、历史过滤及闲置淡出。减少动态效果时光点静止。粒子使用本地 CSS，不新增 WebGL 开销或联机消息。

# 桌面端键盘快捷键

## 背景

游戏以手机触屏为第一适配目标,桌面端此前仅有 WASD/方向键移动(`MoveInput`)和 Q 切换工具(`Game` 内直接监听 keydown)两个补充操作,键鼠体验不完整。需要为电脑版补齐一套与触屏操作一一对应的键盘快捷键,不改变手机端任何行为。

## 需求描述

| 按键 | 行为 | 对应触屏操作 |
|---|---|---|
| WASD/方向键 | 移动(已有) | 虚拟摇杆 |
| B | 开关背包 | 背包按钮 |
| Q 短按 | 循环切换手持工具 | 工具按钮点按 |
| Q 长按(0.35s) | 打开手持/表情选择面板 | 工具按钮长按 |
| 1~4 | 发送对应快捷表情(😍😭😡😱,与选择面板顶部表情区顺序一致) | 长按面板顶部表情区点选 |
| M | 开关小地图 | 地图按钮 |
| Esc | 逐层关闭已打开的弹层;全部关闭后再按打开设置 | 设置按钮 |
| F | 触发当前可见的提示卡(捡回 > 进食 > 手搓,与卡片互斥优先级一致) | 点击提示卡 |
| G | 触发进食卡的「吃饱」(连续吃到满) | 进食卡「吃饱」按钮 |

边界约定:拍照模式中 Esc 退出拍照;死亡、拍照/设置/GM 全屏弹层期间玩法键不响应;焦点在文本输入控件(设置/GM 面板)时按键不拦截;带 Ctrl/Meta/Alt/Shift 修饰键不触发。

## 设计方案

- **`src/ui/useKeyboardShortcuts.ts`**:统一挂在 `window` 的 keydown/keyup 钩子,由 `GameplayUI` 传入 `gameRef` 与各弹层开关状态。监听只挂一次、状态经 latest ref 读取——避免 HUD 快照高频更新导致重挂监听、打断 Q 长按计时。
- **Q 长按语义与工具按钮一致**(`TOOL_HOLD_MS = 350`):按下起计时,超时弹出选择面板并吞掉本次短按(且忙碌/移动中不弹,同按钮淡出语义);提前抬起在 keyup 时触发 `Game.cycleTool()`。Q 从 `Game.ts` 的 keydown 监听迁入本钩子,`Game` 不再自带键盘监听;窗口失焦收不到 keyup 时按住状态作废(不触发切换)。
- **`src/ui/promptActions.ts`**:从 `CraftPrompt` 抽出「当前最高优先级手搓配方」(`topHandRecipe`),并与 `promptVisibility` 组合成「当前唯一可见提示卡」(`currentPromptCard`:drop/eat/craft)。F/G 键与卡片渲染共用同一判定,不重复实现显隐条件。
- **Esc 关闭层级**:拍照 → 设置 → GM → 设施面板 → 选择面板 → 背包 → 地图,逐个关闭;全关后且未死亡时作为设置按钮的键盘入口。
- **联机**:Q/B/M/Esc 纯本地;F/G/表情走 `Game` 既有动作入口(客人 `action` 上行、房主 `Actions.ts` 权威结算),无新增同步内容。

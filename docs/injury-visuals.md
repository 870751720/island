# 玩家持续受伤表现（伤口与冒血）

## 背景

受击瞬间已有闪红/粒子/飘字/音效反馈，但血量处于低位时缺少持续性的"带伤/濒死"外观，玩家对自己伤势的严重程度感知不强。

## 需求描述

- 血量 < 50：玩家模型身上出现伤口表现（暗红伤口贴片），伤势越重伤口越多。
- 血量 < 20：在伤口基础上加重——伤口数量最多，且身上持续冒血（血滴从伤口滴落）。
- 不做其他表现（无 HUD 变化、无红屏 vignette、无跛行等）。

## 设计方案

- 新增 `src/game/fx/InjuryFx.ts`：挂在玩家模型上的受伤外观模块。
  - 伤口：5 个暗红色薄盒贴片，分别贴在躯干（正/侧/背）、左臂、左腿表面，随部位（肢体摆动）一起运动。
  - 数量分档：≥50 无；<50 显示 3 处；<35 显示 4 处；<20 全部 5 处并渗血。
  - 血滴：对象池（10 枚小血珠），濒死时每 0.22s 从随机一处已显现伤口出生，短寿命（0.45s）重力下落，避免随肢体摆动明显漂移；未激活时隐藏复用，零额外 drawcall 增量以外的常驻成本可控。
- `Player` 新增 `setHealth(health)`：仅作表现驱动的血量镜像，权威值仍在 `SurvivalSystem`；`update()` 每帧先于一切姿态更新（含倒地/睡眠）驱动 `InjuryFx`。
- 联机：房主端在权威生存结算循环、客人端在快照应用处各自调用 `setHealth`（血量本就随快照回流），伤口/血滴属于纯本地表现，无需新增同步消息。参见 `docs/multiplayer.md`。

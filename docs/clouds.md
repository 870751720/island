# 云层表现

## 背景
云层沿用岛屿鲜明的低多边形切面风格，以少量完整的大云体营造天空层次。

## 需求描述
- 保留尖角和大块平面，每朵云具有连续、完整的轮廓。
- 不生成独立小碎云或分离的拖尾；通过宽厚、狭长和高冠三种整体轮廓变化丰富云形。
- 保留缓慢漂移、地面投影与手机端低开销。

## 设计方案
- `CloudModel.ts` 每朵云用一个宽阔主体和三个深入主体的大块组合，主体贯穿整个底部，其余块仅贡献边缘起伏与顶部高低变化。
- 使用未细分二十面体、共享白色标准材质、高粗糙度与 flatShading，由场景光照呈现切面明暗。局部比例仅小幅扰动，保证块间充分交叠。
- 六朵大云覆盖每种轮廓两朵，整体变化大小、厚度和朝向。每朵合并为一个网格，共 480 个三角形，主渲染最多六次云层绘制，投影另计。
- 每帧仅移动整朵云，根据完整包围范围在岛外回绕，退出时释放几何体与材质。
- 房主与客人各自运行纯本地云层表现，不参与权威结算，无动作上行、快照字段、事件补播或存档变化。

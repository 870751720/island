# 云层表现

## 背景
参考图前景的独立白云，以柔软、半透明的棉絮感增加岛屿空间层次。

## 需求描述
- 云朵保持稀疏、独立，避免连续云海和大片遮挡。
- 轮廓圆润不规则，中心柔白，边缘逐渐透明，底部略带冷灰层次。
- 缓慢漂移，兼容手机画面和拍照相机。

## 设计方案
- `CloudModel.ts` 用相交椭圆密度场及低频扰动生成三张 256×128 RGBA 纹理，不引入外部图片或模型。每朵云的云瓣预先融合，消除透明粒子层叠的开销。
- `Clouds.ts` 保留六朵云，以两列三行分布和统一缓慢漂移保持留白，云宽为 19–23 世界单位，完整离开范围后回绕。
- 每朵使用一个共享平面和三种共享标准材质之一，随场景光照变化。透明混合、关闭深度写入、保留深度测试，边缘自然显露背景；不投射硬边阴影。
- 渲染前对齐相机，支持正常视角和拍照旋转。总计 12 个三角形、最多六次云层绘制，无额外阴影绘制、无每帧纹理生成。退出时释放几何体、纹理和材质。
- 房主与客人各自运行纯本地表现，不参与权威结算，无动作上行、快照字段、事件补播或存档变化。

# 云层表现

## 背景
云层沿用岛屿鲜明的低多边形切面风格，通过不同空间轮廓丰富天空。

## 需求描述
- 保留尖角和大块平面，不细分成圆润的统一积云。
- 同时出现狭长风带、紧凑团簇、扁平云片、偏心高冠、弯月云和小碎云。
- 大小云组合成云群，主体部分交叠、边缘碎云留白，整组一起漂移。
- 保留缓慢漂移、地面投影与手机端低开销。

## 设计方案
- `CloudModel.ts` 定义六类独立空间布局，每类由三至四个未细分二十面体组成；通过云团局部旋转和比例扰动产生同类差异，整体再变化大小、厚度和朝向。
- 使用共享白色标准材质、高粗糙度与 flatShading，由场景光照呈现切面明暗。
- `CloudCluster.ts` 将六种云形组合为宽云群、拖尾云带和错层云簇，每组四至五朵，包含主云、搭接的次云和分离的小碎云。
- 九组云覆盖每种组合三组，整组合并为一个网格，共 3,060 个三角形，主渲染最多九次云层绘制，投影另计。每帧仅移动组位置，成员保持相对位置与共同速度；根据整组包围范围在岛外回绕，退出时释放几何体与材质。
- 房主与客人各自运行纯本地云层表现，不参与权威结算，无动作上行、快照字段、事件补播或存档变化。

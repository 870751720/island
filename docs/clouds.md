# 云层表现

## 背景
高空云层需要符合岛屿的手工黏土风格，并在手机画面中呈现容易辨认的积云轮廓。

## 需求描述
- 云底平缓、云冠饱满，大小团块紧密重叠，避免尖锐石块和整齐串珠的观感。
- 各朵云具有不同的尺寸、厚度、朝向和局部比例；保留缓慢漂移与地面投影。
- 手机端控制绘制调用，不引入纹理、模型文件或额外渲染通道。

## 设计方案
- `CloudModel.ts` 用七个细分二十面体构造云底、主云冠和侧缘，压薄下半球形成柔和底线；每朵合并为一个几何体。
- 使用高粗糙度、flatShading 的共享标准材质，顶点颜色从底部淡蓝灰渐变至顶部暖白，继续响应场景光照。
- 保持十二朵云，每朵 1,260 个三角形、一个网格，共 15,120 个三角形；主渲染最多十二次云层绘制，投影另计。每帧仅更新位置，退出时释放几何体与材质。
- 云层属于本地环境表现，房主、客人各自漂移，不参与碰撞、天气或生存结算，无动作上行、快照字段或事件补播；存档版本不变。

# 地点预览场

## 背景

村落与遗迹需要反复调整轮廓与摆放。用独立展示页复用正式布局和模型，在本地热更新后检查，定稿再统一部署。

## 需求描述

- 手机竖屏优先，兼容横屏；点选全部地点、单指旋转、双指缩放，也提供放大、缩小、复位按钮。
- 白天与夜晚切换，固定整数种子控制布局随机选择，可换一组查看工坊设备与猎人物资抽取；各地点作物配色固定，帐篷统一一级。
- 不启动游戏循环，不读取或写入存档，不连接联机房间。

## 设计方案

### 使用

在仓库根目录运行 `npm run dev:preview`。电脑访问 `http://localhost:3000/island/landmark-preview`；手机与电脑连接同一 Wi-Fi 后访问 `http://电脑局域网IP:3000/island/landmark-preview`。可以用 `ipconfig` 查看正在使用的网卡 IPv4 地址。若端口被占用，以终端实际打印的端口为准；手机无法连接时检查 Windows 防火墙是否允许 Node 在专用网络接入。

保留服务运行，修改 `src/game/world/landmarks/LandmarkDefinitions.ts` 或实体模型代码后页面通过 Next.js 热更新刷新效果，无需提交或部署。停止时在终端按 Ctrl+C。线上也可使用 `/island/landmark-preview` 页面，但线上代码更新仍需部署。

### 模块

- `LandmarkPreview`：选择、种子、加载反馈及移动端布局。
- `LandmarkPreviewScene`：正交相机、触屏 OrbitControls、低档阴影、昼夜灯光与资源释放。
- 正式模板拆分为生活地点与遗迹，预览直接读取同一份蓝图；每处最多一张一级床，遗迹没有床。
- `PreviewModels`：从正式蓝图实例化现有实体，围栏复用 `buildFenceMesh` 并按邻接点连接，门补齐端柱连接。
- 展示不调用游戏系统；种子约束布局中的随机分支，不保证模型内部随机纹理细节逐像素一致。作物统一成熟，火堆沿用空燃料状态，神龛与火把保留动画。

### 性能与边界

仅显示一个地点，像素比上限 1.5，阴影 512，点光源池四盏。页面卸载或切换地点时停止动画、移除监听并释放几何体、材质、阴影贴图和渲染器。后台标签跳过渲染。

展示台为平坦圆盘，方便比较布局；不代表正式岛屿地形、选址方向和所有天气效果。正式生成仍使用房主权威和原有设施同步，新布局只应用于新生成地点，旧档不重建。

# 动物受击伤害跳字

## 背景
攻击动物时需要直观、贴合动物位置的伤害反馈。

## 需求描述
野生动物、鸟和螃蟹受到有效攻击时，在动物中心上方显示清晰加粗的灰色伤害数字，跟随动物移动并上浮淡出，包含致命一击。数字属于 3D 场景；玩家原有红色界面跳字保持不变。

## 设计方案
- 各生物在统一伤害入口扣血后通知游戏层，显示本次结算伤害，四舍五入且至少为 1；致命一击显示完整攻击伤害。
- `AnimalDamageNumbers` 使用 CanvasTexture + Three.js Sprite，灰色 #b8b8b8 配 4px 深色描边、700 字重；精灵高 0.64 世界单位，字形约高 0.4 单位，保持朝向相机，按世界尺寸随镜头缩放。
- 命中时以模型包围盒水平中心、顶部上方 0.18 单位为起点，记录相对模型位置偏移。每帧跟随模型世界位置（含飞行与死亡坠落），不继承转向或侧翻；1 秒内上升 0.55 单位并淡出。模型移除后从最后位置完成淡出。
- 数字正常参与场景遮挡，不创建 React/DOM UI，不阻挡触屏操作；同时最多 32 个，结束后释放纹理、材质。
- 联机沿用动作上行与房主权威伤害结算，房主广播 animalDamage（动物类型、ID、伤害与世界位置），各端跟随本地模型，实体缺失时使用事件坐标。客人不预测跳字，血量、死亡、闪红继续由原同步机制驱动。
- 不新增存档字段，不修改存档版本。

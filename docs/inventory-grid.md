# 格子背包与地面掉落物

## 背景

原背包是「资源计数表」(四种资源各一个数字),背包面板里混合展示资源与合成列表,无法体现道具的个体、描述与丢弃。需要改为手机游戏常见的格子制背包,并支持把道具丢到地上。

## 需求描述

- 点击背包按钮打开格子背包面板(面板里不再有合成功能,合成仍由左侧手搓卡片触发)。
- 默认 10 个格子;相同道具自动叠加(单格上限 20);装备背包类道具后可扩容。
- 点击有道具的格子显示道具描述,并提供操作:
  - 丢弃:将一个该道具丢到玩家附近地上,走近后可自动拾回;
  - 使用:食物道具可点击使用(开始进食),并自动关闭背包。

## 设计方案

- `src/game/systems/Inventory.ts`:重写为格子制。`InventorySlot = { kind, count } | null`,`capacity` 默认 10(常量 `DEFAULT_CAPACITY`),`setCapacity` 只扩不缩。`add` 先叠加已有格再占空格,返回实际放入数(背包满则放入失败);`remove` 从后往前扣(保留靠前的格子);`count(kind)` 汇总;`snapshot()` 供 UI 渲染。
- `src/game/systems/Items.ts`(新增):道具静态定义 `ITEMS`,含名称、图标、描述;后续新道具在此登记。
- `src/game/systems/DropSystem.ts`(新增):地面掉落物系统。每个掉落物是低面数八面体网格,按道具着色,在玩家附近随机偏移落地,旋转 + 悬浮动画;丢弃后 0.8 秒内不可拾取,玩家走近(1.3 距离内)自动拾回背包,背包满则留在地上。
- `src/game/Game.ts`:
  - `HudSnapshot` 新增 `slots`(格子快照)与 `capacity`;原有的 wood/gravel/stone/berry 计数改为由格子汇总,继续供手搓/进食卡片判断材料。
  - 新增 `dropItem(kind)`(丢弃一个到地上);`eatFood(kind?)` 支持指定食物种类(背包「使用」按钮),不带参数时仍吃背包最前面的食物。
- `src/ui/Backpack.tsx`:重写为格子面板。5 列格子网格,点击有道具的格子选中并在下方显示名称、数量、描述与「使用/丢弃」按钮;使用食物后由外层关闭背包。背包按钮位置与样式不变。
- 合成消耗(`Crafting`/`WorkbenchSystem`)与进食判定(`EatingSystem`)从读取计数表改为 `inventory.count(kind)`。

## 迭代记录

- 2026-08-28:初版——背包改为 10 格格子制(叠加上限 20),新增道具定义与描述、丢弃到地上与自动拾回、背包内使用食物;移除背包面板中的合成列表。
- 2026-08-28(迭代 2):
  - 背包面板改为顶层居中弹窗(带半透明遮罩,点遮罩关闭),不再锚在右侧按钮旁被小屏截断。
  - 丢弃物不再自动捡回(旧版丢弃距离小于自动拾取半径,丢弃后 0.8 秒会被立刻捡回,表现为"地上看不到丢弃物");改为玩家靠近(1.6 距离)时左侧弹出「捡回」卡片,点击后才拾回;掉落物八面体放大加高更显眼。

- 2026-08-28(迭代 3):背包为空时隐藏背包按钮,拾取到道具后再显示。

- 2026-08-28(迭代 4):掉落物不再是统一八面体,新增 `src/game/systems/DropModels.ts` 为每种道具构建专属低面数造型——木材=交叉叠放圆木(带浅色端面)、石头=一大一小切面岩石、浆果=三颗红果+绿叶、纤维=捆扎成束的扇形草茎、绳线=双层盘绳圈+绳头、鱼=纺锤鱼身+尾鳍背鳍+浅色鱼腹;均保持黏土 flatShading 质感,主题色抽到 `DROP_COLORS` 与粒子特效共用,`DropSystem` 改用造型工厂并按子网格遍历释放资源。

- 2026-08-29(迭代 5):背包「物品」页详情区固定最小高度(与选中道具时等高,内容垂直居中),未选中时的提示文案不再使面板高度塌陷,选中/未选中切换面板高度保持一致。
- 2026-08-29(迭代 3):斧子/镐子/鱼竿/弓四种工具改为背包道具(`ResourceKind`/`ITEMS` 登记),制作产物入包并占格,可在背包查看详情与丢弃;「已拥有工具」改由背包内容推导(`Game.syncTools` 每帧同步),丢弃即失去、手持中被丢自动收手;工具掉落物有专属造型。HUD 工具布尔字段更名为 `hasAxe/hasPickaxe/hasFishingrod/hasBow`。

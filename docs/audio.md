# 音乐与音效(程序化生成)

## 背景

游戏此前完全没有声音。目标是加入背景音乐与玩法音效,全部声音由代码用 WebAudio 实时程序化合成,不引入任何音频文件,不增加加载体积,符合手机端性能约束。音乐风格参考久石让:五声音阶的如歌旋律、柔和钢琴音色、温暖铺底。

## 需求描述

- 背景音乐:久石让式调性的生成式配乐,循环不断且每次听都略有不同;白天明亮流动,夜晚低回稀疏。
- 环境声:常驻海浪声;雨天雨声随天气强度淡入淡出。
- 玩法音效:砍树、采石、采集(沙沙声,挥动即响)、手搓/工作台敲打、进食、喝水、抛竿、落水/拉鱼水花、咬钩提示、获得物品(采集收获/捡回/钓到鱼统一同一种)、丢弃、制作完成、死亡。
- 静音开关:游戏内右上角按钮,一键全局静音/恢复。
- 音量设置:开始界面「声音设置」区,音乐与音效两条滑杆独立调节,持久化到 localStorage,下次进入仍生效。
- 遵守浏览器自动播放策略:音频在用户点击「开始游戏」后启动,若上下文被挂起则借下一次触摸唤醒。

## 设计方案

模块位于 `src/game/audio/`,按职责拆分:

- `synth.ts`:合成底层工具——钢琴感拨弦音(正弦+八度三角波+低通+指数衰减)、通用单音、噪声爆发、循环噪声源、简易梳状混响(多抽头反馈延迟,手机友好)。音乐与音效共用,所有输出统一过混响营造海岛空间感。
- `Sfx.ts`:按动作语义命名的音效合成(每次播放带随机音高抖动避免机械感)。
- `Music.ts`:生成式配乐,三首久石让风格骨架的原创小曲轮换(每首连续两遍后换下一首)。参考其代表作的技术语汇(调性、和声进行、拍号、织体,不受版权保护;旋律为原创,不照搬原曲):「夏日之风」(《One Summer's Day》式,C 大调 4/4 慢速流动)、「海边圆舞曲」(《人生的旋转木马》式,A 小调 3/4 圆舞曲织体)、「森林絮语」(《风之甬道》式,F 大调田园风)。夜晚自动放慢 20%、低八度、旋律留白更多。音乐走独立总线,整体音量压在音效之下。前瞻式排程(setInterval 200ms,排 0.6s)。
- `Ambience.ts`:海浪(低通白噪声 + 0.09Hz LFO 起伏)与雨(带通噪声,setTargetAtTime 平滑跟随天气强度)。
- `GameAudio.ts`:统一入口。管理 AudioContext 生命周期、总音量/静音、挂起兜底唤醒;对外仅暴露 `play / setNight / setRainIntensity / toggleMute / dispose`。

接入方式沿用 `fx` 粒子系统的注入模式:各玩法系统(Collect/Crafting/Workbench/Eating/Water/Fishing/Drop)在事件发生处调用 `audio.play(...)`;`Game` 负责创建与销毁,并在主循环同步昼夜与雨声、检测死亡播放音效。UI 层 `GameplayUI` 提供右上角静音按钮(44px 触控区)。

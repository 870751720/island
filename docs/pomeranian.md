# 黑色博美伴侣

## 背景

荒岛上只有玩家一个人太孤单,希望有一只忠诚的小狗陪伴:出生时就在身边,能互动喂食,平时跟在身旁自己玩耍,为游戏增加情感陪伴氛围。

## 需求描述

- 一只黑色博美与玩家一起出生在附近。
- 玩家丢弃肉块(生肉/烤肉)落地后,博美会被附近的肉块吸引,跑过去吃掉(肉块消失,不进背包)。
- 吃完后回到玩家身旁跟随。
- 博美与玩家距离足够近时不再跟随,直到玩家再次走远。
- 不跟随时博美会自己玩:原地打转追尾巴、小跳、围着玩家踱步、坐着休息。
- 博美时不时在头顶冒小表情(❤️ 🦴 🎾 😊 等)传达心情。

## 设计方案

### 文件

- `src/game/entities/Pomeranian.ts` — 博美实体:程序化低多边形建模、AI 状态机、表情气泡。
- `src/game/systems/DropSystem.ts` — 新增 `nearestMeat()` / `consumeMeatNear()` 与 `MEAT_KINDS`(蟹肉/鸟肉/兽肉及其烤制品)。
- `src/game/Game.ts` — 创建实体、循环更新、存取档接入。
- `src/game/systems/SaveSystem.ts` — 存档新增 `dog: { x, z }` 落点,`SAVE_VERSION` 21 → 22。

### 模型

代码程序化建模,黏土质感(flatShading + 高粗糙度):蓬松黑毛圆身、张开的深色鬃毛(狮子脸)、尖耳、黑鼻头 + 粉舌头 + 高光眼睛、四条小短腿、背上由渐小毛球串成的卷尾。运行时程序动画:摆腿、摇尾(兴奋时加速)、进食低头咀嚼、小跳蹦跶。

### AI 状态机(每帧按优先级)

1. **进食中**:原地低头咀嚼 1.4 秒,不可移动。
2. **吃肉**:9 格内有玩家丢弃的肉块 → 奔跑去吃,吃到后冒 😋/🦴 表情。只吃主动丢弃的肉;狩猎战利品与背包溢出的掉落不碰,不和玩家抢。
3. **跟随**:与玩家距离 > 3.2 → 小跑跟上(>8 格改奔跑);玩家下水时追到岸边等待(不踏入水)。
4. **闲玩**:玩家在身边 → 随机切换「围着玩家转圈(优先)/ 原地转圈追尾巴 / 趴坐 / 趴下睡觉 / 刨坑」;玩家远行归来后回到身边时冒 🥰。
5. **睡觉**:夜间玩家在身边没别的事时,趴在旁边睡长觉(💤),被肉香或玩家走远叫醒;白天闲玩池里也会偶尔小睡。睡觉有 2 分钟内置冷却。
6. **刨坑**:两只前腿飞快扒土、扬起沙尘粒子,开始冒 🐾,刨完歪头冒 ❓/😮。刨坑有 2 分钟内置冷却;原地转圈有 1 分钟冷却。
7. **表情节奏**:闲玩随机表情每 60 秒一次、持续 2 秒;吃肉/重逢/睡觉/刨坑等事件表情即时触发;不再有出场与开始跟随的表情。

### 表情气泡

与玩家自言自语同一套链路:博美实体只维护「当前表情 + 剩余时间」与头顶锚点,Game 每帧把锚点投影为屏幕坐标,通过回调直写 React 层的白色圆泡 DOM:吃肉(😋/🦴)、重逢(🥰)、睡觉(💤)、刨坑(🐾/❓/😮)、闲玩随机(🐕/❤️/✨/🐾/🎾/😊/🥰,每 60 秒一次持续 2 秒)。

### 移动约束

只站在高出当地水面(海面或水洼)0.05 的干地上,且被围栏阻挡;不可走时停在原地。

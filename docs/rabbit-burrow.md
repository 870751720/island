# 兔子洞

## 背景

兔子此前是纯粹的「逃跑型猎物」:玩家靠近就背向逃窜,只能用弓箭/剑追猎。参考饥荒的兔子洞机制,给兔子一个避难所,让铲子成为狩猎兔子的另一条稳定路线。

## 需求描述

- 每个兔子栖息地生成 1~2 个兔子洞(地表低模洞口:土堆 + 黑洞口 + 干草点缀),洞与栖息地绑定,是兔子共同的「家」。
- 兔子受惊(被打、玩家进入感知圈、听到劳作/放箭噪音)时,优先朝最近的完好洞跑(寻找范围 16 米,超出才照旧背向逃窜);跑到洞口即钻入躲藏(模型隐藏)。
- 躲藏期间无敌:近战、弓箭、噪音惊动都对其无效。玩家离开洞口警戒圈(3.6 米)持续 5 秒后,兔子探头钻出恢复游荡。
- 手持铲子靠近完好洞站定自动挖掘(与其他可挖掘建筑一致):挖开后藏在内的兔子直接死亡(按普通猎杀掉落兽肉+兔毛,散落在洞口),洞变废弃不再提供庇护。
- 废弃洞在 1~2 个昼夜(240~480 秒)后,在附近重新塌出一个新洞,保持生态循环。

## 设计方案

- `src/game/entities/RabbitBurrow.ts`:程序化兔子洞模型(土堆环绕 + 深色洞口 + 干草),`abandon()` 把洞口塌成浮土痕迹;状态 `intact / abandoned`。
- `src/game/systems/RabbitBurrowSystem.ts`:洞的生成(`generateFor`:以兔子栖息地中心为锚,草地内采样落点)、铲子自动挖掘(`updateActor`,与净化器同套路:1.6 米内站定挥铲,命中数按铲子等级)、废弃重生(仅权威端推进倒计时,到点在原洞附近找新草地落点,删旧建新)、存档/网络快照(`RabbitBurrowSave`,重生倒计时只入档不下发)。洞是野外场景实体,不进背包、不可搬运。
- `src/game/entities/Wildlife.ts` 兔子行为:
  - 逃跑分支加入洞口寻路:受惊时先 `nearestIntact`(16 米),朝洞跑、距洞口 0.5 米内 `enterBurrow`(藏身点记录在 `animal.burrow`,模型隐藏)。
  - 躲藏分支 `updateHidden`:任一可攻击玩家距洞口 < 警戒平息距离(3.6 米)则重置倒计时,否则 5 秒后探头恢复游荡。
  - 躲藏无敌:`nearestAlive / nearestId / hitSegment / damageNearby / damage / startle` 全部跳过 `hidden` 个体。
  - `killHidden(x, z)`:挖洞塌方结算,把藏在该洞的兔子直接判死(释放栖息地槽位,走正常冷却补刷),数量返回给游戏侧掉落战利品。
  - `rabbitHomes()`:暴露兔子栖息地中心给洞系统开局生成;`setBurrowSource` 注入洞查询接口。
- Game 接线:洞系统在 Wildlife 之后构造,挖开回调里 `killHidden` + 按普通猎杀在洞口周围 `dropAt` 战利品;客人端不本地生成洞,由欢迎包世界状态 + 世界增量补建。

### 联机

- 洞的增删/挖废是离散变化:走世界增量(`WorldPatch.burrows` 节,稳定实体 id);重生倒计时是连续数值,不下发,仅房主推进。
- 挖掘动作无客人上行:客人的铲子挖掘由房主 `updateActor` 对远程会话统一结算,与其他可挖掘建筑一致。
- 兔子躲藏是房主 AI 状态:姿态快照 `AnimalPose` 增加 `hidden` 标记,客人端同步隐藏/显示模型,并同样跳过躲藏个体的本地索敌。

# 围栏与围栏门功能实现方案

## 核心思路:网格顶点吸附 + 自动连接

现有放置系统是自由坐标(玩家脚下),无法保证围栏对齐无缝。围栏改为 **1 格网格(GRID=1)顶点吸附**:

- 每个围栏段是一个**网格顶点上的柱子**;放置时吸附到玩家面前最近的网格顶点。
- 渲染时检查 4 个相邻顶点(±1, 0 / 0, ±1)是否也有围栏/门,自动向这些方向伸出横杆 → **玩家只要沿边走一圈逐个放置,天然无缝闭合**。
- 放置后重新刷新相邻围栏的模型,保证双向连接即时可见。

围栏门占一条**边**(两个相邻顶点之间),放置时吸附到玩家面前最近的网格边(东西边或南北边,取朝向较近者);关闭时阻挡,靠近点击/动作键切换开关;开门状态栏本身仍显示为门框,不伸出连接横杆之外的多余杆。

## 配方(二级工作台,minBenchLevel: 2,station: 'workbench')

- `fenceWood`:1 木头 → 2 个木围栏
- `fenceStone`:1 石头 → 2 个石围栏
- `fenceGate`:2 木头 → 1 个围栏门(木门样式,石头围栏区也可用)

## 文件改动

1. **`src/game/entities/Fence.ts`**(新):程序化建模。木围栏 = 粗糙圆柱柱子 + 扁平板横杆;石围栏 = 方石堆柱 + 石板横杆,flatShading 黏土风。导出 `buildFenceMesh(kind, connections: {n,s,e,w})`,连接变化时 dispose 重建(参考 Workbench.rebuild)。
2. **`src/game/entities/FenceGate.ts`**(新):门框两柱 + 可旋转门扇,`setOpen(bool)` 用旋转动画,木材质。
3. **`src/game/systems/FenceSystem.ts`**(新,参考 CrateSystem 骨架):
   - `fences: Map<key "gx,gz", {kind}>`、`gates: Map<edgeKey, {dir, open}>`
   - `use(kind)`:吸附到玩家面前网格顶点,校验(干地、不与 props/其他建筑/已有围栏重叠)→ 放置 → 刷新自身与 4 邻居模型
   - `placeGate()`:吸附最近网格边,校验该边无围栏横杆穿过(即两顶点间不能已有连接)
   - `updateDig()`:手持锄头靠近可挖除变回道具(同 CrateSystem)
   - 碰撞查询:`blockSegments()` 产出所有阻挡线段(围栏连接段 + 关闭状态的门边);`isBlocked(x, z, r)` 点查询
   - `toggleGate()` / 交互检测(动作键靠近门时优先开门)
   - `snapshot()/restore()`
4. **玩家碰撞**:`Player.ts` 的 `resolveCollision` 调用处追加 FenceSystem 的线段推挤(点到线段距离 < 半径则沿法线推出),围栏挡玩家。
5. **动物阻挡**:`Wildlife.ts` 的 `step()/tryDir` 可走性判断与 `Crab.ts` 的沙地判断中,加入 `isBlocked(x,z)` 回调(Game 注入 FenceSystem),围栏闭合时切线方向也失败 → 动物被圈住。
6. **物品与配方**:`Inventory.ts` ResourceKind 加 `fenceWood/fenceStone/fenceGate`;`Items.ts` 加图标(🪵/🪨/🚪风格 emoji)与描述;`Crafting.ts` 加 3 条 RECIPES。
7. **存档**:`SaveSystem.ts` 的 SaveData 加 `fences: {x,z,kind}[]`、`fenceGates: {x,z,dir,open}[]`;`SAVE_VERSION` 20→21(旧档丢弃,符合仓库约定)。
8. **Game.ts**:接线 use 分发、碰撞注入、动作键交互门、snapshot/restore、锄头挖掘。
9. **交互提示**:放置失败 notify 文案;靠近门时动作按钮显示"开门/关门"。
10. **`docs/fence.md`**(新):按仓库模板记录需求。

## 移动端注意

- 围栏模型低面数(柱子 6-8 边圆柱、横杆 Box),无阴影以外开销。
- 放置仍是"背包使用→原地(吸附)放置",无新增预览 UI,与现有交互一致,适合触屏。
